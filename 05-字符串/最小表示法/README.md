# 最小表示法（Minimal Representation）

> 最小表示法求一个字符串的**循环同构串中字典序最小**的那个。它是双指针的经典应用，$O(n)$ 时间。

## 1. 问题定义

给定长度为 $n$ 的字符串 $s$，它的**循环同构串**共有 $n$ 个：

$$
s[0..n-1],\ s[1..n-1]+s[0],\ \ldots,\ s[n-1]+s[0..n-2]
$$

求这些串中**字典序最小**的那个（输出起始位置或字符串本身）。

**例子**：$s = \text{"baca"}$

循环同构：`baca`、`acab`、`caba`、`abac`。最小是 `abac`（起点 3）。

---

## 2. 暴力做法

枚举 $n$ 个起点，每个比较 $n$ 个字符，$O(n^2)$。

---

## 3. 双指针优化

**核心**：维护两个候选起点 $i, j$，比较从它们开始的串，跳过不可能成为最小表示的位置。

算法：

1. $i = 0$，$j = 1$，$k = 0$；
2. 比较 $s[(i+k) \bmod n]$ 与 $s[(j+k) \bmod n]$：
   - 若相等，$k$ 增加；
   - 若不相等（假设 $s[i+k] > s[j+k]$），则 $i$ 到 $i+k$ 之间的所有起点都不可能（因为以 $j$ 开头更优），令 $i = i + k + 1$（$k$ 重置）；
   - 若 $i == j$，令 $j$ 增加；
3. 直到 $k \ge n$ 或 $i, j$ 有一个 $\ge n$；
4. 答案是 $\min(i, j)$。

**复杂度**：$O(n)$（$i, j$ 都只增）。

### 为什么跳过有效？

若 $s[i..i+k-1] == s[j..j+k-1]$ 且 $s[i+k] > s[j+k]$，那么对任意 $0 \le t \le k$，以 $i+t$ 开头的串都大于以 $j+t$ 开头的串（因为前 $k-t$ 个字符相同，而 $i+t$ 的第 $k-t$ 个字符更大）。所以 $i..i+k$ 都可以跳过。

## 4. 模板代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 返回最小表示法的起始位置（0-indexed）
int minRepresentation(const string& s) {
    int n = s.size();
    int i = 0, j = 1, k = 0;
    while (i < n && j < n && k < n) {
        char a = s[(i + k) % n];
        char b = s[(j + k) % n];
        if (a == b) {
            ++k;
        } else {
            if (a > b) i += k + 1;
            else j += k + 1;
            if (i == j) ++j;
            k = 0;
        }
    }
    return min(i, j);
}

int main() {
    string s;
    cin >> s;
    int pos = minRepresentation(s);
    int n = s.size();
    string ans = s.substr(pos) + s.substr(0, pos);
    cout << ans << endl;
    return 0;
}
```

### 4.1 最大表示法

把比较符号反过来（`a > b` 时换成 `j += k + 1`）。

## 5. 经典例题

### 5.1 【模板】最小表示法

**题意**：给字符串，求最小表示。

**做法**：双指针。

### 5.2 循环同构判断

**题意**：判断两串是否循环同构。

**做法**：求两串的最小表示，比较是否相等。

```cpp
bool isCyclicIsomorphic(const string& a, const string& b) {
    if (a.size() != b.size()) return false;
    int pa = minRepresentation(a);
    int pb = minRepresentation(b);
    int n = a.size();
    for (int i = 0; i < n; ++i)
        if (a[(pa + i) % n] != b[(pb + i) % n]) return false;
    return true;
}
```

### 5.3 循环同构串中第 $k$ 小

求所有循环同构串排序后的第 $k$ 小（进阶）。

### 5.4 字符串匹配

用最小表示法 + KMP/哈希加速匹配。

## 6. 易错点与练习

### 易错点

1. **取模**：`(i + k) % n`；
2. **`i == j` 时**：要令 `j++`，否则死循环；
3. **`k` 重置**：不相等后 `k = 0`；
4. **结束条件**：`i < n && j < n && k < n`；
5. **答案是 `min(i, j)`**：不是 `i`；
6. **空串**：特判。

### 练习建议

1. 最小表示法模板；
2. 最大表示法；
3. 循环同构判断；
4. 循环同构 + 哈希；
5. 与后缀数组配合。

## 附：更多经典例题

### 例题 1：循环同构串的字典序排名

**题意**：给字符串 $s$，求它的所有循环同构串按字典序排序后，原串的排名。

**思路**：把 $s$ 复制一份得到 $ss$，对 $ss$ 建后缀数组，取前 $n$ 个后缀排序即为所有循环同构串的字典序。$O(n \log n)$。

### 例题 2：最小表示法 + 哈希判重

**题意**：给 $n$ 个字符串，统计本质不同（循环同构意义下）的字符串个数。

**思路**：对每个串求最小表示，再对所有最小表示求哈希去重。$O(\sum |s|)$。

### 例题 3：字符串最小循环移位（带权）

**题意**：在循环移位中找使某权值函数最小的位置。

**思路**：若权值随字典序单调，可用最小表示法；否则需要枚举或其它方法。

### 例题 4：最小表示法的对拍验证

写一个暴力枚举所有循环移位取最小的程序，与双指针版本对拍，验证 $n \le 20$ 的随机串全部一致。
