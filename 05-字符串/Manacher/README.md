# Manacher 算法

> Manacher 用 $O(n)$ 时间求**最长回文子串**。它的核心是：利用已知回文的信息，避免重复比较。

## 1. 中心扩展法

回文串有 $2n-1$ 个中心（$n$ 个字符中心 + $n-1$ 个间隙中心）。对每个中心向两边扩展，最坏 $O(n^2)$。

```
"abba" 的中心：
a  b  b  a
  ^  ^  ^
字符中心   间隙中心
```

---

## 2. 奇偶统一处理

**技巧**：在字符间插入特殊分隔符（如 `#`），把奇偶回文统一成奇数长度。

```
原串: a b b a
处理: # a # b # b # a #
```

这样所有回文都是奇数长度，中心一定是字符。

---

## 3. Manacher 的核心优化

**定义**：$p[i]$ = 以 $i$ 为中心的最长回文半径（包含中心）。

**维护**：当前已知的「最右回文边界」$R$，以及其中心 $C$。

- 若 $i < R$：$p[i] \ge \min(p[2C - i], R - i)$（对称点 $2C-i$ 已知）；
- 从 $\min$ 处继续扩展；
- 若 $i + p[i] > R$，更新 $C = i$，$R = i + p[i]$。

**复杂度**：$R$ 只增不减，总扩展 $O(n)$。

### 图示

```
     C
  ---|-----------
     |   i     R
     |   |
  2C-i  对称点
```

## 4. 模板代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 返回处理后的字符串和 p 数组
pair<string, vector<int>> manacher(const string& s) {
    string t = "^";
    for (char c : s) { t += '#'; t += c; }
    t += "#$";

    int n = t.size();
    vector<int> p(n, 0);
    int C = 0, R = 0;
    for (int i = 1; i < n - 1; ++i) {
        int mirror = 2 * C - i;
        if (i < R) p[i] = min(R - i, p[mirror]);
        while (t[i + 1 + p[i]] == t[i - 1 - p[i]]) ++p[i];
        if (i + p[i] > R) { C = i; R = i + p[i]; }
    }
    return {t, p};
}

// 最长回文子串长度
int longestPalindrome(const string& s) {
    auto [t, p] = manacher(s);
    int ans = 0;
    for (int i = 1; i < (int)t.size() - 1; ++i) ans = max(ans, p[i]);
    return ans;
}

int main() {
    string s;
    cin >> s;
    printf("%d\n", longestPalindrome(s));
    return 0;
}
```

### 4.1 输出最长回文子串

```cpp
// p[i] 是以 i 为中心的半径（# 分隔后的长度）
// 原串中回文起点: (i - p[i]) / 2
// 回文长度: p[i]（因为插入了 #）
int center = 1;
for (int i = 1; i < (int)t.size() - 1; ++i)
    if (p[i] > p[center]) center = i;
int start = (center - p[center]) / 2;
printf("%s\n", s.substr(start, p[center]).c_str());
```

## 5. 经典例题

### 5.1 【模板】最长回文子串

**题意**：给字符串，求最长回文子串长度。

**做法**：Manacher。

**复杂度**：$O(n)$。

### 5.2 回文子串数量

**题意**：统计所有回文子串个数。

**做法**：Manacher 后，以每个中心贡献 `(p[i])/2` 个回文。

### 5.3 最长双回文串

**题意**：把字符串分成两段，每段都是回文，求最大总长度。

**做法**：Manacher 预处理每个前缀/后缀的最长回文。

### 5.4 回文分割

**题意**：最少分割次数使每段都是回文。

**做法**：Manacher + DP。

### 5.5 回文自动机

Manacher 求最长，回文自动机求所有本质不同回文（见[回文自动机](../回文自动机/README.md)）。

## 6. 易错点与练习

### 易错点

1. **边界哨兵**：`t = "^...$"` 防止越界；
2. **`p[i]` 的含义**：是半径，回文实际长度在变换后是 `p[i]`，在原串是 `p[i]`（如果按上面写法）；
3. **`min(R - i, p[mirror])`**：注意不能超过边界；
4. **更新 `C, R`**：`i + p[i] > R` 时；
5. **下标**：`p` 数组大小要开 `2n+3`；
6. **输出子串**：起点 `(i - p[i]) / 2`。

### 练习建议

1. Manacher 模板；
2. 回文子串数量；
3. 最长双回文串；
4. 回文分割（DP + Manacher）；
5. 对比哈希 + 二分（$O(n \log n)$）。

## 附：更多经典例题与实现细节

### 例题 1：回文子串计数

**题意**：统计字符串中回文子串的个数（不同位置算不同）。

**思路**：Manacher 求出每个中心的半径 $p[i]$ 后，以该中心为中心的回文子串个数为 $\lceil p[i]/2 \rceil$（按 `#` 分隔的写法）。所有中心求和即可。$O(n)$。

### 例题 2：最长双回文串

**题意**：把字符串切成两段 $s[1..i]$ 与 $s[i+1..n]$，两段都必须是回文，求最大总长度。

**思路**：正着做一遍 Manacher 求出「以每个位置结尾的最长回文长度」，反着再做一遍求「以每个位置开头的最长回文长度」，然后枚举分界点。$O(n)$。

### 例题 3：回文分割最小次数

**题意**：把字符串分割成若干回文串，求最少段数。

**思路**：先用 Manacher 预处理出所有回文区间（$O(n^2)$ 个时不可取），再设 $dp[i]$ 表示前 $i$ 个字符的最少段数，转移时只考虑以 $i$ 结尾的最长回文（可以证明最优解总能用最长回文），$O(n)$ 或 $O(n \log n)$。

### 实现细节：为什么插入 `#` 后所有回文都是奇数长度

原串中长度为偶数的回文（如 `abba`）中心在两个字符之间；插入 `#` 后变成 `#a#b#b#a#`，中心落在中间那个 `#` 上，长度变为奇数。这样统一处理，避免分奇偶讨论。
