# Z 函数（Z-Algorithm / 扩展 KMP）

> Z 函数 $z[i]$ 表示「字符串 $s$ 与 $s[i..]$ 的最长公共前缀长度」。它能 $O(n)$ 求出所有后缀与原串的 LCP，是 KMP 的好兄弟。

## 1. 定义

对字符串 $s$（长度 $n$），定义

$$
z[i] = \text{LCP}(s, s[i..n-1]) \quad (0 \le i < n)
$$

即从 $i$ 开始的后缀与整个串的最长公共前缀长度。

**约定**：$z[0] = n$（或 0，看实现）。

**例子**：$s = \text{"ababab"}$

| $i$ | 后缀 | LCP | $z[i]$ |
|---|---|---|---|
| 0 | ababab | 6 | 6 |
| 1 | babab | 0 | 0 |
| 2 | abab | 4 | 4 |
| 3 | bab | 0 | 0 |
| 4 | ab | 2 | 2 |
| 5 | b | 0 | 0 |

---

## 2. 朴素求法与优化

**朴素**：对每个 $i$ 从 0 开始比较，最坏 $O(n^2)$。

**优化思路**：维护一个「当前最靠右的匹配区间」$[l, r]$，其中 $s[l..r] = s[0..r-l]$。

- 若 $i \le r$：则 $z[i] \ge \min(z[i-l], r - i + 1)$；
- 从 $\min$ 处继续暴力扩展；
- 若 $i + z[i] - 1 > r$，更新 $l = i$，$r = i + z[i] - 1$。

**关键**：$r$ 只增不减，总扩展次数 $O(n)$。

---

## 3. 算法流程

```
l = r = 0
z[0] = n
for i = 1 to n-1:
    if i <= r:
        z[i] = min(r - i + 1, z[i - l])
    while i + z[i] < n and s[z[i]] == s[i + z[i]]:
        z[i]++
    if i + z[i] - 1 > r:
        l = i
        r = i + z[i] - 1
```

## 4. 模板代码

### 4.1 纯 Z 函数

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> zFunction(const string& s) {
    int n = s.size();
    vector<int> z(n, 0);
    z[0] = n;
    for (int i = 1, l = 0, r = 0; i < n; ++i) {
        if (i <= r) z[i] = min(r - i + 1, z[i - l]);
        while (i + z[i] < n && s[z[i]] == s[i + z[i]]) ++z[i];
        if (i + z[i] - 1 > r) { l = i; r = i + z[i] - 1; }
    }
    return z;
}

int main() {
    string s;
    cin >> s;
    auto z = zFunction(s);
    for (int i = 0; i < (int)s.size(); ++i) printf("%d ", z[i]);
    return 0;
}
```

### 4.2 模式匹配（扩展 KMP）

在 $t + \# + s$ 上求 Z 函数（`#` 是不存在的字符）：

```cpp
vector<int> match(const string& s, const string& t) {
    string u = t + '\1' + s;
    auto z = zFunction(u);
    vector<int> res;
    int m = t.size();
    for (int i = m + 1; i < (int)u.size(); ++i)
        if (z[i] >= m) res.push_back(i - m - 1);   // 匹配起点
    return res;
}
```

## 5. 应用

### 5.1 字符串匹配

见上，$O(n + m)$。

### 5.2 求所有 border

$i + z[i] = n$ 的位置，$z[i]$ 就是一个 border 长度。

### 5.3 最小循环节

若 $n \bmod (n - z[?])$ ... 实际上最小循环节用 KMP 更方便。

### 5.4 字符串周期

若 $z[i] \ge n - i$，则前缀 $s[0..n-i-1]$ 是周期。

### 5.5 压缩

用 Z 函数找重复前缀。

## 6. 经典例题

### 6.1 【模板】Z 函数

**题意**：输出所有 $z[i]$。

**做法**：直接套模板。

### 6.2 字符串匹配（扩展 KMP）

**题意**：求模式串在文本串中的所有出现位置。

**做法**：拼接后求 Z 函数。

### 6.3 最长公共前缀

**题意**：多次询问两个后缀的 LCP。

**做法**：后缀数组 + RMQ，或 Z 函数（单串）。

### 6.4 循环同构

**题意**：判断 $B$ 是否是 $A$ 的循环移位。

**做法**：$B$ 在 $A + A$ 中用 Z 函数匹配。

### 6.5 字符串压缩

**题意**：求最短的压缩表示。

**做法**：Z 函数 + 枚举周期。

## 7. 易错点与练习

### 易错点

1. **$z[0]$ 的定义**：设为 $n$ 还是 0，要统一；
2. **`min(r - i + 1, z[i - l])`**：顺序不能反；
3. **更新 $l, r$ 的条件**：`i + z[i] - 1 > r`；
4. **`while` 的边界**：`i + z[i] < n`；
5. **分隔符**：拼接时用不出现在字符串中的字符（如 `\1`）；
6. **多组数据**：每次重新计算。

### 练习建议

1. Z 函数模板；
2. 字符串匹配（扩展 KMP）；
3. 最小循环节（对比 KMP）；
4. 循环同构判断；
5. 与后缀数组对比 LCP。
