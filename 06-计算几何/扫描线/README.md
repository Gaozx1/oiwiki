# 扫描线（Sweep Line）

> 扫描线 = 想象一条直线从一侧扫到另一侧，**只在关键事件处停下来处理**。它把二维问题降为一维，是计算几何与数据结构结合的经典技巧。

## 1. 核心思想

**问题**：求若干个矩形的面积并 / 周长并。

**朴素做法**：暴力把平面切成网格——$O(n^2)$ 甚至更慢。

**扫描线做法**：

1. 把所有矩形的左右边界（或上下边界）作为**事件**；
2. 按 $x$ 坐标排序；
3. 用一条竖直线从左往右扫，维护当前被覆盖的 $y$ 区间；
4. 每扫过一段，计算「覆盖宽度 × 扫描距离」。

**关键**：维护「被覆盖区间的总长度」需要**线段树**。

```
       ┌───────┐
       │   A   │
   ┌───┼───┐   │
   │   │   │   │
   │   B   │   │
   └───┴───┴───┘
   ↑   ↑   ↑   ↑
  x1  x2  x3  x4      ← 事件线
```

## 2. 矩形面积并

### 2.1 算法

1. 把每个矩形拆成两条事件：`(x1, y1, y2, +1)` 和 `(x2, y1, y2, -1)`；
2. 按 $x$ 排序；
3. 坐标 $y$ 离散化；
4. 线段树维护每个 $y$ 小区间被覆盖的次数与有效长度；
5. 从左往右扫：
   - 面积 += 上一次的「有效高度」 × $(x_i - x_{i-1})$；
   - 应用当前事件（区间加/减）。

### 2.2 线段树节点定义

```cpp
struct Node {
    int cnt;        // 被完整覆盖的次数
    double len;     // 当前被覆盖的长度
};
```

- 若 `cnt > 0`：`len = 区间总长`；
- 若 `cnt == 0` 且是叶子：`len = 0`；
- 若 `cnt == 0` 且非叶子：`len = 左.len + 右.len`。

**不需要**懒标记下传，因为只需要根节点的 `len`。

## 3. 矩形周长并

**思路**：周长 = 两条扫描线的贡献之和。

- **竖边**：每次扫描线移动时，有效高度变化量的绝对值；
- **横边**：每段扫描的「有效高度 × 2」（上下各一条）——但要注意重叠。

更简单的方法：做两次扫描线（一次扫 $x$，一次扫 $y$），或者用「周长 = 2 × (所有竖边长度 + 所有横边长度)」分别计算。

**另一种做法**：线段树额外维护「区间内线段条数」，横边贡献 = 线段条数 × 2 × 扫描距离。

## 4. 模板代码

### 4.1 矩形面积并

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 200005;

struct Event {
    double x, y1, y2;
    int type;          // +1 入边, -1 出边
    bool operator<(const Event& b) const { return x < b.x; }
};

struct Node {
    int cnt;
    double len;
} tr[N << 3];

double yyy[N << 1];   // 离散化后的 y 坐标

void pushup(int p, int l, int r) {
    if (tr[p].cnt > 0) {
        tr[p].len = yyy[r + 1] - yyy[l];
    } else if (l == r) {
        tr[p].len = 0;
    } else {
        tr[p].len = tr[p<<1].len + tr[p<<1|1].len;
    }
}

void update(int p, int l, int r, int ql, int qr, int v) {
    if (ql <= l && r <= qr) {
        tr[p].cnt += v;
        pushup(p, l, r);
        return;
    }
    int mid = (l + r) >> 1;
    if (ql <= mid) update(p<<1, l, mid, ql, qr, v);
    if (qr > mid)  update(p<<1|1, mid+1, r, ql, qr, v);
    pushup(p, l, r);
}

int main() {
    int n;
    scanf("%d", &n);
    vector<Event> ev;
    int tot = 0;
    for (int i = 0; i < n; ++i) {
        double x1, y1, x2, y2;
        scanf("%lf%lf%lf%lf", &x1, &y1, &x2, &y2);
        ev.push_back({x1, y1, y2, 1});
        ev.push_back({x2, y1, y2, -1});
        yyy[++tot] = y1;
        yyy[++tot] = y2;
    }
    sort(yyy + 1, yyy + tot + 1);
    int m = unique(yyy + 1, yyy + tot + 1) - yyy - 1;

    sort(ev.begin(), ev.end());

    double ans = 0;
    for (int i = 0; i < (int)ev.size(); ++i) {
        double x = ev[i].x;
        if (i > 0) ans += tr[1].len * (x - ev[i-1].x);
        int l = lower_bound(yyy + 1, yyy + m + 1, ev[i].y1) - yyy;
        int r = lower_bound(yyy + 1, yyy + m + 1, ev[i].y2) - yyy - 1;
        if (l <= r) update(1, 1, m - 1, l, r, ev[i].type);
    }
    printf("%.2f\n", ans);
    return 0;
}
```

> 注意：线段树下标是「区间编号」，共 $m-1$ 个区间；$yyy[l]$ 到 $yyy[l+1]$ 是第 $l$ 个区间。

### 4.2 矩形周长并（简化版：两次扫描）

```cpp
// 先求所有竖边贡献（扫描 x）
double solveVertical(vector<Event> ev);   // 与面积并类似，累加 |len 变化|
// 再交换 x/y 求横边
```

更稳妥的做法是求两次面积并的「增量」：

$$
\text{周长} = 2 \times \sum (\text{len}_{\text{new}} - \text{len}_{\text{old}})
$$

不过要注意这是「竖直方向的变化量」，需要逐事件累加绝对值。

## 5. 其他扫描线应用

### 5.1 最大点覆盖（扫描线 + 线段树）

给 $n$ 个矩形的「权重」，求某个点被覆盖的最大权重和。用扫描线维护区间加 + 区间最大值。

### 5.2 矩形面积交

多个矩形的交集面积：可用线段树维护「覆盖次数 ≥ 2 的长度」，或容斥。

### 5.3 圆形面积并

圆形不好处理，一般用自适应辛普森积分（数值方法）。

### 5.4 扫描线求最近点对

按 $x$ 排序后，用 `set` 维护 $y$ 在 $[y-d, y+d]$ 内的点。

### 5.5 扫描线 + 单调栈：最大矩形

柱状图中的最大矩形：见「单调栈」。

### 5.6 平面最近点对（分治）

不完全是扫描线，但思想类似。

## 6. 经典例题

### 6.1 【模板】矩形面积并

**题意**：$n \le 10^5$ 个矩形，求并集面积。

**做法**：扫描线 + 线段树，$O(n \log n)$。

### 6.2 【模板】矩形周长并

**题意**：$n$ 个矩形，求并集周长。

**做法**：两次扫描线，或线段树维护线段数。

### 6.3 亚特兰蒂斯（Atlantis）

**题意**：经典题，求矩形面积并。

**做法**：同上。

### 6.4 窗口的星星

**题意**：给 $n$ 个点，每个点有权值，用一个固定大小的窗口框住尽量多的权值。

**做法**：扫描线 + 线段树区间加/区间最大值。

## 7. 易错点

1. **离散化下标**：`lower_bound` 得到的是**坐标**下标，线段树维护的是**区间**，差 1；
2. **线段树区间数**：$m$ 个坐标 → $m-1$ 个区间，线段树 `build(1, 1, m-1)`；
3. **`pushup` 逻辑**：`cnt > 0` 时 `len = 实际长度`；`cnt == 0` 且叶子时 `len = 0`；否则合并儿子；
4. **不需要 `pushdown`**：因为 `cnt` 是「覆盖次数」，只在 `pushup` 时用；
5. **事件顺序**：同一 $x$ 的事件要先处理，还是先累加面积？先累加上一段的面积再处理当前事件；
6. **周长并的重复计算**：同一 $x$ 有多个事件时要一起处理；
7. **坐标范围**：注意 `double` 精度与取整（题目可能要求输出整数）。
