# 欧拉路径与欧拉回路

> 一句话概括：**欧拉路径**是一条「不重复地走过图中每条边恰好一次」的路径；若起点与终点相同，则称为**欧拉回路**。判定与构造的核心是「度数条件 + Hierholzer 算法」。

## 1. 概念与直观理解

### 1.1 定义

给定无向图或有向图 $G=(V,E)$：

- **欧拉路径（Euler path）**：一条经过每条边**恰好一次**的路径；
- **欧拉回路（Euler circuit）**：起点与终点相同的欧拉路径；
- **欧拉图**：存在欧拉回路的图；
- **半欧拉图**：存在欧拉路径但不存在欧拉回路的图。

> 注意：欧拉路径要求「边」不重复，**点可以重复经过**；这与哈密顿路径（每个点恰好一次）完全不同。欧拉路径是多项式可解的，而哈密顿路径是 NP 完全问题。

### 1.2 直观例子：一笔画

把图想象成一张由线段组成的画，欧拉路径就是「笔不离开纸、每条线段只描一次」的一笔画问题。

```
   A --- B
   |     |
   C --- D --- E
         |
         F
```

例如上面这个图，从 $E$ 出发可以走：

$$E \to D \to C \to A \to B \to D \to F$$

依次经过边 $ED,\ DC,\ CA,\ AB,\ BD,\ DF$，每条边恰好一次，这就是一条欧拉路径（$E$、$F$ 是仅有的两个奇度点，符合判定条件）。

再比如经典的「七桥问题」：哥尼斯堡的七座桥无法一笔走过，因为奇度顶点有四个，超过两个。

### 1.3 为什么与度数有关

考虑路径经过一个中间点 $v$ 的情形：每经过一次，一定「进」一次、「出」一次，消耗两条与 $v$ 关联的边。因此：

- 对于欧拉**回路**，每个点进出次数相等，所有点的度数必须为偶数；
- 对于欧拉**路径**，除起点与终点外每个点进出次数相等，起点与终点可能「多出」一条边，故度数必须为奇数。

这个直觉就是下面判定定理的来源。

## 2. 存在性判定

### 2.1 无向图

设图连通（忽略孤立点），$d(v)$ 为点 $v$ 的度数：

- **欧拉回路存在** $\iff$ 所有点的度数都是偶数；
- **欧拉路径存在** $\iff$ 恰有 $0$ 个或 $2$ 个奇度点；若有 $2$ 个，路径必须从其中一个奇度点出发，到另一个结束。

### 2.2 有向图

设图的所有边在同一个弱连通分量内（忽略孤立点），记 $\operatorname{in}(v)$、$\operatorname{out}(v)$ 为入度与出度：

- **欧拉回路存在** $\iff$ 对所有点 $v$，$\operatorname{in}(v)=\operatorname{out}(v)$；
- **欧拉路径存在** $\iff$ 至多一个点满足 $\operatorname{out}(v)-\operatorname{in}(v)=1$（起点），至多一个点满足 $\operatorname{in}(v)-\operatorname{out}(v)=1$（终点），其余点入度等于出度。

### 2.3 连通性检查

度条件只是必要条件之一，还必须保证**所有含边的点连通**。常用做法：

- 从任意一个度不为 $0$ 的点开始 DFS/BFS，检查是否能到达所有度不为 $0$ 的点；
- 有向图要检查的是**弱连通**（把边视为无向），而不是强连通。因为欧拉回路经过每条边恰好一次，弱连通加上入度等于出度就能保证可达性。

### 2.4 两个定理

**定理 1（欧拉，1736）**：一个连通无向图存在欧拉回路，当且仅当所有顶点的度数均为偶数。

**证明（必要性）**：沿欧拉回路走一圈，每进入一个顶点必对应一次离开，故每个顶点贡献偶数度数。

**证明（充分性，构造性）**：从任意点出发不断走未走过的边，因为每个点度数为偶数，一旦进入总能离开，最终必然回到起点，得到一条回路。若回路没有覆盖所有边，由于图连通，回路上某点必关联一条未走过的边，从该点出发再走一个回路，然后把两个回路拼接起来。重复此过程即可覆盖所有边。

**定理 2**：连通无向图存在欧拉路径（非回路），当且仅当恰有两个奇度顶点。

**证明思路**：在两个奇度点之间加一条虚拟边，则所有点度数变为偶数，由定理 1 存在欧拉回路；删去虚拟边即得欧拉路径。

## 3. Hierholzer 算法

### 3.1 朴素 DFS 的陷阱

最直接的想法是「从起点 DFS，能走就走，走到底就记录路径」。但这样做会走进死胡同：**回到起点时可能还有边没走**。

经典反例（两个三角形共用一个顶点）：

```
        5
       / \
      2---4
     / \
    1---3

边集：1-2, 2-3, 3-1（三角形 1-2-3）
      2-4, 4-5, 5-2（三角形 2-4-5）
```

更正式地，取边集：

$$
(1,2),\ (2,3),\ (3,1),\ (2,4),\ (4,5),\ (5,2)
$$

所有点的度数都是偶数（1、3、4、5 度数为 2，2 度数为 4），因此必存在欧拉回路。

但如果从 1 出发贪心地走：

```
1 -> 2 -> 3 -> 1
```

此时回到 1，1 已经没有未走过的边了，朴素 DFS 就此结束，可边 $(2,4),(4,5),(5,2)$ 一条都没走。**路径是「合法走法」，但不是欧拉回路。**

正确的做法应当允许「先走旁支、最后再回到主干」，这就需要 Hierholzer 的「回溯时记录」技巧。

### 3.2 正确做法：回溯时记录

Hierholzer 算法的关键：**在 DFS 回溯（即「无路可走」）时把节点加入答案栈**，最后反转栈。

```
procedure Hierholzer(u):
    while u 还有未访问的边 (u, v):
        删除边 (u, v)
        Hierholzer(v)
    答案栈.push(u)
```

为什么正确？「无路可走」时说明 $u$ 的所有边已经被其他回路消化，或者 $u$ 本身就是某段路径的终点。这样递归返回时会把「后走的边」先记录，最终逆序输出恰好是正序路径。

### 3.3 手工模拟

图：$1-2,\ 2-3,\ 3-1,\ 3-4,\ 4-5,\ 5-3$（即一个三角形 1-2-3 与另一个三角形 3-4-5 在 3 处相接）。

```
从 1 开始：
  1 -> 2 -> 3 -> 1（无路可走，push 1）
  回溯到 3，走 3 -> 4 -> 5 -> 3（无路可走，push 3）
  回溯 push 5, 4, 3, 2, 1
栈内容（从底到顶）：1, 3, 5, 4, 3, 2, 1
反转：1, 2, 3, 4, 5, 3, 1
```

对应路径 $1\to2\to3\to4\to5\to3\to1$，恰好是欧拉回路。

### 3.4 复杂度

- 邻接表 + 当前弧优化：每条边只被访问一次，$O(n+m)$；
- 若使用邻接矩阵：$O(n^2)$ 或 $O(nm)$，适用于稠密图或需要按字典序输出时。

## 4. 模板代码

### 4.1 无向图欧拉路径（邻接表 + 当前弧优化）

题目通常要求输出字典序最小的欧拉路径，此时可以把每个点的邻接表排序，并用 `cur[u]` 记录当前扫到哪条边。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100010;
const int MAXM = 200010;

struct Edge {
    int to, id;     // id 用于标记无向边是否已访问
};

vector<Edge> g[MAXN];
bool used[MAXM];    // used[i] 表示第 i 条无向边是否走过
int cur[MAXN];      // 当前弧指针
vector<int> ans;    // 答案栈
int deg[MAXN];

int n, m;

void dfs(int u) {
    for (int &i = cur[u]; i < (int)g[u].size(); ) {
        Edge &e = g[u][i];
        if (used[e.id]) {   // 这条边已经被走过
            ++i;
            continue;
        }
        used[e.id] = true;
        ++i;                // 注意：先移动指针再递归，避免引用失效
        dfs(e.to);
    }
    ans.push_back(u);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> m;
    for (int i = 1; i <= m; ++i) {
        int u, v;
        cin >> u >> v;
        g[u].push_back({v, i});
        g[v].push_back({u, i});
        ++deg[u];
        ++deg[v];
    }
    // 找起点：优先选最小的奇度点，否则选最小的有边的点
    int start = 1;
    for (int i = 1; i <= n; ++i) {
        if (deg[i] & 1) { start = i; break; }
    }
    while (start <= n && deg[start] == 0) ++start;
    if (start > n) { cout << "No\n"; return 0; }

    // 检查奇度点个数
    int odd = 0;
    for (int i = 1; i <= n; ++i) if (deg[i] & 1) ++odd;
    if (odd != 0 && odd != 2) { cout << "No\n"; return 0; }

    dfs(start);
    // 检查是否所有边都被访问（图可能不连通）
    if ((int)ans.size() != m + 1) { cout << "No\n"; return 0; }

    reverse(ans.begin(), ans.end());
    for (int i = 0; i < (int)ans.size(); ++i) {
        if (i) cout << ' ';
        cout << ans[i];
    }
    cout << '\n';
    return 0;
}
```

> 若题目要求字典序最小的欧拉路径，把每个 `g[u]` 按 `to` 升序排序后，算法天然给出字典序最小的方案（正确性来自「回溯时记录」的性质：越晚被回溯的边越靠前）。

### 4.2 有向图欧拉路径

有向图不需要「标记边」，每条边只能按出边方向走一次，因此只要在递归**之前**把当前弧指针推进一格即可（这一步极易写错，若像无向图那样等递归返回后再 `++i`，同一条边会被重复使用导致死循环）。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100010;

vector<int> g[MAXN];
int inDeg[MAXN], outDeg[MAXN];
int cur[MAXN];               // 当前弧：g[u] 中下一条待走的边
vector<int> ans;
int n, m;

void dfs(int u) {
    while (cur[u] < (int)g[u].size()) {
        int v = g[u][cur[u]++];   // 先取边、再推进指针，保证每条边只走一次
        dfs(v);
    }
    ans.push_back(u);             // 回溯时记录
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> m;
    for (int i = 1; i <= m; ++i) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        ++outDeg[u];
        ++inDeg[v];
    }
    int start = -1, cntStart = 0, cntEnd = 0;
    for (int i = 1; i <= n; ++i) {
        int d = outDeg[i] - inDeg[i];
        if (d == 1) { ++cntStart; start = i; }
        else if (d == -1) { ++cntEnd; }
        else if (d != 0) { cout << "No\n"; return 0; }
    }
    if (!((cntStart == 0 && cntEnd == 0) || (cntStart == 1 && cntEnd == 1))) {
        cout << "No\n";
        return 0;
    }
    if (start == -1) {          // 欧拉回路：任选有出边的点
        for (int i = 1; i <= n; ++i) {
            if (outDeg[i] > 0) { start = i; break; }
        }
    }
    if (start == -1) {          // 没有边
        cout << "No\n";
        return 0;
    }
    for (int i = 1; i <= n; ++i) sort(g[i].begin(), g[i].end());  // 字典序
    dfs(start);
    if ((int)ans.size() != m + 1) { cout << "No\n"; return 0; }   // 图不连通
    reverse(ans.begin(), ans.end());                              // 逆序输出
    for (int i = 0; i < (int)ans.size(); ++i) {
        if (i) cout << ' ';
        cout << ans[i];
    }
    cout << '\n';
    return 0;
}
```

### 4.3 欧拉回路计数（BEST 定理，了解）

有向欧拉图的欧拉回路条数（以某个点为起点、边编号不同视为不同）由 **BEST 定理** 给出：

$$
\operatorname{ec}(G) = t_w(G)\cdot \prod_{v\in V}\bigl(\deg^+(v)-1\bigr)!
$$

其中 $t_w(G)$ 是以任意点为根的内向生成树个数（可用矩阵树定理计算）。无向图没有这么简洁的公式，一般用 DP 或矩阵树相关方法。

## 5. 经典例题

### 例题 1：欧拉路径模板（Luogu P7771 【模板】欧拉路径）

**题目大意**：给定 $n$ 个点、$m$ 条边的有向图，求字典序最小的欧拉路径。若不存在输出 `No`。

**思路**：按第 2.2 节判定入度出度条件，按第 3 节 Hierholzer 算法求解。若存在欧拉回路，从任意有出边的点出发；否则从唯一的「出度比入度大 1」的点出发。对每个点的邻接表排序，保证字典序最小。

**复杂度**：$O(m\log m)$（排序）+ $O(n+m)$（DFS）。

---

### 例题 2：欧拉回路模板（Luogu P2731 [USACO3.3] 骑马修栅栏 Riding the Fences）

**题目大意**：给定 $m$ 条无向边（栅栏），求一条经过每条边恰好一次的路径，要求字典序最小，输出经过的顶点编号。

**思路**：无向图欧拉路径，注意：

1. 可能存在重边，用边编号标记是否访问；
2. 起点选最小的奇度点，没有奇度点则选最小的有边点；
3. 对邻接表排序后用 Hierholzer 求路径。

**复杂度**：$O(m\log m)$。

```cpp
// 核心片段：带边编号的无向图 DFS
void dfs(int u) {
    for (int &i = cur[u]; i < (int)g[u].size(); ) {
        int id = g[u][i].id, v = g[u][i].to;
        if (used[id]) { ++i; continue; }
        used[id] = true;
        ++i;
        dfs(v);
    }
    ans.push_back(u);
}
```

### 例题 3：单词接龙（Luogu P1341 无序字母对）

**题目大意**：给定 $n$ 个字母对（每个字母对由两个不同字母组成，可重复），要求把所有字母对首尾相接成一个字符串，使前一个字母对的后一个字母等于后一个字母对的前一个字母。求字典序最小的方案。

**思路**：把每个字母看成点，每个字母对看成一条无向边。问题转化为「求字典序最小的欧拉路径」。

- 统计每个字母的度数，奇度点只能是 $0$ 或 $2$ 个，否则无解；
- 起点选最小的奇度点，否则选最小的有边点；
- Hierholzer + 回溯记录，邻接表排序，输出时反转。

**复杂度**：$O(n\log n + 26^2)$。

---

### 例题 4：重新安排行程（LeetCode 332）

**题目大意**：给定一份航线列表 `[from, to]`，表示从 `from` 飞往 `to`。所有航线都属于同一个人，且他恰好使用所有机票一次。求行程字典序最小的路线，起点必须是 `"JFK"`。

**思路**：把机场看成点、航线看成有向边，问题即「从 JFK 出发的字典序最小欧拉路径」。由于题目保证至少存在一种合理行程，直接：

1. 建图并对每个点的邻接表排序；
2. Hierholzer 从 `"JFK"` 开始；
3. 回溯记录，最后反转。

**复杂度**：$O(E\log E)$，$E$ 为航线数。

## 6. 易错点

1. **忘记判定连通性**：度条件满足但图不连通时仍然无解。DFS 后检查 `ans.size() == m + 1`。
2. **无向图重边处理**：不能简单用 `vis[v]` 标记点，要用边编号标记，否则重边会被误判为已访问。
3. **当前弧指针引用失效**：`for (int &i = cur[u]; ...)` 中递归调用可能修改 `cur[u]`（如果是同一个点的不同递归层），应先 `++i` 再递归，或者不用引用。
4. **起点选择错误**：有欧拉路径时起点必须是奇度点（无向）或出度比入度大 1 的点（有向），否则会漏边。
5. **输出顺序**：Hierholzer 记录的是逆序，最后必须 `reverse`。
6. **有向图弱连通**：有向图只需要弱连通，不需要强连通；但判定时必须把边当无向做一次 DFS。
7. **孤立点干扰**：选起点时跳过度为 0 的点。
8. **多组数据**：清空邻接表、度数、`used`、`cur`、`ans`。

## 7. 练习建议

由易到难：

1. **入门**：Luogu P7771 【模板】欧拉路径 —— 熟悉判定与 Hierholzer；
2. **无向图模板**：Luogu P2731 骑马修栅栏 —— 处理重边与字典序；
3. **字母建模**：Luogu P1341 无序字母对 —— 体会「建模成图」的过程；
4. **网格图**：Luogu P1127 词链 —— 单词接龙变体；
5. **混合图**：Luogu P1333 瑞瑞的木棍 —— 无向图欧拉路径判定练习；
6. **欧拉回路应用**：Codeforces 508D Tanya and Password —— 有向图欧拉路径 + 字符串哈希；
7. **进阶**：Luogu P3520 [POI2011] SMI-Garbage —— 欧拉回路与构造结合；
8. **计数**：BEST 定理相关题目（如 Luogu P5807 Which Dreamed It）—— 需要矩阵树定理基础。

学习建议：

- 先手画图，模拟 Hierholzer 的回溯过程，理解为什么「回溯时记录」是正确的；
- 写完模板后自己造几组数据（不连通、重边、自环、只有环）验证；
- 欧拉路径的题目建模往往比算法本身更难，注意识别「边是元素、点是连接关系」的模型。
