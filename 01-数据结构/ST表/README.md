# ST 表（Sparse Table，稀疏表）

> 一句话概括：**ST 表用倍增预处理出所有长度为 $2^k$ 的区间的答案，再用两次查询覆盖任意区间，实现 $O(1)$ 静态区间查询**，代价是 $O(n \log n)$ 的预处理时间和空间，且**不支持修改**。

## 1. 什么是 ST 表

### 1.1 问题引入

给定长度为 $n$ 的**静态**数组 $a$，$m$ 次询问区间 $[l,r]$ 的最大值（或最小值、gcd 等），要求单次询问尽可能快。

- 暴力：$O(n)$ 每次，太慢；
- 线段树：$O(\log n)$ 每次，够用但要建树、常数不小；
- **ST 表**：$O(n\log n)$ 预处理，**$O(1)$ 查询**，简单暴力，静态问题的最优选择。

### 1.2 一句话本质

**预处理所有长度为 $2^k$ 的区间的答案，查询时用两个这样的区间「拼」出目标区间。**

```
区间 [2, 9]，长度 8：
用两个长度为 8 的区间覆盖：
[2, 9]  ← 完全覆盖（恰好）

区间 [2, 8]，长度 7：
用两个长度为 4 的区间覆盖：
  [2, 5]
     [5, 8]
  中间 5 被重复覆盖了一次
```

关键：**允许重复覆盖，只要不遗漏**。最大值、最小值、gcd 都满足「重复算不影响结果」，这就是 ST 表的适用前提。

## 2. 核心原理：倍增与区间覆盖

### 2.1 状态定义

设 $f[i][k]$ 表示从下标 $i$ 开始、长度为 $2^k$ 的区间 $[i,\ i+2^k-1]$ 的答案（最值）。

```
f[i][0]   = a[i]                      长度 1
f[i][k]   = max(f[i][k-1], f[i+2^{k-1}][k-1])   长度 2^k
```

即：**长度为 $2^k$ 的区间 = 左半段 + 右半段**，两段长度都是 $2^{k-1}$。

```
f[i][k] 覆盖 [i, i+2^k-1]
    ├── f[i][k-1] 覆盖 [i, i+2^{k-1}-1]
    └── f[i+2^{k-1}][k-1] 覆盖 [i+2^{k-1}, i+2^k-1]
```

### 2.2 查询的巧妙之处

设查询区间长度 $len = r-l+1$，取 $k = \lfloor \log_2 len \rfloor$，则 $2^k \le len < 2^{k+1}$。

用两个长度为 $2^k$ 的区间：

- 左区间：从 $l$ 开始，$[l,\ l+2^k-1]$；
- 右区间：从 $r-2^k+1$ 开始，$[r-2^k+1,\ r]$。

**这两个区间的并一定覆盖 $[l,r]$**（因为 $2 \cdot 2^k \ge len$），且都完全落在 $[l,r]$ 内。

```
len = 7, k = 2 (2^k = 4)：
l=2, r=8
左：[2, 5]
右：[5, 8]
并集 [2,8] ✓（5 重复，不影响 max）
```

于是：

$$
\text{ans}(l,r) = \max\big(f[l][k],\ f[r-2^k+1][k]\big)
$$

**$O(1)$ 完成**。

### 2.3 复杂度

| 阶段 | 时间 | 空间 |
|---|---|---|
| 预处理 | $O(n \log n)$ | $O(n \log n)$ |
| 单次查询 | $O(1)$ | $O(1)$ |

## 3. 预处理

### 3.1 预处理 log 表

查询时要算 $\lfloor \log_2 len \rfloor$，用 `log2()` 有精度问题且慢。预处理：

```cpp
int lg[N];                  // lg[i] = floor(log2(i))
lg[1] = 0;
for (int i = 2; i <= n; ++i) lg[i] = lg[i >> 1] + 1;
```

### 3.2 预处理 f 表

```cpp
for (int i = 1; i <= n; ++i) f[i][0] = a[i];      // 长度 1

for (int k = 1; (1 << k) <= n; ++k)                // 枚举区间长度 2^k
    for (int i = 1; i + (1 << k) - 1 <= n; ++i)    // 枚举起点，注意不越界
        f[i][k] = max(f[i][k - 1], f[i + (1 << (k - 1))][k - 1]);
```

**注意循环顺序**：外层枚举 $k$，内层枚举 $i$。因为 $f[i][k]$ 依赖 $f[\cdot][k-1]$，必须先算完所有长度为 $2^{k-1}$ 的区间。

### 3.3 空间优化

$f$ 是二维数组 `f[N][LOG]`，$N = 10^5$、$LOG = 17$ 时约 $1.7 \times 10^6$ 个 `int`，约 7 MB，可以接受。

若内存紧张，可以把 `f[k][i]` 写成「按 $k$ 分行」的形式，便于缓存：

```cpp
int f[LOG][N];              // f[k][i]：从 i 开始长度 2^k 的区间答案
```

## 4. 查询

```cpp
int queryMax(int l, int r) {
    int k = lg[r - l + 1];                 // floor(log2(len))
    return max(f[l][k], f[r - (1 << k) + 1][k]);
}
```

**注意**：右区间的起点是 $r - 2^k + 1$，不是 $r - 2^k$。这是最常见的 off-by-one 错误。

## 5. 完整模板代码

一份可直接编译的 ST 表模板（区间最大值 + 区间最小值 + 区间 gcd）：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
const int LOG = 18;                 // 2^17 > 1e5

int n, m;
int a[N];
int lg[N];

// 三张表分别维护 最大值 / 最小值 / gcd
int mx[LOG][N];
int mn[LOG][N];
int gc[LOG][N];

int gcdInt(int x, int y) {
    while (y) { int t = x % y; x = y; y = t; }
    return x;
}

void build() {
    lg[1] = 0;
    for (int i = 2; i <= n; ++i) lg[i] = lg[i >> 1] + 1;

    for (int i = 1; i <= n; ++i) {              // 长度 2^0 = 1
        mx[0][i] = mn[0][i] = gc[0][i] = a[i];
    }

    for (int k = 1; (1 << k) <= n; ++k) {
        int half = 1 << (k - 1);
        int len  = 1 << k;
        for (int i = 1; i + len - 1 <= n; ++i) {
            mx[k][i] = max(mx[k - 1][i], mx[k - 1][i + half]);
            mn[k][i] = min(mn[k - 1][i], mn[k - 1][i + half]);
            gc[k][i] = gcdInt(gc[k - 1][i], gc[k - 1][i + half]);
        }
    }
}

int queryMax(int l, int r) {
    int k = lg[r - l + 1];
    return max(mx[k][l], mx[k][r - (1 << k) + 1]);
}

int queryMin(int l, int r) {
    int k = lg[r - l + 1];
    return min(mn[k][l], mn[k][r - (1 << k) + 1]);
}

int queryGcd(int l, int r) {
    int k = lg[r - l + 1];
    return gcdInt(gc[k][l], gc[k][r - (1 << k) + 1]);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m;
    for (int i = 1; i <= n; ++i) cin >> a[i];
    build();

    while (m--) {
        int l, r;
        cin >> l >> r;
        cout << queryMax(l, r) << ' ' << queryMin(l, r) << ' ' << queryGcd(l, r) << '\n';
    }
    return 0;
}
```

### 5.1 支持任意满足结合律且幂等的运算

把 `max` 换成 `min` / `gcd` / `lcm` / `&` / `|` 都可以，因为它们都满足：

- **结合律**：$(a \star b) \star c = a \star (b \star c)$；
- **幂等性**：$a \star a = a$。

只有满足这两条，才能用「两个区间重复覆盖」的办法求答案。

---

## 6. 为什么只适用于「可重复贡献」的信息

### 6.1 幂等性（idempotence）

若运算满足 $x \star x = x$，则区间被重复计算不影响结果。例如：

- $\max(5, 5) = 5$ ✓
- $\gcd(6, 6) = 6$ ✓
- $5 + 5 = 10 \ne 5$ ✗（求和不行！）

**所以 ST 表不能直接求区间和。**

### 6.2 求区间和怎么办

方法一：用前缀和（$O(n)$ 预处理，$O(1)$ 查询，同样不支持修改）；
方法二：用线段树 / 树状数组（支持修改）。

### 6.3 与线段树的对比

| 维度 | ST 表 | 线段树 |
|---|---|---|
| 预处理 | $O(n\log n)$ | $O(n)$ |
| 查询 | $O(1)$ | $O(\log n)$ |
| 修改 | ❌ 不支持 | ✅ $O(\log n)$ |
| 空间 | $O(n\log n)$ | $O(n)$ |
| 代码 | 极短 | 较长 |
| 适用信息 | 幂等可重复贡献 | 任意可合并 |

**结论**：静态、幂等 → ST 表；动态、或需要求和 → 线段树 / 树状数组。

## 7. 进阶应用

### 7.1 二维 ST 表

对矩阵求子矩形的最大值。定义 $f[kx][ky][i][j]$ 表示左上角 $(i,j)$、高 $2^{kx}$、宽 $2^{ky}$ 的矩形最大值，用四个小块合并，查询时也用四块覆盖。预处理 $O(nm\log n\log m)$，查询 $O(1)$。

### 7.2 ST 表 + 二分（「倍增」求最远边界）

利用 ST 表 $O(1)$ 查询的优势，可以二分找「满足条件的最远右端点」。例如：

- 求最长的、最大值减最小值不超过 $K$ 的子段；
- 求区间内第一个 $\ge x$ 的位置。

总复杂度 $O(n\log n)$。

### 7.3 ST 表求 LCA

在欧拉序上建 ST 表，查询区间深度最小值对应的节点就是 LCA。预处理 $O(n\log n)$，查询 $O(1)$。

```cpp
// 伪代码：欧拉序 + 深度 ST 表
int lca(int u, int v) {
    int l = first[u], r = first[v];
    if (l > r) swap(l, r);
    int k = lg[r - l + 1];
    int x = st[k][l], y = st[k][r - (1 << k) + 1];
    return depth[x] < depth[y] ? x : y;
}
```

### 7.4 稀疏表 + 分块（O(n) 预处理 O(1) 查询）

把数组分成大小为 $B$ 的块，块内 RMQ 用「单调栈 + 笛卡尔树」等技巧 $O(n)$ 预处理，块间用 ST 表，可做到 $O(n)$ 预处理、$O(1)$ 查询（Fischer-Heun 结构）。竞赛中较少手写。

## 8. 经典例题

### 8.1 例题一：区间最大值（模板题）

**题意**：给出 $n$ 个数，$m$ 次询问，每次问 $[l,r]$ 的最大值。$n \le 10^5$，$m \le 10^6$。

**思路**：直接套用 ST 表。

**复杂度**：预处理 $O(n\log n)$，每次查询 $O(1)$，总 $O(n\log n + m)$。$m$ 很大时优势明显。

### 8.2 例题二：区间内最大值与最小值之差

**题意**：给定序列，多次询问区间 $[l,r]$ 内最大值与最小值之差。

**思路**：同时维护 `mx` 和 `mn` 两张 ST 表，查询后相减。

**复杂度**：$O(n\log n + m)$。

### 8.3 例题三：最长「差值不超过 K」的子段

**题意**：给定序列和整数 $K$，求最长的子段 $[l,r]$，使得区间最大值减最小值 $\le K$。

**思路**：固定左端点 $l$，随着 $r$ 增大，$\max - \min$ 单调不减，因此可以**双指针 + ST 表**：

- 右指针不断右移，用 ST 表 $O(1)$ 判断当前区间是否合法；
- 不合法时左指针右移。

**复杂度**：$O(n \log n)$（预处理）+ $O(n)$（双指针）。

```cpp
int l = 1, ans = 0;
for (int r = 1; r <= n; ++r) {
    while (l <= r && queryMax(l, r) - queryMin(l, r) > K) ++l;
    ans = max(ans, r - l + 1);
}
```

### 8.4 例题四：静态区间 gcd 查询

**题意**：多次询问区间 $[l,r]$ 的所有数的最大公约数。

**思路**：gcd 满足结合律与幂等性（$\gcd(x,x)=x$），可以直接建 ST 表。

**复杂度**：$O(n\log n + m\log V)$，其中 $\log V$ 来自单次 gcd 运算。

## 9. 易错点

1. **右端点写错**：查询右区间起点是 $r-2^k+1$，不是 $r-2^k$，也不是 $r-2^k-1$。
2. **`lg` 数组没预处理**：直接用 `log2()` 会有精度误差（如 `log2(8)` 可能得到 2.9999）。
3. **循环顺序反了**：必须先枚举 $k$，再枚举 $i$；反过来会用到未计算的状态。
4. **越界**：内层循环条件是 `i + (1 << k) - 1 <= n`，不是 `i + (1 << k) <= n`。
5. **`1 << k` 溢出**：$k$ 较大时（$k \ge 31$）会溢出 `int`，用 `1LL << k` 或限制 $k \le 17$。
6. **空间开小**：`LOG` 要满足 $2^{LOG-1} \ge n$，$n = 10^5$ 时 `LOG = 18` 足够。
7. **用于求区间和**：ST 表**不支持**求和（不满足幂等性），会算重。
8. **试图单点修改**：ST 表不支持修改，必须重建（$O(n\log n)$）。
9. **多组数据不清空**：`lg` 数组和 `f` 表都要重新计算。
10. **`gcd` 传参为 0**：`gcd(0, x) = x`，但要注意负数取绝对值。
