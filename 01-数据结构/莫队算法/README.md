# 莫队算法（Mo's Algorithm）

> 一句话概括：**莫队把全部询问离线、按「左端点所在块、右端点」排序，用两个指针在序列上滑动维护答案**，把 $O(nm)$ 的暴力区间查询优化到 $O(n\sqrt{m})$，是离线区间查询问题的万能暴力。

## 1. 什么是莫队

### 1.1 问题引入

给定长度为 $n$ 的序列和 $m$ 个询问，每个询问是区间 $[l,r]$，要求回答某种**只与区间内元素有关**的问题，例如：

- 区间内不同数字的个数；
- 区间众数；
- 区间内出现次数为 $k$ 的数有多少个。

这类问题往往**没有简单的合并方式**（不能用线段树），但有一个共同点：**可以从一个区间的答案快速推导出相邻区间的答案**。

例如「不同数字个数」：区间 $[l,r]$ 向右扩展到 $[l,r+1]$，只需要看 $a_{r+1}$ 是否为第一次出现；向左收缩也只需看某数的计数是否降到 0。

### 1.2 暴力做法

对每个询问，用两个指针 $L, R$ 表示当前区间，通过移动指针从上一个询问的区间「滑」到当前询问：

```
上一个询问 [2, 5]，当前询问 [4, 7]：
L: 2 → 4（右移两次，删掉 a[2]、a[3]）
R: 5 → 7（右移两次，加入 a[6]、a[7]）
```

如果询问顺序不好，指针总移动量可能达到 $O(nm)$。**莫队的核心就是通过排序，让指针总移动量降到 $O(n\sqrt{m})$。**

### 1.3 一条时间线

```
排序前：[1,n], [n,1], [2,n-1], ...
        指针来回横跳，$O(nm)$

排序后：按块分组，块内右端点递增
        左指针在块内小幅移动，右指针一路向右
```

## 2. 核心思想：指针滑动

### 2.1 维护什么

维护一个「当前区间」$[L,R]$ 和它的答案，以及支撑答案的统计量。以「不同数字个数」为例：

```cpp
int cnt[MAXV];        // 每个值在当前区间出现的次数
int curAns = 0;       // 当前区间不同数字个数

void add(int pos) {   // 把 a[pos] 加入区间
    if (cnt[a[pos]] == 0) ++curAns;
    ++cnt[a[pos]];
}

void remove(int pos) { // 把 a[pos] 移出区间
    --cnt[a[pos]];
    if (cnt[a[pos]] == 0) --curAns;
}
```

### 2.2 指针移动

```cpp
int L = 1, R = 0;     // 初始空区间
while (L > ql) add(--L);      // 左指针左移
while (R < qr) add(++R);      // 右指针右移
while (L < ql) remove(L++);   // 左指针右移
while (R > qr) remove(R--);   // 右指针左移
```

**顺序很重要**：一般先扩展、后收缩，避免区间变空导致 `remove` 越界（对具体问题要具体分析）。

### 2.3 为什么能快

关键观察：**从左端点所在块 $b$ 到 $b+1$，右端点整体单调递增**，于是：

- **左指针**：每个询问内移动不超过 $O(\sqrt{n})$（同一块内），跨块时最多 $O(n)$，总 $O(m\sqrt{n} + n)$；
- **右指针**：在同一个块内单调递增，总移动 $O(n)$；共有 $\sqrt{n}$ 个块，总 $O(n\sqrt{n})$。

两部分都是 $O(n\sqrt{n})$，比暴力 $O(nm)$ 快得多。

## 3. 排序策略与复杂度证明

### 3.1 标准排序

块大小 $B = \sqrt{n}$，询问按：

- **第一关键字**：左端点所在块 `l / B`；
- **第二关键字**：右端点 `r`（奇数块降序、偶数块升序，可优化常数）。

```cpp
int blockSize;

bool cmp(const Query& x, const Query& y) {
    int bx = x.l / blockSize, by = y.l / blockSize;
    if (bx != by) return bx < by;
    return (bx & 1) ? (x.r > y.r) : (x.r < y.r);   // 奇偶优化
}
```

**奇偶优化（Hilbert 序的简化版）**：偶数块的 `r` 升序、奇数块降序，让右指针在块之间「折返」的距离更短，常数约减半。

### 3.2 复杂度证明

设块大小 $B$，块数 $n/B$。

**左指针移动**：

- 每个询问内，左端点移动不超过块长 $B$，共 $m$ 个询问：$O(mB)$；
- 跨块时最多移动 $O(n)$，共 $O(n/B)$ 次：$O(n^2/B)$。

**右指针移动**：

- 每个块内，右端点单调，最多移动 $O(n)$；共 $n/B$ 个块：$O(n^2/B)$。

总复杂度：

$$
O\left(mB + \frac{n^2}{B}\right)
$$

取 $B = \dfrac{n}{\sqrt{m}}$ 时最优，得 $O(n\sqrt{m})$。当 $m = n$ 时即 $O(n\sqrt{n})$。

> 若 $m$ 与 $n$ 同阶，直接取 $B = \sqrt{n}$ 即可。

### 3.3 值域很大怎么办

若 $a_i$ 值域是 $10^9$，`cnt` 数组开不下，需要**离散化**（见[离散化](../../00-语言与基础/离散化/README.md)）：

```cpp
sort(v.begin(), v.end());
v.erase(unique(v.begin(), v.end()), v.end());
for (int i = 1; i <= n; ++i)
    a[i] = lower_bound(v.begin(), v.end(), a[i]) - v.begin() + 1;
```

## 4. 完整模板代码

以「区间不同数字个数」为例，可直接编译：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;

int n, m;
int a[MAXN];
int cnt[MAXN];              // 值出现次数（离散化后）
int ans[MAXN];              // 每个询问的答案
int curAns = 0;
int blockSize;

struct Query {
    int l, r, id;
} q[MAXN];

bool cmp(const Query& x, const Query& y) {
    int bx = x.l / blockSize, by = y.l / blockSize;
    if (bx != by) return bx < by;
    return (bx & 1) ? (x.r > y.r) : (x.r < y.r);   // 奇偶优化
}

void add(int pos) {
    if (cnt[a[pos]] == 0) ++curAns;
    ++cnt[a[pos]];
}

void remove(int pos) {
    --cnt[a[pos]];
    if (cnt[a[pos]] == 0) --curAns;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m;
    vector<int> vals;
    for (int i = 1; i <= n; ++i) { cin >> a[i]; vals.push_back(a[i]); }

    // 离散化
    sort(vals.begin(), vals.end());
    vals.erase(unique(vals.begin(), vals.end()), vals.end());
    for (int i = 1; i <= n; ++i)
        a[i] = (int)(lower_bound(vals.begin(), vals.end(), a[i]) - vals.begin()) + 1;

    for (int i = 1; i <= m; ++i) {
        cin >> q[i].l >> q[i].r;
        q[i].id = i;
    }

    blockSize = max(1, (int)(n / sqrt(max(1, m))));   // 常用取法
    sort(q + 1, q + m + 1, cmp);

    int L = 1, R = 0;                                 // 当前空区间
    for (int i = 1; i <= m; ++i) {
        int ql = q[i].l, qr = q[i].r;
        while (L > ql) add(--L);
        while (R < qr) add(++R);
        while (L < ql) remove(L++);
        while (R > qr) remove(R--);
        ans[q[i].id] = curAns;
    }

    for (int i = 1; i <= m; ++i) cout << ans[i] << '\n';
    return 0;
}
```

### 4.1 `add` 与 `remove` 的可扩展性

莫队的模板是固定的，**每题只需要改 `add` / `remove` 两个函数和 `curAns` 的含义**。这是它最大的优势：

| 问题 | `add` / `remove` 维护什么 |
|---|---|
| 区间不同数个数 | 每个值的出现次数 + 非零个数 |
| 区间众数 | 每个值的次数 + 次数桶 |
| 区间内出现次数 $\ge k$ 的数的个数 | 次数桶 + 后缀和 |
| 区间内 $\gcd$ / 异或和 | 直接合并 / 删除需额外结构 |

## 5. 进阶一：带修莫队

### 5.1 问题

在莫队的基础上增加**单点修改**操作：询问之间可能夹着「把 $a_p$ 改成 $v$」。

### 5.2 核心思想：加一维时间

把每个询问看成三维点 $(l, r, t)$，其中 $t$ 是「已经执行了多少次修改」。排序关键字：

1. 左端点所在块；
2. 右端点所在块；
3. 时间 $t$。

指针也增加一个「时间指针」，修改时把当前位置的值改掉，回退时改回来。

```cpp
struct Query { int l, r, t, id; };
struct Change { int pos, oldVal, newVal; };
```

### 5.3 块大小与复杂度

带修莫队的块大小取 $n^{2/3}$，总复杂度 $O(n^{5/3})$。

```cpp
bool cmp(const Query& x, const Query& y) {
    int bx = x.l / B, by = y.l / B;
    if (bx != by) return bx < by;
    int cx = x.r / B, cy = y.r / B;
    if (cx != cy) return (bx & 1) ? (cx > cy) : (cx < cy);
    return (bx & 1) ? (x.t > y.t) : (x.t < y.t);
}
```

### 5.4 修改的执行

```cpp
void applyChange(int idx, int dir) {   // dir = 1 执行，-1 撤销
    Change& c = chg[idx];
    if (c.pos >= L && c.pos <= R) {    // 该位置在当前区间内才影响答案
        remove(c.pos);
    }
    a[c.pos] = (dir == 1) ? c.newVal : c.oldVal;
    if (c.pos >= L && c.pos <= R) {
        add(c.pos);
    }
}
```

## 6. 进阶二：树上莫队与回滚莫队

### 6.1 树上莫队

把树拍平成**欧拉序**（每个点进出各记一次），路径 $(u,v)$ 的询问转化为欧拉序上的一个区间，再用普通莫队处理。出现两次的点表示「不在路径上」，需要特殊处理。

### 6.2 回滚莫队

有些问题的 `remove` 很难写（如维护最大值，删除后无法快速恢复），但 `add` 很简单。此时用**回滚莫队**：

- 按左端点分块，块内询问按右端点排序；
- 对于左端点在当前块内的询问，先把右指针扩展到 $r$（只加不减）；
- 左端点部分临时暴力添加，记录答案后**回滚**（撤销这些添加）。

这样只需要支持 `add` 和「回滚到某个检查点」，不需要 `remove`。

### 6.3 二次离线莫队

当单次 `add` / `remove` 本身就需要 $O(\log n)$（如维护逆序对），可以用二次离线把复杂度从 $O(n\sqrt{n}\log n)$ 降到 $O(n\sqrt{n})$。这是进阶技巧，竞赛中较少手写。

## 7. 经典例题

### 7.1 例题一：区间不同数字个数（模板题）

**题意**：给定长度为 $n$ 的序列，$m$ 次询问 $[l,r]$ 中有多少个不同的数。$n,m \le 10^5$。

**思路**：直接套用第 4 节模板。

**复杂度**：$O(n\sqrt{m})$，$n = m = 10^5$ 时约 $3 \times 10^7$ 次操作。

### 7.2 例题二：区间众数

**题意**：多次询问区间众数（出现次数最多的数）。

**思路**：莫队维护 `cnt[值]` 和 `numCnt[次数]`（出现次数为 $k$ 的值有多少个），同时维护当前最大次数 `maxCnt`：

```cpp
void add(int pos) {
    int v = a[pos];
    ++cnt[v];
    ++numCnt[cnt[v]];
    maxCnt = max(maxCnt, cnt[v]);
}

void remove(int pos) {
    int v = a[pos];
    --numCnt[cnt[v]];
    if (cnt[v] == maxCnt && numCnt[cnt[v]] == 0) --maxCnt;
    --cnt[v];
}
```

**复杂度**：$O(n\sqrt{m})$。注意「众数出现的具体值」还需另维护，或改为求众数的出现次数。

### 7.3 例题三：带修区间不同数字个数

**题意**：给定序列，支持单点修改与区间不同数字个数查询。$n,m \le 10^5$。

**思路**：带修莫队，块大小 $n^{2/3}$，见第 5 节。

**复杂度**：$O(n^{5/3})$，约 $5 \times 10^7$ 次操作。

### 7.4 例题四：区间内出现次数为 $k$ 的数

**题意**：多次询问 $[l,r]$ 中，有多少个数的出现次数恰好为 $k$。

**思路**：莫队维护 `cnt[值]` 与 `numCnt[次数]`，答案就是 `numCnt[k]`。`add` / `remove` 时同步更新 `numCnt`。

**复杂度**：$O(n\sqrt{m})$。

## 8. 易错点

1. **块大小写死**：应写成 `max(1, n / sqrt(m))` 或 `sqrt(n)`，$n$ 与 $m$ 差距大时块大小要调整。
2. **排序比较函数写错**：先比左端点块，再比右端点；奇偶优化别忘了 `(bx & 1) ?` 的符号。
3. **指针移动顺序**：先扩展后收缩；若先收缩可能让区间变空，`remove` 访问非法位置。
4. **初始区间**：`L = 1, R = 0` 表示空区间；不要写成 `L = R = 1`。
5. **离散化遗漏**：值域大时必须离散化，否则 `cnt` 数组越界。
6. **`remove` 顺序**：先减 `cnt` 再判断是否为 0，顺序反了会多减 `curAns`。
7. **多组数据不清空**：`cnt`、`numCnt`、`curAns` 都要重置。
8. **答案数组按 `id` 存**：询问被排序后顺序变了，必须用 `ans[q[i].id]` 存答案。
9. **带修莫队忘记时间维**：修改操作要按时间顺序执行或回退，不能直接跳到目标版本。
10. **卡常**：莫队常数较大，用快读、`register`、减少函数调用、`#pragma GCC optimize` 等手段优化。

## 9. 复杂度汇总

| 变种 | 块大小 | 时间 | 空间 |
|---|---|---|---|
| 普通莫队 | $\sqrt{n}$ | $O(n\sqrt{m})$ | $O(n)$ |
| 带修莫队 | $n^{2/3}$ | $O(n^{5/3})$ | $O(n)$ |
| 树上莫队 | $\sqrt{n}$ | $O(n\sqrt{n})$ | $O(n)$ |
| 回滚莫队 | $\sqrt{n}$ | $O(n\sqrt{m})$ | $O(n)$ |
| 二次离线莫队 | $\sqrt{n}$ | $O(n\sqrt{n})$ | $O(n)$ |

### 9.1 与其它做法对比

| 问题 | 莫队 | 线段树 | 主席树 |
|---|---|---|---|
| 区间不同数个数 | ✅ $O(n\sqrt{n})$ 在线/离线均可 | ❌ 无简单合并 | ✅ $O(n\log n)$ 离线 |
| 区间众数 | ✅ $O(n\sqrt{n})$ | ❌ | ✅ 较复杂 |
| 区间第 $k$ 小 | ⚠️ 需要值域分块，较慢 | ❌ | ✅ $O(n\log n)$ |
| 带修改 | ✅ 带修莫队 | ✅ 若信息可合并 | ❌ |

**结论**：莫队是「离线 + 可快速增删」问题的通用解法，代码短、思维简单；但复杂度只有 $O(n\sqrt{n})$，能线段树/主席树时优先用更优解。
