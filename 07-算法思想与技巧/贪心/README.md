# 贪心（Greedy）

## 1. 贪心的基本思想

**贪心算法**在每一步选择中都采取**当前状态下最好或最优**的选择，从而希望得到全局最优。

**与 DP 的区别**：

- DP 会考虑所有子问题，保证全局最优；
- 贪心只考虑当前，不做回溯，速度快但**不一定正确**。

**能用贪心的条件**：

1. **贪心选择性质**：局部最优能推出全局最优；
2. **最优子结构**：问题的最优解包含子问题的最优解。

## 2. 贪心的正确性证明

### 2.1 交换论证（Exchange Argument）

**思路**：假设存在一个最优解与贪心解不同，通过交换元素，证明可以变成贪心解而不变差。

**例子**：区间调度问题——按结束时间排序，每次选最早结束的。

**证明**：设贪心选的第一个区间是 $g_1$，最优解选的第一个是 $o_1$。因为 $g_1$ 结束最早，所以 $end(g_1) \le end(o_1)$，用 $g_1$ 替换 $o_1$ 不会影响后续选择，最优解不变差。

### 2.2 归纳法

证明每一步贪心后，剩下的问题仍然是最优子问题。

### 2.3 反证法

假设贪心不是最优，推出矛盾。

## 3. 经典贪心模型

### 3.1 区间调度（最多不重叠区间）

**题意**：给 $n$ 个区间，选尽量多的不重叠区间。

**贪心**：按**结束时间**排序，依次选不与已选重叠的。

```cpp
sort(a, a + n, [](auto& x, auto& y) { return x.r < y.r; });
int cnt = 0, last = -INF;
for (int i = 0; i < n; ++i) {
    if (a[i].l >= last) { ++cnt; last = a[i].r; }
}
```

### 3.2 区间覆盖

**题意**：用最少的区间覆盖 $[1, n]$。

**贪心**：每次选能覆盖当前位置且右端点最远的区间。

### 3.3 哈夫曼编码 / 合并果子

**贪心**：每次合并最小的两个（用堆）。

### 3.4 排队接水

**题意**：$n$ 个人排队接水，每个人需要 $t_i$ 时间，求最小平均等待时间。

**贪心**：按 $t_i$ 从小到大排序。

### 3.5 田忌赛马

**题意**：双方各有 $n$ 匹马，比赛胜负规则，求最多胜场。

**贪心**：排序后双指针，用最弱的马消耗对方最强的马。

### 3.6 活动选择（带权）

如果区间带权，贪心失效，要用 DP（加权区间调度）。

## 4. 反悔贪心

**问题**：有些贪心决策可能选错，需要「反悔」。

**做法**：用堆维护已选元素，发现更优选择时，弹出最差的，加入新的。

### 4.1 例题：股票买卖（最多交易 $k$ 次）

用堆维护所有收益，每次取最大的。

### 4.2 例题：任务调度

**题意**：每个任务有截止时间和收益，求最大总收益。

**贪心**：按截止时间排序，用堆维护已选任务；若当前任务收益更高，替换堆顶。

```cpp
sort(tasks.begin(), tasks.end(), [](auto& a, auto& b) { return a.d < b.d; });
priority_queue<int, vector<int>, greater<int>> pq;   // 小根堆存收益
for (auto& t : tasks) {
    pq.push(t.w);
    if ((int)pq.size() > t.d) pq.pop();   // 超出截止时间，弹出最小收益
}
long long ans = 0;
while (!pq.empty()) { ans += pq.top(); pq.pop(); }
```

### 4.3 例题：修车

**题意**：$n$ 辆车，每辆有维修时间，求最小总等待时间。

**贪心**：按时间排序，或反悔贪心。

## 5. 贪心与排序

很多贪心题的核心是**排序关键字**：

| 问题 | 排序关键字 |
|---|---|
| 区间调度 | 右端点 |
| 区间覆盖 | 左端点 |
| 合并果子 | 值（堆） |
| 排队接水 | 时间 |
| 任务调度 | 截止时间 |
| 最小生成树 | 边权 |

**技巧**：如果不确定排序关键字，可以尝试多种，用对拍验证。

## 6. 经典例题

### 6.1 合并果子

**题意**：$n$ 堆果子，每次合并两堆，代价为两堆之和，求最小总代价。

**做法**：小根堆，每次取最小的两堆。

### 6.2 区间调度

**题意**：最多选多少个不重叠区间。

**做法**：按右端点排序。

### 6.3 任务调度

**题意**：每个任务有截止时间和收益，求最大收益。

**做法**：按截止时间排序 + 小根堆反悔。

### 6.4 田忌赛马

**题意**：$2n$ 匹马，求最多胜场。

**做法**：双指针贪心。

### 6.5 国王游戏

**题意**：$n$ 个大臣排队，每人左右手有数字，求某个比值最大最小。

**做法**：按 $a_i \times b_i$ 排序（高精度）。

---

## 7. 易错点与练习

### 易错点

1. **想当然地贪心**：贪心不成立时要用 DP；
2. **排序关键字错误**：多试几种；
3. **边界情况**：空集、只有一个元素、相等元素；
4. **反悔贪心的堆方向**：小根堆还是大根堆；
5. **溢出**：乘积、累加用 `long long`；
6. **贪心 + 二分**：有时要「二分答案 + 贪心判定」。

### 练习建议

1. 区间调度（按右端点）；
2. 合并果子（堆）；
3. 任务调度（反悔贪心）；
4. 田忌赛马（双指针）；
5. 国王游戏（排序 + 高精度）；
6. 贪心 + 二分（如「最大化最小值」）。
