# 构造（Construction）

> 构造题不给「求最优值」，而是让你**输出一个满足条件的方案**。它的解法高度依赖观察，但套路是有的。

## 1. 构造题的特点

- **没有唯一答案**：只要满足条件都算对；
- **数据范围小或结构特殊**：常常 $n \le 1000$ 或要求「恰好 $k$ 个」；
- **考察观察力**：需要从样例中发现规律；
- **暴力可以拿部分分**：小数据可以直接搜索。

**判断是否为构造题**：

- 输出是「方案」而不是「数值」；
- 题目说「输出任意一种」；
- 答案有多组；
- 出现「恰好」「至少」「不超过」等字眼。

## 2. 常见构造套路

### 2.1 对称构造

利用对称性，让左右/上下配对。

**例子**：构造一个 $n \times n$ 矩阵，每行每列和相等——填 $1 \sim n^2$ 按斜线顺序。

### 2.2 分块构造

把问题分成若干块，每块独立构造。

**例子**：构造长度为 $n$ 的排列，使相邻差绝对值包含 $1 \sim n-1$——交替放两端。

### 2.3 周期构造

用循环节。

**例子**：构造字符串使某模式重复出现。

### 2.4 贪心构造

每一步选当前最优的合法选项。

**例子**：构造字典序最小的拓扑序——每次选入度为 0 且编号最小的。

### 2.5 增量构造

从 $n-1$ 的答案推出 $n$ 的答案。

**例子**：$n$ 个点的树构造。

### 2.6 二进制/位构造

利用二进制位。

**例子**：用 $2$ 的幂次凑出任意数。

### 2.7 随机化构造

随机生成，不满足就重来。适用于条件宽松的题。

## 3. 从特殊到一般

**核心方法**：

1. 先手算 $n = 1, 2, 3, 4, 5$ 的答案；
2. 找规律；
3. 猜公式；
4. 证明或对拍验证。

**例子**：构造长度为 $n$ 的排列，使得 $\sum |p_i - i|$ 最大。

手算：

- $n=1$: `1`，和 = 0
- $n=2$: `2 1`，和 = 2
- $n=3$: `3 1 2`，和 = 4? 或 `2 3 1` 和 = 4
- $n=4$: `4 1 2 3` 和 = 6? 

规律：把后半段放前面。

## 4. 经典例题

### 4.1 构造排列使相邻差不同

**题意**：构造 $1 \sim n$ 的排列，使 $|p_i - p_{i+1}|$ 两两不同。

**做法**：小的放左、大的放右交替。

```cpp
// n = 5: 1 5 2 4 3
int l = 1, r = n;
for (int i = 1; i <= n; ++i) {
    if (i % 2 == 1) a[i] = l++;
    else a[i] = r--;
}
```

### 4.2 构造括号序列

**题意**：构造长度为 $2n$ 的合法括号序列。

**做法**：$n$ 个 `(` 后接 $n$ 个 `)`，或交替。

### 4.3 构造矩阵使每行每列和相等

**做法**：按斜线填充 $1 \sim n^2$。

### 4.4 构造树

**题意**：构造 $n$ 个点的树，使直径恰好为 $d$。

**做法**：先构造一条长度为 $d$ 的链，其余点挂在链上。

### 4.5 构造图

**题意**：构造 $n$ 个点 $m$ 条边的连通图。

**做法**：先造一棵生成树，再加边。

### 4.6 构造序列使异或和为 0

**题意**：构造 $n$ 个数使异或和为 0。

**做法**：前 $n-1$ 个随便，最后一个 = 前面异或和。

## 5. 构造题的检查方法

1. **写一个 checker**：验证输出是否满足条件；
2. **对拍**：构造多个解，检查都合法；
3. **边界测试**：$n=1$、$n=2$、极大值；
4. **手算小样例**：与题目样例比对。

```cpp
// checker 示例
bool check(const vector<int>& a) {
    // 验证所有条件
    return true;
}
```

## 6. 易错点与练习

### 易错点

1. **输出格式**：多一个空格、少一个换行都可能挂；
2. **恰好 vs 至少**：题目要求「恰好 $k$ 个」时不能多也不能少；
3. **无解情况**：有些输入本身无解，题目会说明输出 `-1`；
4. **数据范围**：构造的值要在范围内；
5. **特殊值**：$n=1$、$n=2$ 往往要特判；
6. **随机构造不稳定**：加了随机数可能偶尔 WA。

### 练习建议

1. 从 $n=1 \sim 6$ 手算找规律；
2. 写 checker 验证；
3. 练习「构造排列」「构造树」「构造矩阵」三类；
4. 看 Codeforces 的 Constructive Algorithms 标签。

## 附：更多经典例题

### 例题 1：构造满足度数要求的图

**题意**：构造 $n$ 个点、每个点度数恰好为 $d_i$ 的简单无向图，或说明无解。

**思路**：Havel–Hakimi 定理的构造版：每次取度数最大的点，与剩下度数最大的若干个点连边。$O(n^2)$ 或 $O(n \log n)$。

### 例题 2：构造括号序列使第 $k$ 个前缀平衡

**题意**：给定 $n$ 与目标值，构造长度为 $2n$ 的合法括号序列，使某个前缀和条件成立。

**思路**：先构造标准序列，再通过局部交换调整。

### 例题 3：构造矩阵使行列式非零

**题意**：构造 $n \times n$ 的 $01$ 矩阵，使行列式非零。

**思路**：上三角矩阵，对角线全 1，其余任意。

### 例题 4：构造反例

**题意**：给定一个错误算法，构造数据使其出错。

**思路**：分析算法的错误假设，针对该假设构造边界数据。这类题常出现在「交互 / 构造」混合题中。

### 例题 5：构造 + 验证器

写完构造后，务必写一个 checker：逐条检查输出是否满足题面所有约束，避免「看起来对」但漏掉某个条件。
