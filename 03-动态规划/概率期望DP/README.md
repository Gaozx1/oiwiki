# 概率期望 DP

> 一句话概括：在带随机性的状态机上，利用**期望的线性性**与**全期望公式**，把"从当前状态到终点的期望代价"拆成"这一步的代价 + 下一步的期望"，用递推求出答案。

## 一、概念与原理

### 1.1 随机变量与期望

一个**随机试验**的所有可能结果构成**样本空间** $\Omega$，每个结果 $\omega$ 被赋予概率 $P(\omega)$，满足非负性 $P(\omega)\ge 0$ 与归一性 $\sum_{\omega}P(\omega)=1$。事件 $A\subseteq\Omega$ 的概率为 $P(A)=\sum_{\omega\in A}P(\omega)$。

**随机变量** $X$ 是从样本空间到实数的函数。若 $X$ 取值 $x_1,\dots,x_k$，其**期望**为

$$
E[X]=\sum_{i=1}^{k}x_i\Pr[X=x_i].
$$

期望是大量重复试验下的平均值，不一定是可能取值（均匀骰子的期望是 $3.5$）。基本性质：

$$
E[aX+b]=aE[X]+b,\qquad E[X+Y]=E[X]+E[Y].
$$

### 1.2 期望的线性性

对任意随机变量 $X,Y$（**不要求独立**）：

$$
E[X+Y]=\sum_{\omega}\bigl(X(\omega)+Y(\omega)\bigr)P(\omega)
=\sum_{\omega}X(\omega)P(\omega)+\sum_{\omega}Y(\omega)P(\omega)=E[X]+E[Y].
$$

推广得 $E\bigl[\sum_i X_i\bigr]=\sum_i E[X_i]$。这是期望 DP 最重要的工具：很多"求总期望"的题目，把总量拆成若干个**指示变量**之和，就能化为若干独立小期望之和。

### 1.3 全概率与全期望公式

设 $B_1,\dots,B_m$ 是样本空间的一个划分（互不相交、并为 $\Omega$），则

$$
P(A)=\sum_{i=1}^{m}P(B_i)P(A\mid B_i),\qquad
E[X]=\sum_{i=1}^{m}P(B_i)E[X\mid B_i].
$$

在 DP 中取 $B_i$ 为"第一步走到状态 $i$"，得到**逆推期望方程**：

$$
E[\text{从 }u\text{ 出发的总代价}]
=\sum_{v}p(u,v)\Bigl(w(u,v)+E[\text{从 }v\text{ 出发的总代价}]\Bigr).
$$

### 1.4 正推概率与逆推期望

**（1）求概率：从初态正推。** 令 $f[u]$ 表示"从起点走到 $u$"的概率，$f[\text{起点}]=1$，则

$$
f[v]\mathrel{+}=f[u]\cdot p(u,v),
$$

按拓扑序推进，最后把终态概率相加。

**（2）求期望：从终态逆推。** 令 $E[u]$ 表示"从 $u$ 出发到终态"的期望代价，终态 $E=0$，则

$$
E[u]=\sum_{v}p(u,v)\bigl(w(u,v)+E[v]\bigr),
$$

按拓扑序的**逆序**计算。下图是一个四状态随机过程：

```
              p=0.5
        ┌───────────────┐
        │               ▼
   ┌─────────┐      ┌─────────┐
   │    A    │─────▶│    B    │
   └─────────┘ p=0.5└─────────┘
        │                │
        │ p=0.5          │ p=1
        ▼                ▼
   ┌─────────┐      ┌─────────┐
   │    C    │─────▶│    D    │  ← 终态，E[D]=0
   └─────────┘ p=1  └─────────┘

   逆推顺序：D → C → B → A
   E[C] = 1 + E[D]
   E[B] = 1 + E[D]
   E[A] = 1 + 0.5·E[B] + 0.5·E[C]
```

**（3）有环怎么办？** 若状态图有环，递推式出现循环依赖：

$$
E[u]=1+\tfrac{1}{2}E[u]+\tfrac{1}{2}E[v].
$$

可移项消去 $E[u]$ 得到一元方程；若多个状态互相依赖，则整理成线性方程组用**高斯消元**求解；状态多但结构特殊时可用迭代法逼近。

### 1.5 状态设计与首步分析

设计状态时问自己：需要记住哪些信息才能保证无后效性？能否用期望的线性性把整体拆成局部？转移是否成环、能否移项消掉自环？

**首步分析**是最常用的推导手法：站在当前状态枚举下一步。例如下一步以 $p$ 概率回到当前、以 $1-p$ 概率进入终态，则

$$
E=1+pE+(1-p)\cdot 0\quad\Longrightarrow\quad E=\frac{1}{1-p}.
$$

## 二、模板代码

### 2.1 期望逆推模板

**模型**：$0,1,\dots,n$ 共 $n+1$ 个格子，从 $0$ 出发，每次等概率掷出 $1\sim 6$ 前进，越过 $n$ 视为到达 $n$，求到达 $n$ 的期望掷骰次数。设 $E[i]$ 为从 $i$ 出发的期望次数，则 $E[n]=0$，

$$
E[i]=1+\frac{1}{6}\sum_{k=1}^{6}E[\min(n,i+k)].
$$

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1000005;
int n;
double E[MAXN];   // E[i]：从位置 i 走到 n 的期望掷骰次数

int main() {
    scanf("%d", &n);
    E[n] = 0.0;                       // 终点不再需要掷
    for (int i = n - 1; i >= 0; --i) {
        E[i] = 1.0;                   // 先付出"掷一次"的代价
        for (int k = 1; k <= 6; ++k) {
            int j = min(n, i + k);    // 超过终点视为到达终点
            E[i] += E[j] / 6.0;       // 六种点数等概率
        }
    }
    printf("%.10f\n", E[0]);
    return 0;
}
```

循环必须**从大到小**，因为 $E[i]$ 依赖 $E[j]\ (j>i)$。

### 2.2 概率正推模板

**模型**：同样的格子与走法，求到达 $n$ 的概率。设 $f[i]$ 为"从 $0$ 出发恰好落在 $i$"的概率，$f[0]=1$，则

$$
f[\min(n,i+k)]\mathrel{+}=\frac{f[i]}{6}.
$$

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    scanf("%d", &n);
    vector<double> f(n + 1, 0.0);
    f[0] = 1.0;                          // 起点概率为 1
    for (int i = 0; i < n; ++i) {        // 按位置从小到大正推
        if (f[i] == 0.0) continue;
        for (int k = 1; k <= 6; ++k) {
            int j = min(n, i + k);
            f[j] += f[i] / 6.0;
        }
    }
    printf("%.10f\n", f[n]);
    return 0;
}
```

两个模板只差一处：**逆推算期望先加 1 再累加后继；正推算概率只传递概率、不加代价**。

## 三、经典例题

### 例题 1：集齐 n 种卡片

**题意**：$n$ 种卡片等概率出现（有放回），求集齐全部 $n$ 种所需抽取次数的期望。

**思路**：已集齐 $k$ 种时，抽到新卡片的概率 $p_k=\frac{n-k}{n}$，从 $k$ 到 $k+1$ 的期望次数为 $1/p_k=\frac{n}{n-k}$。由线性性，

$$
E=\sum_{k=0}^{n-1}\frac{n}{n-k}=nH_n=n\sum_{i=1}^{n}\frac{1}{i}.
$$

**复杂度**：$O(n)$ 时间，$O(1)$ 空间。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    scanf("%d", &n);
    double ans = 0.0;
    for (int i = 1; i <= n; ++i) ans += (double)n / i;   // n * H_n
    printf("%.6f\n", ans);
    return 0;
}
```

> 这是期望线性性最纯粹的应用：不用状压记录"集齐了哪些"，直接按种类拆贡献。若每种卡片概率不同，则需要状压 DP（$n\le 20$）。

### 例题 2：连续 k 次正面

**题意**：反复抛公平硬币，求首次出现连续 $k$ 次正面所需抛掷次数的期望。

**思路**：设 $E_i$ 为"已连续 $i$ 次正面、还差多少次"的期望，$E_k=0$。首步分析：

$$
E_i=1+\frac{1}{2}E_{i+1}+\frac{1}{2}E_0.
$$

猜闭式解 $E_i=2^{k+1}-2^{i+1}$，代入验证：$E_k=0$，且

$$
1+\frac{1}{2}E_{i+1}+\frac{1}{2}E_0
=1+\frac{2^{k+1}-2^{i+2}}{2}+\frac{2^{k+1}-2}{2}
=2^{k+1}-2^{i+1}=E_i.
$$

答案 $E_0=2^{k+1}-2$。

**复杂度**：$O(1)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int k;
    scanf("%d", &k);
    long long ans = (1LL << (k + 1)) - 2;   // 要求 k <= 61
    printf("%lld\n", ans);
    return 0;
}
```

若不想推闭式解，可设 $E_i=A_iE_0+B_i$，从后往前代入，最终解出 $E_0$——这种"设未知数 + 代入消元"的技巧很常用。

### 例题 3：绿豆蛙的归宿

**题意**：$n$ 个点、$m$ 条边的 DAG，边有长度。从 $1$ 号点出发，每次等概率选一条出边前进，求走到 $n$ 号点的期望路径长度。

**思路**：设 $E[u]$ 为从 $u$ 出发到 $n$ 的期望长度，$E[n]=0$，则

$$
E[u]=\frac{1}{\mathrm{outdeg}(u)}\sum_{(u,v,w)}(w+E[v]).
$$

先拓扑排序，再按拓扑序**逆序**计算。

**复杂度**：$O(n+m)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int n, m, indeg[MAXN], outdeg[MAXN];
vector<pair<int, int>> g[MAXN];   // (后继, 边权)
vector<int> topo;
double E[MAXN];

int main() {
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= m; ++i) {
        int u, v, w;
        scanf("%d%d%d", &u, &v, &w);
        g[u].push_back({v, w});
        ++indeg[v]; ++outdeg[u];
    }
    queue<int> q;
    for (int i = 1; i <= n; ++i) if (indeg[i] == 0) q.push(i);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        topo.push_back(u);
        for (auto &e : g[u]) if (--indeg[e.first] == 0) q.push(e.first);
    }
    for (int i = (int)topo.size() - 1; i >= 0; --i) {
        int u = topo[i];
        if (outdeg[u] == 0) continue;
        for (auto &e : g[u])
            E[u] += (E[e.first] + e.second) / outdeg[u];
    }
    printf("%.2f\n", E[1]);
    return 0;
}
```

### 例题 4：OSU!

**题意**：$n$ 次操作，第 $i$ 次成功概率 $p_i$，得分为所有极长连续成功段长度的立方和，求期望得分。

**思路**：设 $L_i$ 为以 $i$ 结尾的连续成功长度，$S_i$ 为前 $i$ 次得分。第 $i$ 次成功时新增

$$
(L_{i-1}+1)^3-L_{i-1}^3=3L_{i-1}^2+3L_{i-1}+1.
$$

维护 $\ell_i=E[L_i]$、$q_i=E[L_i^2]$：

$$
\ell_i=(\ell_{i-1}+1)p_i,\quad
q_i=(q_{i-1}+2\ell_{i-1}+1)p_i,\quad
E[S_i]=E[S_{i-1}]+(3q_{i-1}+3\ell_{i-1}+1)p_i.
$$

**复杂度**：$O(n)$ 时间，$O(1)$ 空间。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    scanf("%d", &n);
    double len = 0.0;   // E[L]
    double sq = 0.0;    // E[L^2]
    double ans = 0.0;   // E[S]
    for (int i = 1; i <= n; ++i) {
        double p;
        scanf("%lf", &p);
        ans += (3.0 * sq + 3.0 * len + 1.0) * p;   // 先用旧的 len、sq
        sq = (sq + 2.0 * len + 1.0) * p;
        len = (len + 1.0) * p;
    }
    printf("%.6f\n", ans);
    return 0;
}
```

> 若得分是长度的 $d$ 次方，就需要维护 $1\sim d-1$ 阶矩；这与本题维护一次矩、二次矩的思路一致。

## 四、易错点

1. **正推/逆推方向搞反。** 求概率从起点正推，求期望从终态逆推；先写清 $f[i]$ 的定义再写代码。
2. **忘记乘转移概率。** 逆推时每个后继要乘 $p(u,v)$；出边等概率时别忘除以出度。
3. **误以为线性性需要独立。** $E[X+Y]=E[X]+E[Y]$ 恒成立；只有 $E[XY]=E[X]E[Y]$ 才需要独立。
4. **自环没有消去。** 转移里出现 $E[u]$ 本身时必须移项，否则递推无法结束。
5. **浮点判断与输出。** 用 `double` 或 `long double`，输出用 `printf("%.6f")`；不要用 `==` 比较浮点数。
6. **初始状态遗漏。** 概率正推 $f[\text{起点}]=1$；期望逆推所有终态 $E=0$，不可达状态要赋不可能值。
7. **状态不满足无后效性。** 例如"连续成功次数"必须完整记录，否则立方增量算不对。
8. **期望不存在。** 过程可能永不终止时期望不存在，需要特判。
