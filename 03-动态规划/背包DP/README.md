# 背包 DP：在容量限制下做取舍

> 一句话概括：**背包 DP 解决的是「每个物品选或不选、容量有限、求最大价值」这一类最优化问题**，几乎所有背包模型都可以由 01 背包的「逆序枚举容量」技巧推导出来。

## 1. 概念与原理

### 1.1 背包问题的统一框架

背包问题的一般形式：

> 有 $n$ 件物品和一个容量为 $V$ 的背包。第 $i$ 件物品的体积为 $v_i$，价值为 $w_i$。在总体积不超过 $V$ 的前提下，选择若干物品，使总价值最大。

不同背包模型的区别在于**每件物品可选几次**、**物品之间有没有附加约束**：

| 模型 | 每件物品可选次数 | 典型转移方向 |
|---|---|---|
| 01 背包 | 至多 1 次 | 容量**逆序**枚举 |
| 完全背包 | 无限次 | 容量**正序**枚举 |
| 多重背包 | 至多 $c_i$ 次 | 二进制拆分 / 单调队列 |
| 分组背包 | 每组至多选 1 件 | 外层枚举组，内层逆序 |
| 树形背包 | 依赖关系构成树 | 树上合并子树 |

所有背包问题的状态都长得一样：

$$
dp_{j} = \text{用容量 } j \text{ 能获得的最大价值}
$$

写背包题的第一步永远是：**先问清楚这是哪一种背包，再套对应的循环顺序**。

### 1.2 01 背包

**状态设计**：$dp_{i,j}$ 表示「只考虑前 $i$ 件物品、容量为 $j$ 时的最大价值」。

**转移方程**：

$$
dp_{i,j}=\max\left(dp_{i-1,j},\ dp_{i-1,j-v_i}+w_i\right),\quad j\ge v_i
$$

含义：第 $i$ 件物品要么不选（继承 $dp_{i-1,j}$），要么选（占用 $v_i$ 的容量，价值增加 $w_i$）。

**滚动数组优化**：注意到第 $i$ 行只依赖第 $i-1$ 行，可以压成一维：

$$
dp_j=\max(dp_j,\ dp_{j-v_i}+w_i)
$$

**关键：$j$ 必须从 $V$ 逆序枚举到 $v_i$。**

为什么？因为 $dp_j$ 依赖的是「上一轮的 $dp_{j-v_i}$」。如果正序枚举，$dp_{j-v_i}$ 可能在本轮已经被第 $i$ 件物品更新过，相当于同一件物品被选了多次，就变成了完全背包。

```
容量索引:  0   1   2   3   4   5
初始:      0   0   0   0   0   0
物品 (v=2,w=3)，逆序更新：
  j=5: dp[5] = max(dp[5], dp[3]+3) = 3
  j=4: dp[4] = max(dp[4], dp[2]+3) = 3
  j=3: dp[3] = max(dp[3], dp[1]+3) = 3
  j=2: dp[2] = max(dp[2], dp[0]+3) = 3
  结果每个容量最多用这件物品一次 ✔
```

### 1.3 完全背包

**状态设计**：$dp_j$ 表示容量为 $j$ 时的最大价值，每件物品可选无限次。

**转移方程**：

$$
dp_j=\max\left(dp_j,\ dp_{j-v_i}+w_i\right),\quad j\ \text{从}\ v_i\ \text{正序枚举到}\ V
$$

正序枚举时，$dp_{j-v_i}$ 已经是**本轮**更新过的值，所以允许同一物品反复加入——恰好对应「无限次」。这是 01 背包与完全背包唯一的代码差别。

```
完全背包 (v=2, w=3)，正序更新：
  j=2: dp[2] = dp[0]+3 = 3
  j=3: dp[3] = dp[1]+3 = 3
  j=4: dp[4] = dp[2]+3 = 6   ← 用了两次同一物品
  j=5: dp[5] = dp[3]+3 = 6
```

**另一种推导**：完全背包也可以写成 $dp_{i,j}=\max(dp_{i-1,j},\ dp_{i,j-v_i}+w_i)$，注意第二项是 $dp_{i,\cdot}$ 而不是 $dp_{i-1,\cdot}$，即「选第 $i$ 件后还可以继续选第 $i$ 件」。

### 1.4 多重背包

**问题**：第 $i$ 件物品最多选 $c_i$ 次。

**做法一：直接拆分**。把 $c_i$ 件同样的物品当成 $c_i$ 件独立的 01 物品，复杂度 $O(V\sum c_i)$，在 $c_i$ 较大时会超时。

**做法二：二进制拆分**。把 $c_i$ 拆成 $1,2,4,\dots,2^{k-1}, c_i-2^k+1$ 这些「块」，每块作为一个 01 物品。任何 $0\sim c_i$ 的选取数量都能由这些块的子集和表示，于是物品数从 $c_i$ 降到 $\log c_i$。

```
c_i = 13 拆成 1, 2, 4, 6
可以拼出 0..13 的所有整数：例如 3=1+2, 7=1+2+4, 11=1+4+6, 13=1+2+4+6
```

复杂度 $O(V\sum \log c_i)$。

**做法三：单调队列优化**。对每个余数 $r$ 单独处理，把 $j=r+kv_i$ 的转移写成滑动窗口最大值，复杂度 $O(nV)$。这是多重背包的最优复杂度。

### 1.5 分组背包

**问题**：有 $k$ 组物品，每组内部最多只能选一件。

**做法**：外层枚举组，中层枚举容量（逆序），内层枚举组内物品：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int k = 2, V = 10;                       // 共 k 组，背包容量 V
    vector<vector<int>> group = {{0, 1}, {2}};   // 每组存物品编号
    vector<int> v = {0, 3, 7}, w = {0, 4, 9};    // 物品的体积与价值
    vector<int> dp(V + 1, 0);

    for (int g = 0; g < k; ++g)              // 外层：每组
        for (int j = V; j >= 0; --j)         // 中层：容量必须逆序
            for (int i : group[g])           // 内层：组内物品
                if (j >= v[i]) dp[j] = max(dp[j], dp[j - v[i]] + w[i]);

    cout << dp[V] << '\n';
    return 0;
}
```

**注意循环顺序**：容量必须在组内物品的外层，否则同一组可能被选多件。可以理解为「每组做一次 01 背包，且这一组只能选一个」。

### 1.6 依赖背包与树形背包

**问题**：物品之间有依赖关系（选 A 必须先选 B），依赖关系构成一棵树。

设 $dp_{u,j}$ 表示在 $u$ 的子树中选择物品、总容量为 $j$ 的最大价值。合并子节点 $v$ 时做一次卷积式的背包合并：

$$
dp_{u,j}=\max_{0\le k\le j}\left(dp_{u,j-k}+dp_{v,k}\right)
$$

如果要求「选子节点必须先选父节点」，初始化时强制 $dp_{u,v_u}=w_u$，且 $u$ 不选时整棵子树都不能选。

## 2. 模板代码

### 2.1 01 背包

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, V;
    cin >> n >> V;
    vector<int> v(n), w(n);
    for (int i = 0; i < n; ++i) cin >> v[i] >> w[i];

    vector<int> dp(V + 1, 0);             // dp[j]：容量 j 的最大价值
    for (int i = 0; i < n; ++i) {
        for (int j = V; j >= v[i]; --j) { // 逆序！保证每件物品至多用一次
            dp[j] = max(dp[j], dp[j - v[i]] + w[i]);
        }
    }
    cout << dp[V] << '\n';
    return 0;
}
```

### 2.2 完全背包

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, V;
    cin >> n >> V;
    vector<int> v(n), w(n);
    for (int i = 0; i < n; ++i) cin >> v[i] >> w[i];

    vector<int> dp(V + 1, 0);
    for (int i = 0; i < n; ++i) {
        for (int j = v[i]; j <= V; ++j) { // 正序！允许同一物品重复使用
            dp[j] = max(dp[j], dp[j - v[i]] + w[i]);
        }
    }
    cout << dp[V] << '\n';
    return 0;
}
```

### 2.3 多重背包（二进制拆分）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, V;
    cin >> n >> V;
    vector<int> v, w;                      // 拆分后的 01 物品
    for (int i = 0; i < n; ++i) {
        int vi, wi, ci;
        cin >> vi >> wi >> ci;
        for (int k = 1; ci > 0; k <<= 1) { // 1, 2, 4, ...
            int take = min(k, ci);
            ci -= take;
            v.push_back(vi * take);        // 一块相当于 take 件物品捆绑
            w.push_back(wi * take);
        }
    }
    vector<int> dp(V + 1, 0);
    for (size_t i = 0; i < v.size(); ++i)
        for (int j = V; j >= v[i]; --j)    // 拆成 01 背包，逆序
            dp[j] = max(dp[j], dp[j - v[i]] + w[i]);
    cout << dp[V] << '\n';
    return 0;
}
```

### 2.4 分组背包

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, V;
    cin >> n >> V;                         // n 组物品
    vector<int> dp(V + 1, 0);

    for (int g = 0; g < n; ++g) {
        int s;
        cin >> s;                          // 本组物品数量
        vector<int> v(s), w(s);
        for (int i = 0; i < s; ++i) cin >> v[i] >> w[i];

        for (int j = V; j >= 0; --j) {     // 容量逆序
            for (int i = 0; i < s; ++i) {  // 组内枚举
                if (j >= v[i])
                    dp[j] = max(dp[j], dp[j - v[i]] + w[i]);
            }
        }
    }
    cout << dp[V] << '\n';
    return 0;
}
```

### 2.5 树形背包（依赖背包）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 105;
int n, V;
int v[MAXN], w[MAXN];
vector<int> g[MAXN];
int dp[MAXN][MAXN];                        // dp[u][j]：u 子树用 j 容量

void dfs(int u) {
    // 必须选 u 才能选其子树，故先放入 u
    for (int j = v[u]; j <= V; ++j) dp[u][j] = w[u];
    for (int to : g[u]) {
        dfs(to);
        // 背包合并：枚举 u 已用容量 j 与儿子用容量 k
        for (int j = V; j >= v[u]; --j)
            for (int k = 0; k <= j - v[u]; ++k)
                dp[u][j] = max(dp[u][j], dp[u][j - k] + dp[to][k]);
    }
}

int main() {
    cin >> n >> V;
    for (int i = 1; i <= n; ++i) cin >> v[i] >> w[i];
    for (int i = 2; i <= n; ++i) {
        int p;
        cin >> p;                          // i 的父亲是 p
        g[p].push_back(i);
    }
    dfs(1);
    cout << dp[1][V] << '\n';
    return 0;
}
```

## 3. 经典例题

### 例题 1：01 背包（洛谷 P1048 采药）

**题意**：有 $M$ 株草药，每株有采集时间和价值，总时间 $T$。求在 $T$ 时间内能采到的最大价值。$1\le M,T\le 100$。

**思路**：裸的 01 背包，容量为时间，价值为草药价值。

**复杂度**：时间 $O(MT)$，空间 $O(T)$。

### 例题 2：完全背包（洛谷 P1616 疯狂的采药）

**题意**：与采药相同，但每种草药可以无限次采集。

**思路**：容量正序枚举的完全背包。注意答案可能超过 `int`，要用 `long long`。

**复杂度**：时间 $O(MT)$，空间 $O(T)$。

### 例题 3：多重背包（洛谷 P1776 宝物筛选）

**题意**：$n$ 种宝物，每种有体积、价值、数量上限，背包容量 $W$。求最大价值。数据范围要求 $O(nW)$ 或 $O(W\sum\log c)$。

**思路**：二进制拆分 + 01 背包即可通过弱化数据；完整数据需要用单调队列优化。

**复杂度**：二进制拆分 $O(W\sum\log c_i)$；单调队列 $O(nW)$。

### 例题 4：分组背包（洛谷 P1757 通天之分组背包）

**题意**：$n$ 件物品，每件有重量、价值、所属组号，每组最多选一件，背包总重不超过 $m$。

**思路**：把物品按组归类，外层组、中层容量逆序、内层组内物品。

**复杂度**：时间 $O(\sum s_g \cdot m)$，空间 $O(m)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int m, n;
    cin >> m >> n;
    map<int, vector<pair<int, int>>> groups;   // 组号 -> (重量, 价值)
    for (int i = 0; i < n; ++i) {
        int a, b, c;
        cin >> a >> b >> c;
        groups[c].push_back({a, b});
    }

    vector<int> dp(m + 1, 0);
    for (auto &kv : groups) {
        auto &g = kv.second;
        for (int j = m; j >= 0; --j)          // 容量逆序
            for (auto &pr : g)                // 组内最多选一个
                if (j >= pr.first)
                    dp[j] = max(dp[j], dp[j - pr.first] + pr.second);
    }
    cout << dp[m] << '\n';
    return 0;
}
```

## 4. 易错点与练习建议

### 4.1 常见易错点

1. **01 背包写成正序**：这是最经典的错误，会让物品被重复选择，答案偏大。记住口诀「**01 逆序、完全正序**」。
2. **分组背包循环顺序错误**：容量必须在组内物品的外层；如果写成「组内物品在外、容量在内」，同组会被选多件。
3. **多重背包拆分越界**：二进制拆分的最后一块是 `ci - (2^k - 1)`，不要写成固定的 `2^k`。
4. **体积为 0 的物品**：完全背包中若 $v_i=0$ 且 $w_i>0$ 会死循环（或答案无穷），需要题目保证 $v_i>0$，否则要特判。
5. **求「恰好装满」时的初始化**：$dp_0=0$，其余 $dp_j=-\infty$；求「不超过容量」时全部初始化为 0。两者不能混。
6. **方案数背包**：计数时转移是 `dp[j] += dp[j - v[i]]`，01 背包计数仍需逆序，完全背包计数需正序。
7. **`int` 溢出**：价值总和可能达到 $10^{18}$ 量级，用 `long long`。
8. **树形背包的合并顺序**：`dp[u][j]` 的枚举必须逆序，否则子树会被重复合并。

### 4.2 练习建议（由易到难）

| 难度 | 题目 | 考点 |
|---|---|---|
| 入门 | 洛谷 P1048 采药 | 01 背包模板 |
| 入门 | 洛谷 P1616 疯狂的采药 | 完全背包、`long long` |
| 普及 | 洛谷 P1060 开心的金明 | 01 背包的变体（价值 = 价格 × 重要度） |
| 普及 | 洛谷 P1757 通天之分组背包 | 分组背包 |
| 普及 | 洛谷 P1776 宝物筛选 | 多重背包、二进制拆分 |
| 提高 | 洛谷 P1833 樱花 | 混合背包（01 + 完全 + 多重） |
| 提高 | 洛谷 P2014 选课 | 树形背包 |
| 提高 | 洛谷 P1941 飞扬的小鸟 | 完全背包的变形 |

**训练方法**：

1. 手算一遍 01 背包的 DP 表格，理解「逆序」到底保护了什么；
2. 把 01、完全、多重、分组四个模板背到能默写，考试时直接套；
3. 遇到新题先判断「物品可选几次」「容量维度是什么」，再选模型；
4. 用对拍验证：正序/逆序写错时，小数据往往能暴露问题。
