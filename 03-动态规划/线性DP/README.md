# 线性 DP：沿着序列一步步做决策

> 一句话概括：**线性 DP 是状态只沿一个线性顺序（下标）推进的动态规划**，核心是把「前 $i$ 个元素」的最优解用「前 $j$ 个元素」（$j<i$）的最优解表示出来。

## 1. 概念与原理

### 1.1 什么是线性 DP

如果一个问题的**状态可以排成一条线**，并且每个状态只依赖它前面的若干个状态，那么这类 DP 就叫**线性 DP**。这里的「线」可以是：

- 数组下标：$dp_i$ 表示「前 $i$ 个数」或「以 $i$ 结尾」的最优值；
- 字符串下标：$dp_{i,j}$ 表示「第一个串的前 $i$ 个字符、第二个串的前 $j$ 个字符」；
- 二维网格的行列：$dp_{i,j}$ 表示走到格子 $(i,j)$ 的最优值。

线性 DP 是动态规划最基础、也最常考的形态。看上去模型很多，但套路高度统一：

```
    阶段 i-2       阶段 i-1        阶段 i        阶段 i+1
  ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
  │ dp[i-2] │ → │ dp[i-1] │ → │  dp[i]  │ → │ dp[i+1] │
  └─────────┘   └─────────┘   └─────────┘   └─────────┘
       状态只沿一个方向推进，后面的状态不会反过来影响前面的状态
```

**能用线性 DP 的两个前提：**

1. **最优子结构**：问题的最优解能由子问题的最优解拼出来；
2. **无后效性**：一旦 $dp_i$ 算完，后面无论怎么转移，都不会再改变 $dp_i$ 的取值。换句话说，状态里必须包含「影响未来决策的全部历史信息」。

### 1.2 状态设计的三个问题

写线性 DP 时，先逼自己回答三个问题，能避免 90% 的胡写：

**问题一：$dp$ 数组的下标表示什么？**

常见的有两类：

| 定义方式 | 含义 | 适合的问题 |
|---|---|---|
| 「前 $i$ 个」型 | $dp_i$ 表示只考虑前 $i$ 个元素时的答案 | 背包、前缀划分、LCS |
| 「以 $i$ 结尾」型 | $dp_i$ 表示强制选第 $i$ 个元素时的答案 | LIS、最大子段和、子序列计数 |

两种定义没有优劣，但不能混用。例如 LIS 如果定义成「前 $i$ 个里的最长上升子序列」，转移时无法知道上一个选的元素是谁，状态不够用；必须定义成「以 $i$ 结尾」。

**问题二：决策是什么？**

决策就是「上一步从哪里来」。例如：

- LIS：上一步是某个 $j<i$ 且 $a_j<a_i$；
- 最大子段和：上一步是「接在前一段后面」还是「从 $a_i$ 重新开始」；
- 数字三角形：上一步从左上角来还是右上角来。

**问题三：边界和答案是什么？**

- 边界：$dp_0$、$dp_{0,j}$、$dp_{i,0}$ 这些「空集」状态要手动赋初值；
- 答案：是 $dp_n$、$\max_i dp_i$，还是 $dp_{n,m}$？很多题错在答案取错位置。

### 1.3 模型一：最长上升子序列（LIS）

**问题**：给定序列 $a_1,a_2,\dots,a_n$，求最长的严格上升子序列长度。

**状态设计**：令 $dp_i$ 表示**以 $a_i$ 结尾**的最长上升子序列长度。

为什么必须「以 $i$ 结尾」？因为只有知道当前结尾的值，才能判断下一个数能不能接上去。

**转移方程**：

$$
dp_i = \max\left(1,\ \max_{1\le j<i,\ a_j<a_i}\{dp_j+1\}\right)
$$

**文字示意图**：

```
a:        2   5   3   7   4   6
dp:       1   2   2   3   3   4
                 ↑           ↑
          5 能接在 2 后面   6 能接在 3 或 4 后面
          所以 dp=2        所以 dp=3+1=4
```

朴素做法枚举 $j$，复杂度 $O(n^2)$。当 $n\le 10^5$ 时需要优化。

**优化思路（贪心 + 二分）**：维护数组 `tails`，其中 `tails[k]` 表示「所有长度为 $k+1$ 的上升子序列中，结尾元素的最小值」。这个数组一定是**严格递增**的。处理新元素 $x$ 时：

- 用 `lower_bound` 找到第一个 $\ge x$ 的位置并替换它（让同样长度的子序列结尾更小，后面更容易接）；
- 如果找不到，说明 $x$ 可以接到当前最长序列后面，`tails` 长度加一。

```
处理 2: tails = [2]
处理 5: tails = [2, 5]
处理 3: tails = [2, 3]      ← 3 替换 5，长度 2 的结尾更小
处理 7: tails = [2, 3, 7]
处理 4: tails = [2, 3, 4]   ← 4 替换 7
处理 6: tails = [2, 3, 4, 6]
答案 = tails.size() = 4
```

`tails` 的长度就是 LIS 长度，但 `tails` 本身**不一定**是一个合法的 LIS，它只是「每个长度的最小结尾」。需要输出方案时要额外记录前驱。

### 1.4 模型二：最长公共子序列（LCS）

**问题**：给定两个字符串（或序列）$A$、$B$，求它们的最长公共子序列长度。

**状态设计**：$dp_{i,j}$ 表示 $A$ 的前 $i$ 个字符与 $B$ 的前 $j$ 个字符的 LCS 长度。

**转移方程**：

$$
dp_{i,j}=
\begin{cases}
dp_{i-1,j-1}+1, & A_i=B_j\\[4pt]
\max(dp_{i-1,j},\ dp_{i,j-1}), & A_i\ne B_j
\end{cases}
$$

边界 $dp_{0,j}=dp_{i,0}=0$。

**为什么 $A_i=B_j$ 时可以直接匹配？** 因为两个串的当前末尾相同，把它们配成一对不会比任何其他方案差（可以用交换论证证明）。这一步也是 LCS 能 $O(nm)$ 求解的关键。

```
        ε   A   B   C   B   D
    ε   0   0   0   0   0   0
    A   0   1   1   1   1   1
    B   0   1   2   2   2   2
    C   0   1   2   3   3   3
    B   0   1   2   3   4   4
    D   0   1   2   3   4   5
```

答案在右下角 $dp_{n,m}$。如果想输出具体方案，从 $(n,m)$ 倒推：字符相等就取这个字符并向左上走，否则向 $dp$ 值较大的方向走。

### 1.5 模型三：最大子段和

**问题**：给定数组 $a_1,\dots,a_n$，求一个连续子段，使元素和最大（子段不能为空）。

**状态设计**：$dp_i$ 表示**以 $a_i$ 结尾**的最大子段和。

**转移方程**：

$$
dp_i=\max(a_i,\ dp_{i-1}+a_i)
$$

含义：要么从 $a_i$ 重新开一段，要么把 $a_i$ 接在前一段后面。答案为 $\max_{i=1}^{n} dp_i$，不是 $dp_n$。

```
a:       -2    1   -3    4   -1    2    1   -5    4
dp:      -2    1   -2    4    3    5    6    1    4
                           ↑              ↑
                       从 4 重新开始   继续累加得到 6（最优）
```

由于 $dp_i$ 只依赖 $dp_{i-1}$，可以用一个变量滚动，空间 $O(1)$。

### 1.6 模型四：数字三角形

**问题**：一个 $n$ 层的数字三角形，从顶部出发，每次只能走到左下或右下，求到达底部的最大路径和。

**状态设计**：$dp_{i,j}$ 表示从顶部走到第 $i$ 行第 $j$ 列的最大和。

**转移方程**：

$$
dp_{i,j}=a_{i,j}+\max(dp_{i-1,j-1},\ dp_{i-1,j})
$$

边界处理：越界的位置视为 $-\infty$。更省事的写法是**从下往上**推：

$$
dp_{i,j}=a_{i,j}+\max(dp_{i+1,j},\ dp_{i+1,j+1})
$$

```
        7
      3   8
    8   1   0
  2   7   4   4

自底向上：dp[3] = 2 7 4 4
          dp[2] = 8+max(2,7)=15, 1+max(7,4)=8, 0+max(4,4)=4
          dp[1] = 3+max(15,8)=18, 8+max(8,4)=16
          dp[0] = 7+max(18,16)=25
```

自底向上不需要处理边界，也不会有越界下标，是推荐写法。

## 2. 模板代码

### 2.1 LIS 的 $O(n\log n)$ 写法

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    // tails[k] = 长度为 k+1 的严格上升子序列的最小结尾
    vector<int> tails;
    for (int x : a) {
        // 严格上升：找第一个 >= x 的位置替换
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) {
            tails.push_back(x);          // x 可以接在当前最长序列后面
        } else {
            *it = x;                     // 让该长度的结尾更小，更有利于后续
        }
    }
    cout << tails.size() << '\n';        // tails 的长度即 LIS 长度
    return 0;
}
```

> 若要求**最长不下降子序列**（允许相等），把 `lower_bound` 换成 `upper_bound` 即可。

### 2.2 LCS 的二维 DP

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string a, b;
    cin >> a >> b;                       // 读入两个字符串
    int n = a.size(), m = b.size();

    // dp[i][j]：a 的前 i 个字符与 b 的前 j 个字符的 LCS 长度
    vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));

    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= m; ++j) {
            if (a[i - 1] == b[j - 1]) {  // 注意字符串下标从 0 开始
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    cout << dp[n][m] << '\n';
    return 0;
}
```

### 2.3 最大子段和（$O(1)$ 空间）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n; cin >> n;
    long long best = -(1LL << 60), cur = 0;   // best 必须初始化为负无穷
    for (int i = 1; i <= n; ++i) {
        long long x; cin >> x;
        cur = (i == 1 ? x : max(x, cur + x));  // 重新开始 or 接在前一段后
        best = max(best, cur);
    }
    cout << best << '\n';
    return 0;
}
```

### 2.4 数字三角形（自底向上）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<vector<int>> a(n, vector<int>(n, 0));
    for (int i = 0; i < n; ++i)
        for (int j = 0; j <= i; ++j) cin >> a[i][j];

    vector<int> dp(n, 0);
    for (int j = 0; j < n; ++j) dp[j] = a[n - 1][j];   // 最后一层就是初值

    for (int i = n - 2; i >= 0; --i) {                  // 从倒数第二层往上推
        for (int j = 0; j <= i; ++j) {
            dp[j] = a[i][j] + max(dp[j], dp[j + 1]);    // 左下或右下
        }
    }
    cout << dp[0] << '\n';
    return 0;
}
```

## 3. 经典例题

### 例题 1：数字三角形（洛谷 P1216）

**题意**：给定 $r$ 行的数字三角形（$1\le r\le 1000$），从顶部走到最底层，每次只能向左下或右下走一格，求路径上数字之和的最大值。

**思路**：自底向上 DP，$dp_{i,j}=a_{i,j}+\max(dp_{i+1,j},dp_{i+1,j+1})$。用滚动数组可以做到 $O(r)$ 空间。

**复杂度**：时间 $O(r^2)$，空间 $O(r)$。

### 例题 2：最大子段和（洛谷 P1115）

**题意**：给出 $n$ 个数 $a_1,\dots,a_n$，选出连续且非空的一段，使其和最大。$1\le n\le 2\times 10^5$。

**思路**：设 $cur$ 为以当前数结尾的最大子段和，转移 $cur=\max(a_i,cur+a_i)$，同时用 $best$ 记录历史最大值。

**复杂度**：时间 $O(n)$，空间 $O(1)$。

### 例题 3：最长公共子序列（洛谷 P1439）

**题意**：给出 $1\sim n$ 的两个排列 $A$、$B$（$n\le 10^5$），求它们的最长公共子序列长度。

**思路**：朴素的 $O(n^2)$ LCS 会超时。由于两个序列都是 $1\sim n$ 的排列，可以建立映射 `pos[x]` = 数字 $x$ 在 $B$ 中的位置，把 $A$ 转成 `pos[A[1]], pos[A[2]], ...`，问题等价于求这个数组的 **LIS**，用 `tails` + 二分做到 $O(n\log n)$。

**复杂度**：时间 $O(n\log n)$，空间 $O(n)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> a(n), b(n), pos(n + 1);
    for (int i = 0; i < n; ++i) cin >> a[i];
    for (int i = 0; i < n; ++i) {
        cin >> b[i];
        pos[b[i]] = i;                     // 记录每个数字在 B 中的位置
    }

    vector<int> tails;                     // 对映射后的序列求 LIS
    for (int i = 0; i < n; ++i) {
        int x = pos[a[i]];
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) tails.push_back(x);
        else *it = x;
    }
    cout << tails.size() << '\n';
    return 0;
}
```

### 例题 4：导弹拦截（洛谷 P1020）

**题意**：拦截系统每次拦截的导弹高度不能高于上一次（即形成**不上升**序列）。第一问：一套系统最多能拦截多少枚导弹？第二问：要拦截全部导弹至少需要几套系统？

**思路**：

- 第一问即**最长不上升子序列**长度；
- 第二问由 Dilworth 定理，等于**最长严格上升子序列**长度。

用贪心 + 二分维护两个 `tails` 数组，均做到 $O(n\log n)$。

**复杂度**：时间 $O(n\log n)$，空间 $O(n)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> a;
    int x;
    while (cin >> x) a.push_back(x);

    vector<int> dec, inc;
    for (int v : a) {
        // 最长不上升：在递减数组里找第一个 < v 的位置替换
        auto it = upper_bound(dec.begin(), dec.end(), v, greater<int>());
        if (it == dec.end()) dec.push_back(v);
        else *it = v;

        // 最长严格上升：找第一个 >= v 的位置替换
        auto it2 = lower_bound(inc.begin(), inc.end(), v);
        if (it2 == inc.end()) inc.push_back(v);
        else *it2 = v;
    }
    cout << dec.size() << '\n' << inc.size() << '\n';
    return 0;
}
```

## 4. 易错点与练习建议

### 4.1 常见易错点

1. **状态定义含糊**：LIS 写成「前 $i$ 个中的 LIS」而不是「以 $i$ 结尾」，导致无法转移。建议在纸上写下完整的一句话定义，包括「强制选谁」。
2. **LIS 的 `lower_bound` / `upper_bound` 用反**：严格上升用 `lower_bound`（替换第一个 $\ge x$），不下降用 `upper_bound`（替换第一个 $>x$）。
3. **答案取错位置**：LIS、最大子段和的答案是所有 $dp_i$ 的最大值，不是 $dp_n$。
4. **LCS 下标错位**：字符串从 0 开始，而 DP 从 1 开始，转移里要写 `a[i-1] == b[j-1]`。
5. **边界没初始化**：最大子段和若把 $best$ 初始化为 0，遇到全负数序列会输出 0，而题目要求非空子段。
6. **`int` 溢出**：涉及求和、计数时先估算上界，超过 $2\times 10^9$ 就换 `long long`。
7. **LIS 的 `tails` 被误当成方案**：`tails` 只保证长度正确，不保证内容是一个合法 LIS，输出方案需要记录前驱。
8. **滚动数组方向写反**：二维依赖 `dp[i-1][j-1]` 和 `dp[i-1][j]` 时，一维滚动要从后往前更新。

### 4.2 练习建议（由易到难）

| 难度 | 题目 | 考点 |
|---|---|---|
| 入门 | 洛谷 P1216 数字三角形 | 自底向上、边界处理 |
| 入门 | 洛谷 P1115 最大子段和 | 以 $i$ 结尾的状态设计 |
| 普及 | 洛谷 P1020 导弹拦截 | LIS 的贪心 + 二分、Dilworth 定理 |
| 普及 | 洛谷 P1439 最长公共子序列 | 排列转 LIS |
| 提高 | 洛谷 P1091 合唱队形 | 正反两遍 LIS |
| 提高 | 洛谷 P2516 最长公共子序列 | LCS 计数、去重 |
| 提高 | 洛谷 P2758 编辑距离 | 二维线性 DP 的分类讨论 |

**训练方法**：

1. 每道题先写出「状态的一句话定义 + 转移方程 + 边界 + 答案位置」四件套，再动手写代码；
2. 写完后用暴力程序对拍小数据，重点检查边界（$n=1$、全负数、有重复元素）；
3. 同一道题尝试两种状态定义（「前 $i$ 个」与「以 $i$ 结尾」），体会哪种能转移；
4. 遇到 $n\le 10^5$ 的 LIS 类问题，条件反射想到 `tails + 二分`。
