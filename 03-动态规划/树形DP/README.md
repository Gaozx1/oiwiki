## 1. 概念与原理

### 1.1 树形 DP 的基本结构

树是一种**没有环**的连通图，任选一个点为根，整棵树就分成若干棵子树。树形 DP 的通用套路是：

1. 任选根节点（通常为 1）；
2. **后序遍历**（DFS），先递归处理所有儿子，再在回溯时合并儿子的答案；
3. 每个节点维护若干状态，最终答案在根节点处汇总。

```
                1
              /   \
             2     3
            / \     \
           4   5     6

DFS 顺序：4 → 5 → 2 → 6 → 3 → 1
后代先算完，父亲才能合并 —— 这是树形 DP 能成立的根本原因
```

**复杂度分析**：常见的树形 DP 是每个节点做一次「与子树大小相关」的合并。若合并代价为 $O(sz_u\cdot sz_v)$，总复杂度可以用「树上每对点只在 LCA 处被枚举一次」这一事实证明为 $O(n^2)$。

### 1.2 状态设计：节点 + 约束

树形 DP 的状态通常是下面两种形式之一：

**形式一：$dp_u$ 表示以 $u$ 为根的子树内的答案。**

适用于答案只取决于子树内部的问题，如最大独立集、最小覆盖集。

**形式二：$dp_{u,j}$ 表示以 $u$ 为根的子树、在某种「与 $u$ 相关的约束/容量」为 $j$ 时的答案。**

适用于树上背包（$j$ 是容量）、树上染色（$j$ 是颜色或数量）等。

设计状态时最重要的是：**把「父亲对儿子的限制」写进状态**。例如最大独立集中，父亲选不选，直接决定儿子能不能选，所以状态必须区分「$u$ 选/不选」。

### 1.3 模型一：树的最大独立集

**问题**：在树上选出尽可能多的点，使任意两个被选的点都不相邻。

**状态设计**：

- $f_u$：$u$ 的子树中，**选 $u$** 时的最大独立集大小；
- $g_u$：$u$ 的子树中，**不选 $u$** 时的最大独立集大小。

**转移方程**：

$$
f_u=1+\sum_{v\in son(u)} g_v,\qquad
g_u=\sum_{v\in son(u)}\max(f_v,\ g_v)
$$

**解释**：

- 若选了 $u$，则所有儿子都不能选，儿子只能取 $g_v$；
- 若不选 $u$，儿子们选或不选都行，各取最大值。

```
        选 u:   f[u] = 1 + g[v1] + g[v2] + ...
                      (儿子全部强制不选)

      不选 u:   g[u] = max(f[v1],g[v1]) + max(f[v2],g[v2]) + ...
                      (每个儿子自由决定)
```

答案为 $\max(f_{root}, g_{root})$。

### 1.4 模型二：树的直径

**问题**：求树上最远的两个点之间的距离（边权为正）。

**状态设计**：$d_u$ 表示从 $u$ 出发、**向子树内部**走的最长路径长度。

**转移**：枚举儿子 $v$，边长 $w$：

$$
d_u=\max_{v}\left(d_v+w\right)
$$

**统计答案**：以 $u$ 为「最高点」（即两端点分属不同子树或某一端就是 $u$）的路径长度为「最长的两条向下的链之和」：

$$
ans=\max_{u}\left(\max_1\{d_v+w\}+\max_2\{d_v+w\}\right)
$$

其中 $\max_1$、$\max_2$ 是不同儿子中的最大与次大值。

```
             u
          /  |  \
        a1  a2  a3     ← 每个 ai = d[vi] + w(u,vi)
        |    |    |
       链长  链长  链长

经过 u 的最长路径 = 最大的两条链长之和 a1 + a2
（若 u 只有一个儿子，则路径是 u 到最深叶子，长度为 a1）
```

**另一种做法**：两遍 DFS/BFS——从任意点出发找到最远点 $A$，再从 $A$ 出发找到最远点 $B$，$A$ 到 $B$ 的距离即直径。该方法**只适用于非负边权**，而树形 DP 写法对负边权也成立。

### 1.5 模型三：树上背包

**问题**：每个节点有体积 $v_u$ 和价值 $w_u$，选儿子必须先选父亲，背包容量为 $V$，求最大价值。

**状态设计**：$dp_{u,j}$ 表示在 $u$ 的子树中选物品、总容量为 $j$ 的最大价值（且**必须选 $u$**）。

**转移**：先初始化 $dp_{u,v_u}=w_u$，再逐个合并儿子：

$$
dp_{u,j}=\max_{0\le k\le j-v_u}\left(dp_{u,j-k}+dp_{v,k}\right)
$$

**注意**：合并第 $v$ 个儿子时，$dp_{u,\cdot}$ 此时只包含「$u$ 与前几个儿子」的信息，因此必须从大到小枚举 $j$，避免同一个儿子被重复合并。

### 1.6 模型四：换根 DP

有些问题要求「以每个点为根时的答案」，例如求每个点到其余所有点的距离之和。这类问题用**换根 DP**：先做一次 DFS 求出以 1 为根的答案，再利用「根从 $u$ 换到儿子 $v$」时的递推关系 $O(1)$ 求出 $v$ 为根的答案。

以求距离和为例，设：

- $sz_u$：子树大小；
- $down_u$：$u$ 的子树内所有点到 $u$ 的距离之和；
- $ans_u$：以 $u$ 为根时，所有点到 $u$ 的距离之和。

第一次 DFS 求出 $sz$ 与 $down$：

$$
down_u=\sum_{v}\left(down_v+sz_v\right)
$$

第二次 DFS，由父亲的答案推出儿子的答案（设边权为 1）：

$$
ans_v=ans_u+n-2\cdot sz_v
$$

**直观理解**：根从 $u$ 移到 $v$ 后，$v$ 子树内的 $sz_v$ 个点各近了 1（贡献 $-sz_v$），其余 $n-sz_v$ 个点各远了 1（贡献 $+n-sz_v$），合起来就是 $n-2sz_v$。

```
        u                      v
      /   \                  /   \
     v     ...    →         ...    u
    / \                    (以 v 为根时，v 的子树变成 v 原来的下方 + u 那一侧)
```

## 2. 模板代码

### 2.1 树的存储与后序遍历

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
vector<int> g[MAXN];                       // 邻接表
int parent[MAXN];                          // 记录父亲，避免走回头路

void dfs(int u, int p) {
    parent[u] = p;
    for (int v : g[u]) {
        if (v == p) continue;              // 跳过父亲，防止死循环
        dfs(v, u);                         // 先递归处理儿子
    }
    // 在这里合并儿子的信息（后序位置）
}

int main() {
    int n;
    cin >> n;
    for (int i = 1; i < n; ++i) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    dfs(1, 0);
    return 0;
}
```

### 2.2 树的最大独立集

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int n;
vector<int> g[MAXN];
int f[MAXN], gv[MAXN];                     // f: 选 u；gv: 不选 u

void dfs(int u, int p) {
    f[u] = 1;                              // 选自己，先计入自身
    gv[u] = 0;
    for (int v : g[u]) {
        if (v == p) continue;
        dfs(v, u);
        f[u] += gv[v];                     // 选了 u，儿子必须不选
        gv[u] += max(f[v], gv[v]);         // 不选 u，儿子随意
    }
}

int main() {
    cin >> n;
    for (int i = 1; i < n; ++i) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    dfs(1, 0);
    cout << max(f[1], gv[1]) << '\n';
    return 0;
}
```

### 2.3 树的直径

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int n, ans = 0;
vector<pair<int, int>> g[MAXN];            // (邻点, 边权)

int dfs(int u, int p) {
    int best1 = 0, best2 = 0;              // 最长的两条向下链
    for (auto &e : g[u]) {              // C++14：显式取 pair 分量
        int v = e.first, w = e.second;
        if (v == p) continue;
        int d = dfs(v, u) + w;             // 从 u 经 v 向下的最长链
        if (d > best1) { best2 = best1; best1 = d; }
        else if (d > best2) { best2 = d; }
    }
    ans = max(ans, best1 + best2);         // 经过 u 的最长路径
    return best1;                          // 向上返回最长的一条链
}

int main() {
    cin >> n;
    for (int i = 1; i < n; ++i) {
        int u, v, w;
        cin >> u >> v >> w;
        g[u].push_back({v, w});
        g[v].push_back({u, w});
    }
    dfs(1, 0);
    cout << ans << '\n';
    return 0;
}
```

### 2.4 换根 DP：求每个点到其余点的距离之和

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int n;
vector<int> g[MAXN];
long long sz[MAXN], down[MAXN], ans[MAXN];

void dfs1(int u, int p) {                  // 第一遍：求 sz 与 down
    sz[u] = 1;
    down[u] = 0;
    for (int v : g[u]) {
        if (v == p) continue;
        dfs1(v, u);
        sz[u] += sz[v];
        down[u] += down[v] + sz[v];        // v 子树每个点再多走一条边
    }
}

void dfs2(int u, int p) {                  // 第二遍：由父亲推儿子
    for (int v : g[u]) {
        if (v == p) continue;
        ans[v] = ans[u] + n - 2 * sz[v];   // 换根公式（边权为 1）
        dfs2(v, u);
    }
}

int main() {
    cin >> n;
    for (int i = 1; i < n; ++i) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    dfs1(1, 0);
    ans[1] = down[1];                      // 以 1 为根的答案
    dfs2(1, 0);
    for (int i = 1; i <= n; ++i) cout << ans[i] << (i == n ? '\n' : ' ');
    return 0;
}
```

## 3. 经典例题

### 例题 1：没有上司的舞会（洛谷 P1352）

**题意**：$n$ 名职员构成一棵以校长为根的树，每个职员有一个快乐值。若某职员的直接上司参加舞会，则该职员不能参加。求最大快乐值总和。$1\le n\le 6000$。

**思路**：最大独立集模板。$f_u$ 表示选 $u$，$g_u$ 表示不选 $u$，后序合并。

**复杂度**：时间 $O(n)$，空间 $O(n)$。

### 例题 2：二叉苹果树（洛谷 P2015）

**题意**：一棵 $n$ 个节点的二叉树有 $n-1$ 条带权边，要保留 $q$ 条边，且保留的边必须与根连通，求保留边的最大权值和。$1\le q<n\le 100$。

**思路**：树上背包。$dp_{u,j}$ 表示以 $u$ 为根的子树中保留 $j$ 条边的最大收益。合并儿子 $v$ 时，若保留 $(u,v)$ 这条边，则儿子一侧可以再分配 $k$ 条边，权为 $dp_{v,k}+w(u,v)$。

**复杂度**：时间 $O(nq^2)$，空间 $O(nq)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 105;
int n, q;
vector<pair<int, int>> g[MAXN];
int dp[MAXN][MAXN];                        // dp[u][j]：u 子树保留 j 条边

void dfs(int u, int p) {
    for (auto &e : g[u]) {              // C++14：显式取 pair 分量
        int v = e.first, w = e.second;
        if (v == p) continue;
        dfs(v, u);
        for (int j = q; j >= 1; --j)       // 逆序，防止重复合并
            for (int k = 0; k < j; ++k)
                dp[u][j] = max(dp[u][j], dp[u][j - k - 1] + dp[v][k] + w);
    }
}

int main() {
    cin >> n >> q;
    for (int i = 1; i < n; ++i) {
        int u, v, w;
        cin >> u >> v >> w;
        g[u].push_back({v, w});
        g[v].push_back({u, w});
    }
    dfs(1, 0);
    cout << dp[1][q] << '\n';
    return 0;
}
```

### 例题 3：树的直径（洛谷 P3304 / 模板题）

**题意**：给定一棵带非负边权的树，求直径长度。

**思路**：树形 DP，每个节点统计最长的两条向下链，答案取各节点「最长 + 次长」的最大值。

**复杂度**：时间 $O(n)$，空间 $O(n)$。

### 例题 4：Sta 的旅行（换根 DP 模板）

**题意**：给定一棵 $n$ 个点的树，求每个点到其余所有点的距离之和。$1\le n\le 10^5$。

**思路**：两遍 DFS。第一遍求子树大小 $sz$ 与子树内距离和 $down$；第二遍用 $ans_v=ans_u+n-2sz_v$ 换根。

**复杂度**：时间 $O(n)$，空间 $O(n)$。

## 4. 易错点与练习建议

### 4.1 常见易错点

1. **DFS 不传父亲**：无向图存树时必须传 `p` 并跳过，否则会在父子之间来回死循环。
2. **状态缺少「选/不选」维度**：最大独立集、最小点覆盖这类题，状态必须区分节点自身的选择情况。
3. **先合并再递归**：树形 DP 必须是后序遍历，儿子算完才能合并。
4. **树上背包循环方向错**：合并儿子时容量必须逆序，否则同一个儿子会被重复使用。
5. **树上背包的容量上界写成 $V$**：应写当前子树大小与 $V$ 的较小值，否则复杂度退化。
6. **换根公式写错符号**：$ans_v=ans_u+n-2sz_v$，注意 $sz_v$ 是「以 1 为根时」$v$ 的子树大小，不是以 $v$ 为根时的。
7. **`int` 溢出**：树上距离和最大可达 $O(n^2)$（$n=10^5$ 时约 $10^{10}$），必须用 `long long`。
8. **多组数据不清空**：邻接表、dp 数组、答案变量都要清空。

### 4.2 练习建议（由易到难）

| 难度 | 题目 | 考点 |
|---|---|---|
| 入门 | 洛谷 P1352 没有上司的舞会 | 最大独立集 |
| 入门 | 洛谷 P2015 二叉苹果树 | 树上背包 |
| 普及 | 洛谷 P3304 树的直径 | 树形 DP 求直径 |
| 普及 | 洛谷 P3478 STA 的旅行 | 换根 DP |
| 提高 | 洛谷 P2279 消防局的设立 | 树上贪心 / 树形 DP |
| 提高 | 洛谷 P3177 树上染色 | 树上背包 + 贡献计算 |
| 提高 | 洛谷 P5021 赛道修建 | 树上二分 + 贪心 |

**训练方法**：

1. 画出一棵 5 个节点的小树，手动跑一遍 DFS 顺序与状态转移；
2. 记住三个基本模型（独立集、直径、树上背包）的方程，新题往往只是它们的组合；
3. 写树形 DP 时先写暴力搜索版本，确认状态定义无误后再改成递推；
4. 注意复杂度：$O(n^2)$ 的树上背包在 $n\le 2000$ 时可过，$n\le 10^5$ 时必须换思路。
