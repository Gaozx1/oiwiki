## 1. 为什么用位运算

看两个等价写法：`if (x % 2 == 0)` 与 `if ((x & 1) == 0)`。后者通常只编译成一条 `and` 指令，且对负数也稳定。位运算的价值在于**快**（一条 CPU 指令，无分支无除法）、**省空间**（一个 `int` 表示 32 个布尔状态）、**表达力强**（`x & -x` 取出最低位的 1，是树状数组的核心）。

**代价是可读性差**。原则是：只在性能关键处或状态压缩时使用，并写好注释。

## 2. 二进制与补码

### 2.1 二进制表示

一个 `int` 有 32 个二进制位，从右往左编号 $0 \sim 31$：

```
整数 13 的二进制：
位号:  31 ... 4  3  2  1  0
值:     0 ... 0  1  1  0  1
                 8  4     1   → 8 + 4 + 1 = 13
```

### 2.2 补码

现代计算机用**补码**表示有符号整数：正数的补码就是原码；负数的补码是绝对值按位取反再加 1。例：`-5` 的 8 位补码为 `1111 1011`（`5 = 0000 0101` → 取反 `1111 1010` → 加 1）。补码的好处是**减法可以统一成加法**：$a - b = a + (-b)$。

### 2.3 有符号与无符号

| 类型 | 范围（32 位） |
|---|---|
| `int`（有符号） | $-2^{31} \sim 2^{31}-1$ |
| `unsigned int` | $0 \sim 2^{32}-1$ |

`int` 的最高位是**符号位**：0 表示正，1 表示负。因此 `1 << 31` 会溢出成负数，必须用 `1LL << 31` 或 `1u << 31`。

## 3. 六个基本位运算符

| 运算符 | 名称 | 规则 | 例子（4 位） |
|---|---|---|---|
| `&` | 按位与 | 两位都为 1 才为 1 | `1100 & 1010 = 1000` |
| `\|` | 按位或 | 有一位为 1 就为 1 | `1100 \| 1010 = 1110` |
| `^` | 按位异或 | 两位不同为 1 | `1100 ^ 1010 = 0110` |
| `~` | 按位取反 | 0 变 1，1 变 0 | `~1100 = 0011`（4 位） |
| `<<` | 左移 | 整体左移，低位补 0 | `0011 << 1 = 0110` |
| `>>` | 右移 | 整体右移（有符号补符号位） | `0110 >> 1 = 0011` |

左移与右移的含义是

$$a \ll k = a \times 2^k, \qquad a \gg k = \left\lfloor \frac{a}{2^k} \right\rfloor \quad (a \ge 0)$$

> **负数右移**：C++ 标准未规定是算术右移还是逻辑右移，实际编译器多为算术右移（补符号位）。不建议对有符号负数右移。

### 异或的性质

异或是最「神奇」的位运算，满足

$$a \oplus a = 0, \qquad a \oplus 0 = a, \qquad a \oplus b = b \oplus a, \qquad (a \oplus b) \oplus c = a \oplus (b \oplus c)$$

由此可得：**一串数异或，出现偶数次的会被消掉，出现奇数次的会留下**。这是很多题的突破口。

## 4. 常用位运算技巧

### 4.1 判断与设置某一位

| 操作 | 写法 | 说明 |
|---|---|---|
| 取第 $k$ 位 | `(x >> k) & 1` | 结果为 0 或 1 |
| 取第 $k$ 位 | `x & (1 << k)` | 结果为 0 或 $2^k$ |
| 置第 $k$ 位为 1 | `x \|= (1 << k)` | |
| 置第 $k$ 位为 0 | `x &= ~(1 << k)` | |
| 反转第 $k$ 位 | `x ^= (1 << k)` | |

```cpp
int x = 0b1010;              // C++14 支持二进制字面量
int k = 1;
bool bit = (x >> k) & 1;     // 1
x |= (1 << 2);               // 1110
x &= ~(1 << 3);              // 0110
x ^= (1 << 0);               // 0111
```

### 4.2 常用恒等式

```cpp
x & (x - 1)      // 消掉最低位的 1
x & -x           // 取出最低位的 1（lowbit）
x | (x - 1)      // 把最低位的 1 及其右边全部变成 1
x & (x + 1)      // 把最低位连续的 1 变成 0（可判 x 是否为 2^k - 1）
x >> k << k      // 清掉最低 k 位
```

验证 `x & (x - 1)`：

```
x         = 1011000
x - 1     = 1010111
x & (x-1) = 1010000   ← 最低位的 1 被消掉
```

用它统计二进制中 1 的个数，循环次数等于 1 的个数：

```cpp
int popcount(int x) {
    int cnt = 0;
    while (x) { x &= x - 1; ++cnt; }
    return cnt;
}
```

### 4.3 异或交换与绝对值

```cpp
a ^= b; b ^= a; a ^= b;      // 交换，但 a、b 同地址时会被清零，实战用 swap
int mask = x >> 31;          // 负数得 -1（全 1），非负得 0
int abs_x = (x + mask) ^ mask;   // 不用分支的绝对值
```

## 5. lowbit 与树状数组

### 5.1 lowbit 的定义

$$\text{lowbit}(x) = x \ \& \ (-x)$$

它返回 $x$ 二进制中**最低位的 1 所对应的值**：

```
x      = 1011000
-x     = 0101000   （补码）
x & -x = 0001000 = 8
```

### 5.2 树状数组为什么需要 lowbit

树状数组 `c[i]` 维护区间 $(i - \text{lowbit}(i),\ i]$ 的和。修改时 `i += lowbit(i)` 向上跳，查询时 `i -= lowbit(i)` 向下跳，跳转次数都是 $O(\log n)$。

```cpp
int n, c[100005];
void add(int i, int v) {                 // 单点加
    for (; i <= n; i += i & -i) c[i] += v;
}
int query(int i) {                       // 前缀和
    int s = 0;
    for (; i > 0; i -= i & -i) s += c[i];
    return s;
}
int rangeSum(int l, int r) { return query(r) - query(l - 1); }
```

其他用到 lowbit 的地方：快速求二进制中 1 的个数（反复 `x -= x & -x`）、树状数组求第 $k$ 小（lowbit 倍增）。

## 6. 状态压缩中的位运算

一个 `int` 的 32 个位可以表示 $\{0, 1, \ldots, 31\}$ 的子集，例如集合 $\{0,2,3\}$ 对应二进制 `1101` 即十进制 13。

| 集合操作 | 位运算 |
|---|---|
| 加入元素 $i$ | `S \|= (1 << i)` |
| 删除元素 $i$ | `S &= ~(1 << i)` |
| 判断元素 $i$ 是否在 | `(S >> i) & 1` |
| 集合大小 | `popcount(S)` |
| 并集 / 交集 / 差集 / 对称差 | `A \| B` / `A & B` / `A & ~B` / `A ^ B` |

状态压缩 DP 的核心就是把「已访问集合」压进下标。以旅行商问题为例，`dp[S][i]` 表示已访问集合为 `S`、当前在 $i$ 的最短路径：

```cpp
for (int S = 1; S < (1 << n); ++S)
    for (int i = 0; i < n; ++i) {
        if (!((S >> i) & 1)) continue;          // i 必须在 S 中
        for (int j = 0; j < n; ++j) {
            if ((S >> j) & 1) continue;          // j 必须不在 S 中
            dp[S | (1 << j)][j] = min(dp[S | (1 << j)][j], dp[S][i] + d[i][j]);
        }
    }
```

## 7. 枚举子集与二进制枚举

### 7.1 二进制枚举

用 $0 \sim 2^n - 1$ 的每个整数代表一个子集，复杂度 $O(n \cdot 2^n)$：

```cpp
for (int S = 0; S < (1 << n); ++S)
    for (int i = 0; i < n; ++i)
        if ((S >> i) & 1) { /* 元素 i 在子集中 */ }
```

### 7.2 枚举子集的子集

给定集合 `S`，枚举它的所有非空子集：

```cpp
for (int sub = S; sub; sub = (sub - 1) & S) {
    // sub 是 S 的一个非空子集
}
```

**原理**：`sub - 1` 把最低位的 1 借位，`& S` 把不属于 `S` 的位清零，于是从大到小枚举所有子集。总复杂度 $O(3^n)$，因为每个元素有三种状态（不在 S / 在 S 但不在 sub / 在 sub）。

## 8. 模板代码

### 8.1 位运算工具函数集

```cpp
#include <bits/stdc++.h>
using namespace std;
int popcount(int x) {                       // 二进制中 1 的个数
    int cnt = 0;
    while (x) { x &= x - 1; ++cnt; }
    return cnt;
}
inline int lowbit(int x) { return x & -x; } // 最低位的 1
bool isPowerOfTwo(int x) {                  // 是否为 2 的幂
    return x > 0 && (x & (x - 1)) == 0;
}
inline bool getBit(int x, int k)   { return (x >> k) & 1; }
inline int  setBit(int x, int k)   { return x | (1 << k); }
inline int  clearBit(int x, int k) { return x & ~(1 << k); }
inline int  flipBit(int x, int k)  { return x ^ (1 << k); }
int main() {
    cout << popcount(13) << '\n';       // 3
    cout << lowbit(12) << '\n';         // 4
    cout << isPowerOfTwo(16) << '\n';   // 1
    cout << getBit(13, 2) << '\n';      // 1
    cout << setBit(8, 1) << '\n';       // 10
    cout << clearBit(10, 1) << '\n';    // 8
    cout << flipBit(10, 0) << '\n';     // 11
    return 0;
}
```

### 8.2 二进制枚举模板

```cpp
int main() {
    int n;
    cin >> n;                                  // n ≤ 20
    vector<int> a(n);
    for (int& x : a) cin >> x;
    int best = INT_MIN;
    for (int S = 0; S < (1 << n); ++S) {
        int sum = 0;
        for (int i = 0; i < n; ++i)
            if ((S >> i) & 1) sum += a[i];
        best = max(best, sum);
    }
    cout << best << '\n';
    return 0;
}
```

### 8.3 状态压缩 DP 模板（TSP）

```cpp
const int INF = 0x3f3f3f3f;
int main() {
    int n;
    cin >> n;
    vector<vector<int>> d(n, vector<int>(n));
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j) cin >> d[i][j];
    vector<vector<int>> dp(1 << n, vector<int>(n, INF));
    dp[1][0] = 0;                               // 从 0 号点出发
    for (int S = 1; S < (1 << n); ++S)
        for (int i = 0; i < n; ++i) {
            if (dp[S][i] == INF) continue;
            for (int j = 0; j < n; ++j) {
                if ((S >> j) & 1) continue;
                int nS = S | (1 << j);
                dp[nS][j] = min(dp[nS][j], dp[S][i] + d[i][j]);
            }
        }
    int ans = INF;
    for (int i = 0; i < n; ++i) ans = min(ans, dp[(1 << n) - 1][i] + d[i][0]);
    cout << ans << '\n';
    return 0;
}
```

## 9. 经典例题

### 例题 1：只出现一次的数字

**题意**：给定 $n$ 个整数，除一个数只出现一次外，其余都出现两次，找出那个只出现一次的数。

**思路**：把所有数异或起来。相同的数异或为 0，最后剩下就是答案（$a\oplus a=0$，$a\oplus 0=a$）。

**复杂度**：时间 $O(n)$，空间 $O(1)$。

```cpp
int singleNumber(vector<int>& nums) {
    int ans = 0;
    for (int x : nums) ans ^= x;
    return ans;
}
```

### 例题 2：统计二进制中 1 的个数

**题意**：给定 $n$（$n \le 10^9$），输出其二进制表示中 1 的个数。

**思路**：Brian Kernighan 算法，每次 `x &= x - 1` 消掉最低位的 1，循环次数等于 1 的个数。

**复杂度**：$O(\log n)$，最坏约 30 次。

```cpp
int hammingWeight(int n) {
    int cnt = 0;
    while (n) { n &= n - 1; ++cnt; }
    return cnt;
}
```

### 例题 3：小于等于 n 的最大 2 的幂

**题意**：给定正整数 $n$，求最大的 $2^k \le n$。

**思路**：不断倍增直到超过 $n$，再回退一步。也可用 `1 << (31 - __builtin_clz(n))`。

**复杂度**：$O(\log n)$。

```cpp
int largestPowerOfTwo(int n) {
    int x = 1;
    while (x * 2 <= n) x *= 2;
    return x;
}
```

### 例题 4：二进制枚举子集求和

**题意**：给定 $n$（$n \le 20$）个整数，问有多少个非空子集的和等于 0。

**思路**：枚举 $0 \sim 2^n-1$ 的每个掩码，统计元素之和，判断是否为 0 且非空。

**复杂度**：$O(n2^n)$。

```cpp
int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int& x : a) cin >> x;
    int ans = 0;
    for (int S = 1; S < (1 << n); ++S) {
        long long sum = 0;
        for (int i = 0; i < n; ++i)
            if ((S >> i) & 1) sum += a[i];
        if (sum == 0) ++ans;
    }
    cout << ans << '\n';
    return 0;
}
```

## 10. 易错点

1. **运算符优先级**：`&`、`|`、`^` 优先级低于 `==`，必须写 `(x & 1) == 0`。
2. **`1 << 31` 溢出**：`int` 只有 31 位可用，写 `1LL << 31` 或 `1u << 31`。
3. **移位超过位宽**：`x << 32` 是未定义行为。
4. **负数右移**：`>>` 对有符号负数是实现定义的，避免使用。
5. **`~0` 是 `-1`**：全 1，不是 1。
6. **异或交换同变量**：`a ^= a` 会把 `a` 清零，实战用 `swap`。
7. **`x & -x` 在 `x = 0` 时**：结果是 0，若用于循环 `i += lowbit(i)` 会死循环。
8. **`1 << n` 的类型**：`n` 较大时用 `1LL << n`；状态压缩一般 $n \le 20$。
9. **`popcount` 参数类型**：`__builtin_popcount` 对 `long long` 要用 `__builtin_popcountll`。
10. **二进制字面量**：C++14 才支持 `0b1010`，老编译器不支持。
11. **`unsigned` 与 `int` 混用**：比较时会把 `int` 转成 `unsigned`，负数变成巨大正数。

## 11. 练习建议

### 11.1 学习路线（由易到难）

1. **二进制与补码**：手写十进制转二进制、负数补码。
2. **基本运算**：判奇偶、取某位、统计 1 的个数。
3. **lowbit 技巧**：`x & -x`、`x & (x-1)`。
4. **异或性质**：只出现一次的数字、找不同。
5. **二进制枚举**：子集和、集合覆盖。
6. **状态压缩 DP**：TSP、棋盘覆盖。
7. **枚举子集的子集**：`for (sub = S; sub; sub = (sub-1) & S)`。
