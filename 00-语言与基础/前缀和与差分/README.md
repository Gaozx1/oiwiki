# 前缀和与差分

> 一句话概括：**前缀和把「区间求和」从 $O(n)$ 降到 $O(1)$，差分把「区间加值」从 $O(n)$ 降到 $O(1)$，两者互为逆运算，是区间问题最基础的两把刀。**

## 1. 从一道题说起

**题目**：给定长度为 $n$ 的数组，$q$ 次询问区间 $[l, r]$ 的和。$n, q \le 10^5$。

**暴力**：每次从 $l$ 加到 $r$，单次 $O(n)$，总 $O(nq) = 10^{10}$，超时。

**优化**：预处理一个数组 $S$，令

$$S_i = \sum_{k=1}^{i} a_k$$

则

$$\sum_{k=l}^{r} a_k = S_r - S_{l-1}$$

每次询问 $O(1)$，预处理 $O(n)$，总 $O(n + q)$。

这就是**前缀和**。它把「多次区间查询」的重复计算预先算好，是「空间换时间」最经典的例子。

## 2. 一维前缀和

### 2.1 定义

设 $a_1, a_2, \ldots, a_n$，前缀和数组 $S$ 定义为

$$S_0 = 0, \qquad S_i = S_{i-1} + a_i \quad (1 \le i \le n)$$

则区间和

$$\text{sum}(l, r) = S_r - S_{l-1}$$

### 2.2 为什么从 1 开始存

因为 $S_{l-1}$ 在 $l = 1$ 时要取 $S_0 = 0$。把数组从 1 开始编号并令 `S[0] = 0`，就统一了所有情况，不用特判。预处理 $O(n)$、单次查询 $O(1)$、空间 $O(n)$。

```
下标:  0   1   2   3   4   5
a:         3   1   4   1   5
S:     0   3   4   8   9   14
sum(2, 4) = S[4] - S[1] = 9 - 3 = 6 = 1 + 4 + 1 ✓
```

$S_i$ 可能很大：$n = 10^6$、$a_i = 10^9$ 时 $S_n = 10^{15}$，必须用 `long long`。

```cpp
int a[1000005];
long long S[1000005];    // 注意类型
```

## 3. 二维前缀和

### 3.1 定义

设矩阵 $a_{i,j}$（$1 \le i \le n$，$1 \le j \le m$），二维前缀和

$$S_{i,j} = \sum_{x=1}^{i}\sum_{y=1}^{j} a_{x,y}$$

### 3.2 递推公式

用容斥原理：

$$S_{i,j} = S_{i-1,j} + S_{i,j-1} - S_{i-1,j-1} + a_{i,j}$$

文字理解：上面一块 + 左边一块 − 左上角重复算的部分 + 当前格子。

```
+-----------+---+
|  S(i-1,j) |   |
|     -     |   |
|  S(i,j-1) |aij|
+-----------+---+
```

### 3.3 子矩阵求和

以 $(x_1, y_1)$ 为左上角、$(x_2, y_2)$ 为右下角的子矩阵和：

$$\text{sum} = S_{x_2,y_2} - S_{x_1-1,y_2} - S_{x_2,y_1-1} + S_{x_1-1,y_1-1}$$

同样用容斥：大矩形 − 上方 − 左侧 + 左上角（被减了两次）。

```
      y1         y2
  +----+----------+
  |    |          |
x1|    | 目标区域  |
  |    |          |
  +----+----------+
x2|    |          |
  +----+----------+
```

## 4. 差分数组

### 4.1 问题

给定数组 $a$，$q$ 次操作：把区间 $[l, r]$ 内所有元素加 $v$。最后输出整个数组。

**暴力**：每次循环 $l \sim r$，单次 $O(n)$，总 $O(nq)$。

**差分**：令

$$d_1 = a_1, \qquad d_i = a_i - a_{i-1} \quad (i \ge 2)$$

则 $a_i = \sum_{k=1}^{i} d_k$，即 **$a$ 是 $d$ 的前缀和**。

### 4.2 区间加法的 $O(1)$ 操作

对 $[l, r]$ 加 $v$：

```cpp
d[l] += v;
d[r + 1] -= v;
```

**为什么**：$d_l$ 增加 $v$ 会让 $a_l, a_{l+1}, \ldots$ 全部加 $v$；$d_{r+1}$ 减少 $v$ 会把这个影响从 $r+1$ 起抵消掉。正好只影响 $[l, r]$。

```
a:  3  1  4  1  5
d:  3 -2  3 -3  4
对 [2,4] 加 10：
d:  3  8  3 -3 -6
a': 3 11 14 11  5    ✓
```

### 4.3 差分与前缀和的关系

**前缀和**由「点值」求「区间和」，**差分**由「区间加」求「点值」，两者是**互逆运算**：

$$
a \xrightarrow{\ \text{差分}\ } d \xrightarrow{\ \text{前缀和}\ } a
$$

## 5. 二维差分

### 5.1 子矩阵加法

对矩阵中左上角 $(x_1, y_1)$、右下角 $(x_2, y_2)$ 的子矩阵全部加 $v$：

```cpp
d[x1][y1] += v;
d[x1][y2 + 1] -= v;
d[x2 + 1][y1] -= v;
d[x2 + 1][y2 + 1] += v;
```

四个角对应二维容斥的四个项。最后对 $d$ 做二维前缀和还原矩阵。

### 5.2 验证

```
d 的影响（四个角）：
      y1        y2+1
  +----+----------+
  | +v |    -v    |
x1+----+----------+
  | -v |    +v    |
x2+----+----------+
```

四个区域叠加后，只有 $[x_1, x_2] \times [y_1, y_2]$ 内的格子得到 $+v$，其余为 0。

## 6. 前缀和与差分的对偶关系

| 操作 | 工具 | 预处理 | 单次 |
|---|---|---|---|
| 区间求和 | 前缀和 | $O(n)$ | $O(1)$ |
| 区间加值 | 差分 | $O(n)$ | $O(1)$ |
| 区间加值 + 区间求和 | 树状数组 / 线段树 | $O(n\log n)$ | $O(\log n)$ |

**核心直觉**：

- 前缀和数组的第 $i$ 项 = 原数组前 $i$ 项之和；
- 差分数组的第 $i$ 项 = 原数组第 $i$ 项与第 $i-1$ 项之差；
- 求前缀和与求差分互为逆运算。

**进阶**：若既要区间加又要区间求和，维护两个树状数组，或直接用线段树（懒标记）。

## 7. 模板代码

### 7.1 一维前缀和

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 100005;
int n, q;
long long a[MAXN], S[MAXN];
int main() {
    cin >> n >> q;
    for (int i = 1; i <= n; ++i) cin >> a[i];
    for (int i = 1; i <= n; ++i)
        S[i] = S[i - 1] + a[i];              // 预处理前缀和
    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << S[r] - S[l - 1] << '\n';     // O(1) 查询
    }
    return 0;
}
```

### 7.2 二维前缀和

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 1005;
int n, m, q;
long long a[MAXN][MAXN], S[MAXN][MAXN];
int main() {
    cin >> n >> m >> q;
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= m; ++j) cin >> a[i][j];
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= m; ++j)
            S[i][j] = S[i - 1][j] + S[i][j - 1] - S[i - 1][j - 1] + a[i][j];
    while (q--) {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        cout << S[x2][y2] - S[x1 - 1][y2] - S[x2][y1 - 1] + S[x1 - 1][y1 - 1] << '\n';
    }
    return 0;
}
```

### 7.3 一维差分

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 100005;
long long a[MAXN], d[MAXN];
int main() {
    int n, q;
    cin >> n >> q;
    for (int i = 1; i <= n; ++i) cin >> a[i];
    for (int i = 1; i <= n; ++i) d[i] = a[i] - a[i - 1];   // 构造差分数组
    while (q--) {
        int l, r, v;
        cin >> l >> r >> v;
        d[l] += v;
        d[r + 1] -= v;                                      // 区间加 v，O(1)
    }
    long long cur = 0;
    for (int i = 1; i <= n; ++i) {
        cur += d[i];                                        // 前缀和还原
        cout << cur << ' ';
    }
    return 0;
}
```

### 7.4 二维差分

```cpp
const int MAXN = 1005;
long long d[MAXN][MAXN];
int main() {
    int n, m, q;
    cin >> n >> m >> q;
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= m; ++j) {
            long long x;
            cin >> x;
            d[i][j] += x;            // 初始矩阵也看成一次「单点差分」
            d[i + 1][j] -= x;
            d[i][j + 1] -= x;
            d[i + 1][j + 1] += x;
        }
    while (q--) {
        int x1, y1, x2, y2;
        long long v;
        cin >> x1 >> y1 >> x2 >> y2 >> v;
        d[x1][y1] += v;              // 四个角：二维容斥
        d[x1][y2 + 1] -= v;
        d[x2 + 1][y1] -= v;
        d[x2 + 1][y2 + 1] += v;
    }
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= m; ++j) {
            d[i][j] += d[i - 1][j] + d[i][j - 1] - d[i - 1][j - 1];  // 二维前缀和还原
            cout << d[i][j] << " \n"[j == m];
        }
    return 0;
}
```

## 8. 经典例题

### 例题 1：区间求和

**题意**：给定长度为 $n$（$n \le 10^5$）的数组，$q$ 次询问 $[l, r]$ 的和。

**思路**：前缀和预处理，每次 $O(1)$ 查询。**复杂度**：$O(n + q)$。（代码见 7.1 一维前缀和模板。）

### 例题 2：最大子段和（前缀和版）

**题意**：给定长度为 $n$ 的整数序列，求连续子段的最大和。

**思路**：子段和 $= S_r - S_{l-1}$。固定 $r$，要最大化 $S_r - S_{l-1}$，即让 $S_{l-1}$ 最小。边扫边维护 $S$ 的前缀最小值。**复杂度**：$O(n)$。

```cpp
int main() {
    int n;
    cin >> n;
    long long S = 0, minS = 0, ans = LLONG_MIN;
    for (int i = 0; i < n; ++i) {
        long long x;
        cin >> x;
        S += x;
        ans = max(ans, S - minS);   // 以当前位置结尾的最大子段和
        minS = min(minS, S);         // 更新前缀最小值
    }
    cout << ans << '\n';
    return 0;
}
```

### 例题 3：差分模板

**题意**：给定长度为 $n$ 的数组，$q$ 次操作，每次把 $[l, r]$ 内所有数加 $v$，最后输出数组。

**思路**：差分数组 $d_l += v$、$d_{r+1} -= v$，最后前缀和还原。

**复杂度**：$O(n + q)$。

（代码见上文「一维差分」模板。）

### 例题 4：借教室

**题意**：有 $n$ 天，第 $i$ 天有 $r_i$ 间教室可用。有 $m$ 份订单，第 $j$ 份需要从第 $s_j$ 天到第 $t_j$ 天每天借 $d_j$ 间教室。按顺序处理订单，问第一份无法满足的订单编号。

**思路**：二分答案 + 差分检验。二分前 $k$ 份订单能否满足：用差分数组把前 $k$ 份订单的每日需求累加，再与 $r_i$ 比较。**复杂度**：$O((n + m)\log m)$。

```cpp
int n, m;
vector<int> r, d, s, t;
bool check(int k) {
    vector<long long> diff(n + 2, 0);
    for (int i = 1; i <= k; ++i) { diff[s[i]] += d[i]; diff[t[i] + 1] -= d[i]; }
    long long cur = 0;
    for (int i = 1; i <= n; ++i) { cur += diff[i]; if (cur > r[i]) return false; }
    return true;
}
int main() {
    cin >> n >> m;
    r.assign(n + 1, 0); d.assign(m + 1, 0);
    s.assign(m + 1, 0); t.assign(m + 1, 0);
    for (int i = 1; i <= n; ++i) cin >> r[i];
    for (int i = 1; i <= m; ++i) cin >> d[i] >> s[i] >> t[i];
    if (check(m)) { cout << 0 << '\n'; return 0; }
    int lo = 1, hi = m;
    while (lo < hi) {
        int mid = (lo + hi) >> 1;
        if (check(mid)) lo = mid + 1;
        else hi = mid;
    }
    cout << lo << '\n';
    return 0;
}
```

## 9. 易错点

1. **下标从 0 开始却用 `S[i-1]`**：`i = 0` 时越界。统一从 1 开始存。
2. **忘记 `S[0] = 0`**：查询 `[1, r]` 时会读到未初始化值。
3. **`int` 溢出**：$10^6$ 个 $10^9$ 加起来是 $10^{15}$，必须 `long long`。
4. **二维容斥符号写错**：`S[i-1][j] + S[i][j-1] - S[i-1][j-1]`，最后是减不是加。
5. **差分 `r + 1` 越界**：数组要开到 `n + 2`。
6. **差分只更新不还原**：最后必须做一次前缀和。
7. **多次操作后忘记清空**：多组数据要重置差分数组。
8. **区间加的边界**：`[l, r]` 对应 `d[l] += v` 与 `d[r+1] -= v`，不是 `d[r] -= v`。
9. **二维差分四个角写漏**：少一个角就会影响其他区域。
10. **前缀和与原数组混用**：`S[i]` 是「前 i 项和」，不是「第 i 项」。
11. **负数取模**：差分值可能为负，若参与取模要 `(x % MOD + MOD) % MOD`。
12. **数组开太小**：`MAXN = 100005` 却要处理 $10^6$，开数组前看数据范围。

## 10. 练习建议

### 10.1 学习路线（由易到难）

1. **一维前缀和**：区间求和、前缀最大值。
2. **二维前缀和**：子矩阵求和。
3. **一维差分**：区间加、最后输出。
4. **二维差分**：子矩阵加。
5. **前缀和 + 单调性**：最大子段和、和为 k 的子数组。
6. **二分 + 差分**：借教室、区间覆盖判定。
7. **进阶**：树状数组、线段树。
