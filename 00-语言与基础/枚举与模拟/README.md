## 1. 枚举与模拟是什么

### 1.1 枚举（Enumeration / Brute Force）

**枚举**就是**穷举所有可能的解**，逐个检验是否满足条件，取最优或计数。

$$ans = \max\{\, f(x) \mid x \in \mathcal{X},\ x \text{ 满足约束} \,\}$$

它的正确性来自「不重不漏」：只要枚举范围覆盖了全部候选，且检查函数正确，答案就一定对。

### 1.2 模拟（Simulation）

**模拟**就是**用代码复现题目描述的过程**：给定初始状态和操作规则，一步步推进，直到得到终态。

它没有固定模板，全靠对题意的精确翻译。**模拟题的难点从来不是算法，而是细节。**

### 1.3 二者的关系

| 维度 | 枚举 | 模拟 |
|---|---|---|
| 核心 | 遍历候选解 | 复现过程 |
| 正确性 | 不重不漏 | 忠实翻译 |
| 复杂度 | 取决于搜索空间 | 取决于推进步数 |
| 典型题 | 百钱买百鸡、全排列 | 扫雷、机器人行走、日期计算 |

一道题往往**既枚举又模拟**：枚举操作顺序，模拟每次操作的结果。

## 2. 枚举的要素与优化

### 2.1 确定枚举对象

先问自己：**「答案由什么决定？」** 决定答案的那组变量就是枚举对象。

例如「百钱买百鸡」：公鸡 $x$ 只、母鸡 $y$ 只、小鸡 $z$ 只，约束

$$
\begin{cases}
x + y + z = 100 \\
5x + 3y + z/3 = 100 \\
x, y, z \ge 0
\end{cases}
$$

枚举对象可以选 $(x, y)$，$z$ 由 $z = 100 - x - y$ 推出，这样只需两重循环。

### 2.2 确定枚举范围

范围要**刚好覆盖所有可能**，不能漏也不能多：公鸡最多 $100/5 = 20$ 只、母鸡最多 $100/3 \approx 33$ 只、小鸡数量必须是 3 的倍数。范围收缩往往能把复杂度从 $O(n^3)$ 降到 $O(n^2)$。

### 2.3 枚举顺序与剪枝

- **字典序**：要求输出所有方案时，通常按字典序从小到大枚举；**剪枝**：提前判断「已经不可能成为答案」的分支，直接跳过。

```cpp
for (int x = 0; x <= 20; ++x) {
    for (int y = 0; y <= 33; ++y) {
        int z = 100 - x - y;
        if (z < 0 || z % 3 != 0) continue;      // 剪枝
        if (5 * x + 3 * y + z / 3 == 100)
            cout << x << ' ' << y << ' ' << z << '\n';
    }
}
```

### 2.4 枚举的复杂度估算

枚举的复杂度 = **候选解数量 × 单个候选的检验代价**。候选数 $10^7$ 且检验 $O(1)$ 约 0.1 秒，可以；候选数 $10^9$ 无论检验多快都会超时。

## 3. 模拟的要素与实现

### 3.1 状态、规则与终止条件

模拟的第一步是**明确「状态」**：哪些变量在变化？例如「机器人行走」：位置 $(x, y)$、朝向 $d$、步数 $t$ 都是状态。然后把题目规则拆成**互不重叠的小步骤**，每步对应一个函数：

```cpp
void moveForward();      // 前进一格
void turnLeft();         // 左转 90°
void turnRight();        // 右转 90°
```

模拟最容易出错的三个地方：**越界**（走出地图、下标为负）、**死循环**（状态重复却没设终止条件）、**多组数据忘记清空**。

### 3.2 用「方向数组」简化移动

```cpp
// 上、右、下、左
const int dx[4] = {-1, 0, 1, 0};
const int dy[4] = {0, 1, 0, -1};
int x = 0, y = 0, d = 1;      // 初始朝右
x += dx[d];
y += dy[d];                   // 前进一步
d = (d + 1) % 4;              // 右转
d = (d + 3) % 4;              // 左转
```

这是所有网格模拟题的「标准件」。

## 4. 枚举的常见类型

- **循环枚举**：最朴素的形式，适合枚举对象少（1~3 个）且范围小的情况。
- **排列枚举**：用 `next_permutation` 枚举 $1 \sim n$ 的所有排列，复杂度 $O(n!)$，只适合 $n \le 9$ 左右。

```cpp
vector<int> p(n);
iota(p.begin(), p.end(), 1);          // 1, 2, ..., n
do {
    // 处理排列 p
} while (next_permutation(p.begin(), p.end()));
```

- **子集枚举**：用二进制掩码枚举所有子集（详见「位运算」一章），复杂度 $O(2^n)$，适合 $n \le 20$。

```cpp
for (int S = 0; S < (1 << n); ++S) { /* 处理子集 S */ }
```

- **枚举答案**：有时枚举对象不是输入而是**答案本身**。求最小的 $x$ 使条件成立时，从小到大枚举 $x$，第一个满足的就是答案；若答案有单调性，用二分代替枚举（从 $O(n)$ 降到 $O(\log n)$）。

## 5. 模拟的常见类型

- **过程模拟**：按时间顺序推进，如「模拟队列操作」「模拟银行叫号」。
- **网格模拟**：在二维网格上移动、染色、扩散（BFS 也是网格模拟的一种）。
- **大数模拟**：手写高精度加、减、乘、除（详见数学章节），本质是模拟竖式运算。

**日期时间模拟**需要单独小心：计算两个日期相差几天、某天是星期几时，建议**把日期转成「从公元 1 年 1 月 1 日到今天的天数」**，统一比较。

```cpp
bool isLeap(int y) {
    return (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);
}
int daysInMonth(int y, int m) {
    static const int d[] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    if (m == 2 && isLeap(y)) return 29;
    return d[m];
}
```

## 6. 搜索：枚举的升级版

当枚举空间是**树形**的（每个选择会引出新的选择），就用搜索：

```cpp
void dfs(int step, int state) {
    if (step == n) {                     // 到达叶子，检验答案
        check(state);
        return;
    }
    for (int choice : candidates) {      // 枚举当前所有选择
        dfs(step + 1, state + choice);   // 进入下一层
    }
}
```

**DFS** 适合找「所有方案」或「是否存在」；**BFS** 适合找「最少步数」。搜索与枚举的区别只在于**枚举空间的形状**。

## 7. 模板代码

### 7.1 枚举模板

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int& x : a) cin >> x;
    long long ans = LLONG_MIN;
    for (int i = 0; i < n; ++i) {              // 枚举左端点
        long long sum = 0;
        for (int j = i; j < n; ++j) {          // 枚举右端点
            sum += a[j];
            ans = max(ans, sum);
        }
    }
    cout << ans << '\n';
    return 0;
}
```

### 7.2 方向数组与网格模拟

```cpp
#include <bits/stdc++.h>
using namespace std;
const int dx[4] = {-1, 0, 1, 0};   // 上右下左
const int dy[4] = {0, 1, 0, -1};
int main() {
    int n, m;
    cin >> n >> m;
    vector<string> g(n);
    for (auto& row : g) cin >> row;
    int x = 0, y = 0;
    while (true) {
        char c = g[x][y];
        g[x][y] = '#';                       // 标记已访问，防止死循环
        int d = (c == 'U') ? 0 : (c == 'R') ? 1 : (c == 'D') ? 2 : 3;
        int nx = x + dx[d], ny = y + dy[d];
        if (nx < 0 || nx >= n || ny < 0 || ny >= m) break;   // 越界终止
        x = nx; y = ny;
    }
    cout << x + 1 << ' ' << y + 1 << '\n';
    return 0;
}
```

### 7.3 日期模拟模板

```cpp
#include <bits/stdc++.h>
using namespace std;
bool isLeap(int y) {
    return (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);
}
int daysInMonth(int y, int m) {
    static const int d[] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    if (m == 2 && isLeap(y)) return 29;
    return d[m];
}
int main() {
    int y, m, d;
    cin >> y >> m >> d;
    ++d;
    if (d > daysInMonth(y, m)) {
        d = 1;
        if (++m > 12) { m = 1; ++y; }
    }
    printf("%d-%02d-%02d\n", y, m, d);
    return 0;
}
```

### 7.4 全排列枚举模板

```cpp
int main() {
    int n;
    cin >> n;
    vector<int> p(n);
    iota(p.begin(), p.end(), 1);
    do {
        for (int i = 0; i < n; ++i) cout << p[i] << " \n"[i == n - 1];
    } while (next_permutation(p.begin(), p.end()));
    return 0;
}
```

## 8. 经典例题

### 例题 1：百钱买百鸡

**题意**：公鸡 5 元一只，母鸡 3 元一只，小鸡 1 元三只。用 100 元买 100 只鸡，问公鸡、母鸡、小鸡各多少只。

**思路**：枚举公鸡 $x \in [0, 20]$、母鸡 $y \in [0, 33]$，小鸡 $z = 100 - x - y$。判断 $z \ge 0$、$z \bmod 3 = 0$ 且 $5x + 3y + z/3 = 100$。

**复杂度**：$O(21 \times 34) \approx O(700)$。

```cpp
for (int x = 0; x <= 20; ++x)
    for (int y = 0; y <= 33; ++y) {
        int z = 100 - x - y;
        if (z >= 0 && z % 3 == 0 && 5 * x + 3 * y + z / 3 == 100)
            cout << x << ' ' << y << ' ' << z << '\n';
    }
```

### 例题 2：蛇形填数

**题意**：在 $n \times n$ 的方阵中按蛇形顺序填入 $1 \sim n^2$：先向右，再向下，再向左，再向上，依此类推。

**思路**：用方向数组 `(0,1) (1,0) (0,-1) (-1,0)`，每次尝试走一步；若越界或已填过，就右转。共填 $n^2$ 个数。

**复杂度**：$O(n^2)$。

```cpp
int main() {
    int n;
    cin >> n;
    vector<vector<int>> a(n, vector<int>(n, 0));
    int dx[4] = {0, 1, 0, -1}, dy[4] = {1, 0, -1, 0};
    int x = 0, y = 0, d = 0;
    for (int k = 1; k <= n * n; ++k) {
        a[x][y] = k;
        int nx = x + dx[d], ny = y + dy[d];
        if (nx < 0 || nx >= n || ny < 0 || ny >= n || a[nx][ny]) {
            d = (d + 1) % 4;
            nx = x + dx[d];
            ny = y + dy[d];
        }
        x = nx; y = ny;
    }
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < n; ++j) cout << a[i][j] << ' ';
        cout << '\n';
    }
    return 0;
}
```

### 例题 3：扫雷

**题意**：给定一个 $n \times m$ 的雷区，`*` 表示雷，`.` 表示空地。输出每个格子周围 8 格的雷数（雷格输出 `*`）。

**思路**：对每个非雷格子，遍历 8 个方向统计雷数。注意边界判断。

**复杂度**：$O(nm)$。

```cpp
int main() {
    int n, m;
    cin >> n >> m;
    vector<string> g(n);
    for (auto& row : g) cin >> row;
    int dx[8] = {-1,-1,-1,0,0,1,1,1};
    int dy[8] = {-1,0,1,-1,1,-1,0,1};
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < m; ++j) {
            if (g[i][j] == '*') { cout << '*'; continue; }
            int cnt = 0;
            for (int k = 0; k < 8; ++k) {
                int ni = i + dx[k], nj = j + dy[k];
                if (ni >= 0 && ni < n && nj >= 0 && nj < m && g[ni][nj] == '*') ++cnt;
            }
            cout << cnt;
        }
        cout << '\n';
    }
    return 0;
}
```

### 例题 4：下一个排列

**题意**：给定一个排列，求按字典序的下一个排列；若已是最后一个，输出最小的排列。

**思路**：手写 `next_permutation` 的逻辑：从右往左找第一个「升序对」$a_i < a_{i+1}$；再从右往左找第一个大于 $a_i$ 的数 $a_j$；交换后把 $i+1$ 到末尾反转。也可直接用 STL。

**复杂度**：$O(n)$。

```cpp
int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int& x : a) cin >> x;
    // 等价于 next_permutation(a.begin(), a.end());
    int i = n - 2;
    while (i >= 0 && a[i] >= a[i + 1]) --i;
    if (i >= 0) {
        int j = n - 1;
        while (a[j] <= a[i]) --j;
        swap(a[i], a[j]);
    }
    reverse(a.begin() + i + 1, a.end());
    for (int x : a) cout << x << ' ';
    return 0;
}
```

## 9. 易错点

1. **枚举范围漏边界**：`i < n` 还是 `i <= n`，检查「最大值」和「最小值」两个端点是否覆盖。
2. **漏掉某种情况**：如「百钱买百鸡」漏了 $z \bmod 3 = 0$ 的检查。
3. **模拟方向数组顺序写错**：上右下左与右下左上完全不同，画图确认。
4. **越界未判断**：网格模拟前先检查 `nx`、`ny` 是否在 `[0, n)`、`[0, m)`。
5. **死循环**：状态可能重复时，用 `vis` 数组标记或设步数上限。
6. **多组数据忘清空**：每轮模拟前重置所有状态变量。
7. **全排列 `do-while` 而非 `while`**：`next_permutation` 返回 false 时已经回到第一个排列，`do-while` 保证空排列也被处理。
8. **`next_permutation` 需要初始有序**：从乱序开始只会枚举「从当前排列往后」的排列。
9. **整数除法的取整方向**：模拟「平均分」时注意向下取整。
10. **日期模拟的闰年与月份**：2 月天数、跨年跨月都要单独处理。
11. **输出格式**：多组答案之间是否有空行、末尾是否有空格。
12. **模拟规模太大**：$10^9$ 步的模拟必然超时，要找规律或矩阵快速幂。

## 10. 练习建议

### 10.1 学习路线（由易到难）

1. **简单枚举**：求约数、判素数、找最大值。
2. **双重循环枚举**：百钱买百鸡、两数之和。
3. **全排列 / 子集枚举**：枚举所有方案。
4. **简单模拟**：日期计算、进制转换。
5. **网格模拟**：蛇形填数、扫雷、机器人行走。
6. **带剪枝的枚举**：提前终止、可行性剪枝。
7. **搜索**：DFS/BFS 枚举所有路径。

### 10.2 刷题清单

|---|---|---|
| 入门 | 洛谷 P1008 三连击 | 循环枚举 |

### 10.3 学习检查清单

- [ ] 能说清「枚举对象、枚举范围、检验条件」三要素
- [ ] 能用剪枝把枚举范围缩小
- [ ] 能熟练使用方向数组
- [ ] 能处理网格模拟的边界与死循环
- [ ] 会写日期模拟
- [ ] 会用 `next_permutation` 枚举全排列
- [ ] 知道什么时候该用搜索代替枚举

> **核心思想**：枚举和模拟是「笨办法」，但**笨办法往往最可靠**。先把暴力写对拿到部分分，再考虑优化——这是 OI 最实用的策略。
