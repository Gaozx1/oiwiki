## 1. 公平组合游戏

**定义**：满足以下条件的游戏：

1. 两名玩家轮流操作；
2. 每名玩家在轮到时的**可选操作集合只与当前局面有关**（与是谁无关）；
3. 无法操作者**判负**（正常规则）。

**P 态（必败态）**：当前局面下，先手必败。
**N 态（必胜态）**：当前局面下，先手必胜。

**判定**：

- 终局（无操作）是 P 态；
- 能一步走到 P 态的局面是 N 态；
- 所有可达局面都是 N 态的局面是 P 态。

## 2. Nim 博弈

**问题**：有 $n$ 堆石子，第 $i$ 堆有 $a_i$ 个。两人轮流从某一堆取任意多个（至少 1 个），取不了者负。

**结论（Nim 和 / Bouton 定理）**：

$$
\text{必败} \iff a_1 \oplus a_2 \oplus \cdots \oplus a_n = 0
$$

其中 $\oplus$ 是异或。

### 证明思路

- 若异或和为 0：任何操作都会让异或和变为非 0；
- 若异或和非 0：总能找到一堆，取走一些使其异或和变为 0。

### 代码

```cpp
int x = 0;
for (int i = 1; i <= n; ++i) x ^= a[i];
if (x == 0) puts("Second");   // 后手胜
else puts("First");           // 先手胜
```

### 先手必胜的第一步

找到最高位的 1，选一堆在该位为 1 的，取走使其变为 $a_i \oplus x$：

```cpp
if (x != 0) {
    for (int i = 1; i <= n; ++i) {
        if ((a[i] ^ x) < a[i]) {
            printf("%d %d\n", i, a[i] - (a[i] ^ x));
            break;
        }
    }
}
```

## 3. SG 函数

**定义**：对于局面 $x$，

$$
SG(x) = \text{mex}\{ SG(y) \mid y \text{ 是 } x \text{ 的后继局面} \}
$$

`mex` = 最小的非负整数集合中不存在的数。

**性质**：

- $SG(x) = 0$ 当且仅当 $x$ 是 P 态；
- 终局 $SG = 0$。

### 例：取石子（每次取 1~3 个）

```cpp
int sg[N];
bool vis[N];

void getSG(int n) {
    sg[0] = 0;
    for (int i = 1; i <= n; ++i) {
        memset(vis, 0, sizeof vis);
        for (int j = 1; j <= 3 && i - j >= 0; ++j)
            vis[sg[i - j]] = true;
        for (int j = 0; ; ++j)
            if (!vis[j]) { sg[i] = j; break; }
    }
}
```

## 4. SG 定理

**多个独立游戏的和**：每个游戏的 SG 值异或起来，就是总游戏的 SG 值。

$$
SG(x_1 + x_2 + \cdots + x_n) = SG(x_1) \oplus SG(x_2) \oplus \cdots \oplus SG(x_n)
$$

**应用**：把大游戏拆成若干独立的小游戏，分别求 SG，再异或。

**注意**：

- 如果游戏**不独立**（如「只能选一个操作」「总步数有限」），SG 定理不适用；
- 反 Nim 博弈（取完者负）需要特判。

## 5. 模板代码

### 5.1 Nim

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    scanf("%d", &n);
    int x = 0;
    for (int i = 0, a; i < n; ++i) { scanf("%d", &a); x ^= a; }
    puts(x ? "First" : "Second");
    return 0;
}
```

### 5.2 SG 函数（打表）

```cpp
const int N = 1005;
int sg[N];
bool vis[N];

void init() {
    sg[0] = 0;
    for (int i = 1; i < N; ++i) {
        memset(vis, 0, sizeof vis);
        // 枚举所有可达状态
        for (int j = 0; j < i; ++j) vis[sg[j]] = true;
        for (int j = 0; ; ++j) if (!vis[j]) { sg[i] = j; break; }
    }
}
```

### 5.3 取石子（1~m 个）

$$
SG(n) = n \bmod (m+1)
$$

## 6. 经典例题

### 6.1 【模板】Nim 博弈

**题意**：$n$ 堆石子，问先手是否必胜。

**做法**：异或和判断。

### 6.2 取石子游戏（1~3 个）

**题意**：一堆 $n$ 个石子，每次取 1~3 个。

**结论**：$n \bmod 4 == 0$ 时先手必败。

### 6.3 阶梯 Nim

**题意**：石子放在楼梯上，每次把一堆往下移。

**做法**：只考虑奇数层（或偶数层）的异或和。

### 6.4 有向图游戏

**题意**：在 DAG 上，棋子从起点走，不能走者负。

**做法**：拓扑序求 SG。

### 6.5 威佐夫博弈

**题意**：两堆石子，每次可以从一堆取任意个，或从两堆取同样多个。

**结论**：先手必败当且仅当

$$
\lfloor (b-a) \cdot \frac{1+\sqrt5}{2} \rfloor = a \quad (a \le b)
$$

## 7. 易错点与练习

### 易错点

1. **反 Nim 博弈**：取完者负，需要特判（全为 1 时看奇偶，否则正常 Nim）；
2. **SG 定理的适用条件**：游戏必须可拆成独立子游戏；
3. **mex 数组大小**：SG 值可能超过 $n$，要开够；
4. **多组数据清空**：`sg` 数组、`vis` 数组要重置；
5. **Nim 的第一步**：别忘了输出具体操作时对 $a_i$ 的修改。

### 练习建议

1. Nim 模板；
2. 取石子（1~m）；
3. 阶梯 Nim；
4. 威佐夫博弈；
5. 有向图 SG（拓扑序）。
