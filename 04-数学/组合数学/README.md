## 1. 两个基本原理

### 1.1 加法原理

若完成一件事有 $k$ 类互不重叠的方法，第 $i$ 类有 $n_i$ 种做法，则总方法数为

$$
N = n_1 + n_2 + \cdots + n_k
$$

**关键词**：「分类」「或」。每类方法都能独立完成任务，且类与类之间不重叠。

**例**：从北京到上海，可以坐飞机（3 个航班）、高铁（5 趟）或自驾（1 条路线），共 $3 + 5 + 1 = 9$ 种方式。

### 1.2 乘法原理

若完成一件事需要 $k$ 个步骤，第 $i$ 步有 $n_i$ 种做法，则总方法数为

$$
N = n_1 \times n_2 \times \cdots \times n_k
$$

**关键词**：「分步」「且」。必须依次完成所有步骤。

**例**：从 3 件上衣、4 条裤子中选一套，共 $3 \times 4 = 12$ 种搭配。

### 1.3 区分技巧

- **分类用加法，分步用乘法**；
- 判断标准：一件事是否「一次性完成」——若分成若干独立情况，用加法；若必须一步步做，用乘法。

## 2. 排列与组合

### 2.1 排列（有序）

从 $n$ 个不同元素中取出 $m$ 个，**按一定顺序**排成一列，方案数为

$$
A_n^m = P_n^m = \frac{n!}{(n-m)!} = n(n-1)\cdots(n-m+1)
$$

**推导**：第一个位置有 $n$ 种选法，第二个有 $n-1$ 种，……，第 $m$ 个有 $n-m+1$ 种，由乘法原理即得。

**全排列**：$A_n^n = n!$。约定 $0! = 1$。

### 2.2 组合（无序）

从 $n$ 个不同元素中取出 $m$ 个，**不考虑顺序**，方案数为

$$
\binom{n}{m} = C_n^m = \frac{A_n^m}{m!} = \frac{n!}{m!(n-m)!}
$$

**推导**：每一种组合对应 $m!$ 种排列（$m$ 个元素的全排列），故 $C_n^m = A_n^m / m!$。

### 2.3 组合数的基本性质

1. **对称性**：$\dbinom{n}{m} = \dbinom{n}{n-m}$（选出 $m$ 个等价于留下 $n-m$ 个）；
2. **递推式（帕斯卡公式）**：$\dbinom{n}{m} = \dbinom{n-1}{m-1} + \dbinom{n-1}{m}$；
3. **边界**：$\dbinom{n}{0} = \dbinom{n}{n} = 1$，$\dbinom{n}{m} = 0$（$m > n$ 或 $m < 0$）；
4. **吸收恒等式**：$m\dbinom{n}{m} = n\dbinom{n-1}{m-1}$；
5. **求和**：$\sum_{m=0}^{n}\dbinom{n}{m} = 2^n$。

**帕斯卡公式的证明**：考虑从 $n$ 个元素中选 $m$ 个，分两种情况：

- 选中某个特定元素 $x$：还需从剩下 $n-1$ 个中选 $m-1$ 个，有 $\binom{n-1}{m-1}$ 种；
- 不选 $x$：需从剩下 $n-1$ 个中选 $m$ 个，有 $\binom{n-1}{m}$ 种。

由加法原理即得。$\square$

### 2.4 可重复排列与可重复组合

**可重复排列**：从 $n$ 种元素中取 $m$ 个（可重复），方案数 $n^m$。

**可重复组合**（隔板法）：从 $n$ 种元素中取 $m$ 个（可重复，不计顺序），方案数为 $\dbinom{n+m-1}{m}$。

**隔板法证明**：把 $m$ 个相同的球放入 $n$ 个不同的盒子，用 $n-1$ 块隔板把 $m$ 个球分成 $n$ 段，相当于在 $m + n - 1$ 个位置中选出 $n-1$ 个位置放隔板，故有 $\binom{m+n-1}{n-1} = \binom{m+n-1}{m}$ 种。$\square$

### 2.5 圆排列

$n$ 个不同元素排成一个圆，方案数为 $\dfrac{n!}{n} = (n-1)!$，因为 $n$ 种旋转视为同一种排列。

## 3. 二项式定理与杨辉三角

### 3.1 二项式定理

$$
(x + y)^n = \sum_{k=0}^{n} \binom{n}{k} x^{n-k} y^k
$$

**证明**：$(x+y)^n$ 是 $n$ 个 $(x+y)$ 相乘，展开时每一项从每个括号中选 $x$ 或 $y$。若选了 $k$ 个 $y$（其余 $n-k$ 个为 $x$），则得到 $x^{n-k}y^k$，而选择哪 $k$ 个括号出 $y$ 有 $\binom{n}{k}$ 种，故系数为 $\binom{n}{k}$。$\square$

### 3.2 杨辉三角

按帕斯卡公式逐行构造：

```
n=0:              1
n=1:             1 1
n=2:            1 2 1
n=3:           1 3 3 1
n=4:          1 4 6 4 1
n=5:         1 5 10 10 5 1
```

第 $n$ 行第 $m$ 个数（从 $0$ 计数）就是 $\binom{n}{m}$。杨辉三角的每一行左右对称，且行和为 $2^n$。

### 3.3 常见组合恒等式

1. $\sum_{k=0}^{n} \binom{n}{k} = 2^n$（令 $x=y=1$）；
2. $\sum_{k=0}^{n} (-1)^k \binom{n}{k} = 0$（令 $x=1, y=-1$，$n \ge 1$）；
3. $\sum_{k=0}^{n} k\binom{n}{k} = n2^{n-1}$（对二项式定理求导后令 $x=y=1$）；
4. $\sum_{k=0}^{n} \binom{n}{k}^2 = \binom{2n}{n}$（范德蒙德卷积的特例）。

## 4. 组合数的计算

### 4.1 递推（杨辉三角）

$\dbinom{n}{m} = \dbinom{n-1}{m-1} + \dbinom{n-1}{m}$，适用于 $n \le 5000$，复杂度 $O(n^2)$，可边算边取模。

### 4.2 阶乘 + 逆元

当 $n < p$（$p$ 为素数）时，$\dbinom{n}{m} \equiv \text{fact}[n]\cdot\text{invfact}[m]\cdot\text{invfact}[n-m] \pmod p$，预处理 $O(n)$、单次查询 $O(1)$，适用于 $n \le 10^7$。

### 4.3 卢卡斯定理（$n$ 很大，$p$ 较小）

当 $n$ 可达 $10^{18}$、$p$ 为小素数时，用卢卡斯定理（见第 5 节）。

### 4.4 质因数分解法（无模数）

结果需要精确值（不取模）且 $n$ 较大时，可用勒让德定理统计阶乘中每个素因子的指数再乘起来，避免高精度除法。

### 4.5 组合数计算的复杂度选择

| 场景 | 方法 | 复杂度 |
|---|---|---|
| $n \le 5000$ | 杨辉三角递推 | $O(n^2)$ |
| $n \le 10^7$，$p$ 素数 | 阶乘 + 逆元 | $O(n)$ 预处理 |
| $n \le 10^{18}$，$p$ 小素数 | Lucas 定理 | $O(p \log_p n)$ |
| 精确值 | 质因数分解 | 与结果大小相关 |

## 5. 卢卡斯定理

### 5.1 定理内容

设 $p$ 为素数，$n, m$ 为非负整数。把 $n, m$ 写成 $p$ 进制：

$$
n = n_k p^k + \cdots + n_1 p + n_0, \qquad
m = m_k p^k + \cdots + m_1 p + m_0
$$

则

$$
\binom{n}{m} \equiv \prod_{i=0}^{k} \binom{n_i}{m_i} \pmod p
$$

其中约定 $\binom{a}{b} = 0$ 当 $b > a$。

### 5.2 理解与证明思路

**核心引理**：对素数 $p$ 与 $1 \le k \le p-1$，

$$
\binom{p}{k} \equiv 0 \pmod p
$$

因为 $\binom{p}{k} = \frac{p!}{k!(p-k)!}$，分子含因子 $p$，而分母不含（$k, p-k < p$）。

于是 $(1+x)^p \equiv 1 + x^p \pmod p$。反复使用：

$$
(1+x)^{n} = \prod_i \left((1+x)^{p^i}\right)^{n_i}
\equiv \prod_i (1 + x^{p^i})^{n_i} \pmod p
$$

比较两边 $x^m$ 的系数：左边是 $\binom{n}{m}$；右边要凑出 $x^m$，由于 $p$ 进制表示唯一，只能从每个因子中取 $x^{m_i p^i}$，系数为 $\prod_i \binom{n_i}{m_i}$。$\square$

### 5.3 递归写法

$\text{lucas}(n,m,p) = \dbinom{n \bmod p}{m \bmod p}\cdot \text{lucas}(\lfloor n/p\rfloor, \lfloor m/p\rfloor, p) \bmod p$，当 $m=0$ 时返回 $1$。其中 $\binom{n \bmod p}{m \bmod p}$ 用阶乘逆元计算（$n \bmod p < p$，规模很小）。

### 5.4 适用范围

Lucas 定理要求 $p$ 为**素数**。若 $p$ 为合数，需要扩展卢卡斯（exLucas），把 $p$ 分解为素数幂再用 CRT 合并，复杂度更高。

## 6. 卡特兰数与常见数列

### 6.1 卡特兰数

**定义**：卡特兰数 $C_n$ 满足

$$
C_n = \frac{1}{n+1}\binom{2n}{n} = \binom{2n}{n} - \binom{2n}{n+1}
$$

前几项：$C_0 = 1$，$C_1 = 1$，$C_2 = 2$，$C_3 = 5$，$C_4 = 14$，$C_5 = 42$，$C_6 = 132$。

### 6.2 递推式

$$
C_n = \sum_{i=0}^{n-1} C_i C_{n-1-i}, \qquad C_0 = 1
$$

**组合意义**：把长度为 $n$ 的合法括号序列按「第一个左括号匹配的右括号位置」分类，分成两个独立的子问题。

### 6.3 经典模型

1. **合法括号序列**：$n$ 对括号的合法排列数为 $C_n$；
2. **出栈序列**：$n$ 个元素入栈，不同的出栈序列数为 $C_n$；
3. **二叉树计数**：$n$ 个节点的不同形态二叉树有 $C_n$ 棵；
4. **凸多边形三角剖分**：凸 $n+2$ 边形的三角剖分数为 $C_n$；
5. **网格路径**：从 $(0,0)$ 到 $(n,n)$ 且不越过对角线的路径数为 $C_n$。

### 6.4 网格路径的证明

从 $(0,0)$ 到 $(n,n)$ 的路径数为 $\binom{2n}{n}$。不合法路径（越过对角线）与从 $(0,0)$ 到 $(n-1,n+1)$ 的路径一一对应（反射原理），故不合法数为 $\binom{2n}{n+1}$。因此 $C_n = \binom{2n}{n} - \binom{2n}{n+1} = \frac{1}{n+1}\binom{2n}{n}$。

### 6.5 其他常见数列

- **斐波那契数列**：$F_n = F_{n-1} + F_{n-2}$，组合意义是「用 1 和 2 凑出 $n$ 的方案数」；
- **斯特林数**：第二类 $\left\{{n \atop k}\right\}$ 表示把 $n$ 个元素划分成 $k$ 个非空集合的方案数；
- **贝尔数**：$B_n = \sum_k \left\{{n \atop k}\right\}$，即把 $n$ 个元素划分成若干非空集合的方案数。

## 7. 模板代码

### 7.1 阶乘逆元求组合数（C++14，可直接编译）

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const int MAXN = 1000005;
const ll MOD = 1000000007;
ll fact[MAXN], invfact[MAXN];

ll qpow(ll a, ll b, ll p) {
    ll ans = 1 % p;
    a %= p;
    while (b) {
        if (b & 1) ans = ans * a % p;
        a = a * a % p;
        b >>= 1;
    }
    return ans;
}

void init(int n) {                       // O(n) 预处理
    fact[0] = 1;
    for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i % MOD;
    invfact[n] = qpow(fact[n], MOD - 2, MOD);
    for (int i = n; i >= 1; i--) invfact[i - 1] = invfact[i] * i % MOD;
}

ll C(int n, int k) {                     // C(n, k) mod MOD
    if (k < 0 || k > n) return 0;
    return fact[n] * invfact[k] % MOD * invfact[n - k] % MOD;
}

ll A(int n, int k) {                     // A(n, k) = n!/(n-k)!
    if (k < 0 || k > n) return 0;
    return fact[n] * invfact[n - k] % MOD;
}

int main() {
    init(1000000);
    printf("C(10,3) = %lld\n", C(10, 3));
    printf("A(10,3) = %lld\n", A(10, 3));
    printf("C(1000000,500000) = %lld\n", C(1000000, 500000));
    return 0;
}
```

### 7.2 杨辉三角递推

$n \le 5000$ 时可直接开 `C[5005][5005]` 二维数组：初始化 `C[i][0] = C[i][i] = 1`，再按 `C[i][j] = (C[i-1][j-1] + C[i-1][j]) % p` 逐行递推，复杂度 $O(n^2)$，支持任意模数（含合数）。

### 7.3 卢卡斯定理

```cpp
ll p;                                    // 素数模数

ll C_small(ll n, ll m) {                 // C(n,m) mod p，要求 n,m < p
    if (m > n) return 0;
    ll up = 1, down = 1;
    for (ll i = 1; i <= m; i++) {
        up = up * (n - i + 1) % p;       // 分子 n(n-1)...(n-m+1)
        down = down * i % p;             // 分母 m!
    }
    return up * qpow(down, p - 2, p) % p; // 费马小定理求分母逆元
}

ll Lucas(ll n, ll m) {                   // C(n,m) mod p
    if (m == 0) return 1;
    return C_small(n % p, m % p) * Lucas(n / p, m / p) % p;
}
```

### 7.4 卡特兰数

卡特兰数 $C_n = C(2n,n)/(n+1) \bmod p$：先预处理阶乘与逆元到 $2n$，再计算 `C(2*n, n) * qpow(n+1, p-2, p) % p` 即可。

## 8. 经典例题

### 例题 1：洛谷 P3807 【模板】卢卡斯定理

**题意**：给定 $n, m, p$（$p$ 为素数），求 $\dbinom{n+m}{m} \bmod p$，$n, m \le 10^{18}$，$p \le 10^5$。

**思路**：直接套用 Lucas 定理，$p$ 很小所以 `C_small` 可以直接循环计算。

**复杂度**：$O(p \log_p n)$ 每次询问。

---

### 例题 2：洛谷 P1044 栈

**题意**：$n$ 个元素依次入栈，求不同的出栈序列数，$n \le 18$。

**思路**：这是卡特兰数 $C_n$ 的经典模型。可以直接用递推 $C_n = \sum C_i C_{n-1-i}$，或用公式 $C_n = \binom{2n}{n}/(n+1)$。

**复杂度**：$O(n^2)$ 或 $O(n)$。

**核心代码**：

```cpp
ll h[20];
h[0] = 1;
for (int i = 1; i <= n; i++)
    for (int j = 0; j < i; j++)
        h[i] += h[j] * h[i - 1 - j];
printf("%lld\n", h[n]);
```

---

### 例题 3：洛谷 P2822 [NOIP2016 提高组] 组合数问题

**题意**：给定 $n, m, k$，求满足 $0 \le i \le n$，$0 \le j \le \min(i, m)$ 且 $k \mid \binom{i}{j}$ 的数对 $(i,j)$ 个数。多组询问，$n, m \le 2000$。

**思路**：预处理杨辉三角（对 $k$ 取模），同时维护二维前缀和，$O(1)$ 回答询问。

**复杂度**：$O(n^2 + T)$。

**核心代码**：

```cpp
// C[i][j] 对 k 取模，pre[i][j] 为二维前缀和
for (int i = 0; i <= 2000; i++) {
    C[i][0] = C[i][i] = 1 % k;
    for (int j = 1; j < i; j++)
        C[i][j] = (C[i - 1][j - 1] + C[i - 1][j]) % k;
}
for (int i = 0; i <= 2000; i++)
    for (int j = 0; j <= 2000; j++) {
        pre[i][j] = (i ? pre[i - 1][j] : 0) + (j ? pre[i][j - 1] : 0)
                  - ((i && j) ? pre[i - 1][j - 1] : 0) + (j <= i && C[i][j] == 0);
    }
```

### 例题 4：洛谷 P1641 [SCOI2010] 生成字符串

**题意**：由 $n$ 个 1 和 $m$ 个 0 组成字符串，要求任意前缀中 1 的个数不少于 0 的个数，求方案数（$n \ge m$）。

**思路**：这是卡特兰数的推广（反射原理）。总方案数 $\binom{n+m}{m}$，不合法方案数 $\binom{n+m}{m-1}$，答案为

$$
\binom{n+m}{m} - \binom{n+m}{m-1}
$$

**复杂度**：$O(n + m)$ 预处理阶乘。

## 9. 易错点

1. **混淆排列与组合**：有序用 $A$，无序用 $C$。看清题意「是否考虑顺序」。
2. **组合数取模时 $n \ge p$**：$n! \equiv 0 \pmod p$，逆元不存在，必须用 Lucas。
3. **Lucas 要求 $p$ 为素数**：合数模数要用 exLucas。
4. **阶乘逆元数组开小**：$C_n^m$ 需要算到 $n$，数组至少开到 $n$。
5. **`C(n, k)` 未判 `k < 0 || k > n`**：会导致数组越界或错误结果。
6. **卡特兰数公式记错**：$C_n = \frac{1}{n+1}\binom{2n}{n}$，不是 $\frac{1}{n}\binom{2n}{n}$。
7. **隔板法条件**：球必须相同、盒子必须不同，且允许为空时用 $\binom{n+m-1}{m}$；不允许为空时用 $\binom{m-1}{n-1}$。
8. **二项式定理的指数**：$(x+y)^n$ 中 $x^{n-k}y^k$ 的系数是 $\binom{n}{k}$，不是 $\binom{n}{n-k}$（两者相等，但推导时要清楚）。
9. **多组询问未预处理**：$T$ 很大时必须预处理，否则 $O(Tn)$ 超时。
10. **模数不是素数**：阶乘逆元法失效，需用 exLucas 或质因数分解。

9. **提高**：洛谷 P5290 [十二省联考 2019] 春节十二响 —— 组合计数综合。

**学习路径建议**：

- 先把加法原理与乘法原理用熟，能快速判断一个问题该「分类」还是「分步」；
- 再吃透组合数的五个基本性质，特别是帕斯卡公式与隔板法；
- 然后掌握「阶乘 + 逆元」与 Lucas 两套计算框架；
- 最后积累卡特兰数、斯特林数等常见模型的识别能力。

> 一句话总结：**组合数学的核心是「把复杂计数拆成若干个独立的小计数」**；加法原理处理「分类」，乘法原理处理「分步」，而各种公式不过是这两条原理的推论。
