# 三分法（Ternary Search）

> 三分法用来求**单峰函数**的极值。二分比较的是「中点与目标值的大小」，三分比较的是「两个三分点的函数值」。

## 1. 适用条件

- 函数在区间内**单峰**（先增后减，或先减后增）；
- 函数**可求值**（不需要导数）；
- 不需要函数是连续的（整数三分也适用）。

**注意**：三分法不能处理有多个峰的函数；如果函数不单峰，可以尝试「模拟退火」或分段三分。

---

## 2. 算法原理

设区间 $[l, r]$，取两个三等分点：

$$
m_1 = l + \frac{r-l}{3}, \quad m_2 = r - \frac{r-l}{3}
$$

**求最大值**（先增后减）：

- 若 $f(m_1) < f(m_2)$：最大值在 $[m_1, r]$，令 $l = m_1$；
- 若 $f(m_1) > f(m_2)$：最大值在 $[l, m_2]$，令 $r = m_2$；
- 相等时：最大值在 $[m_1, m_2]$，两边都可以缩。

**求最小值**：反过来。

```
        ╱╲
       ╱  ╲
      ╱    ╲
   l  m1    m2  r
```

## 3. 实数三分

**终止条件**：迭代固定次数（100~200 次）比 `r - l > eps` 更稳。

```cpp
double ternaryMax(double l, double r) {
    for (int it = 0; it < 200; ++it) {
        double m1 = l + (r - l) / 3;
        double m2 = r - (r - l) / 3;
        if (f(m1) < f(m2)) l = m1;
        else r = m2;
    }
    return (l + r) / 2;
}
```

**为什么迭代 200 次？** 每次区间缩小 $2/3$，$200$ 次后缩小到 $(2/3)^{200} \approx 0$，精度足够。

## 4. 整数三分

**注意**：整数域上 $m_1$ 和 $m_2$ 可能相邻或重合，需要特殊处理。

### 4.1 写法一：三分点取整

```cpp
int ternaryMaxInt(int l, int r) {
    while (r - l > 2) {
        int m1 = l + (r - l) / 3;
        int m2 = r - (r - l) / 3;
        if (f(m1) < f(m2)) l = m1 + 1;
        else r = m2 - 1;
    }
    int best = l;
    for (int i = l; i <= r; ++i)
        if (f(i) > f(best)) best = i;
    return best;
}
```

### 4.2 写法二：二分导数（更稳）

如果函数是「先增后减」，可以二分找「$f(x) > f(x+1)$ 的第一个位置」：

```cpp
int ternaryMaxInt(int l, int r) {
    while (l < r) {
        int mid = (l + r) >> 1;
        if (f(mid) < f(mid + 1)) l = mid + 1;   // 还在上升
        else r = mid;
    }
    return l;
}
```

> 推荐写法二，简洁且不会死循环。

## 5. 模板代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 示例函数：f(x) = -x^2 + 4x + 1，最大值在 x = 2
double f(double x) { return -x * x + 4 * x + 1; }

int main() {
    double l = -10, r = 10;
    for (int it = 0; it < 200; ++it) {
        double m1 = l + (r - l) / 3;
        double m2 = r - (r - l) / 3;
        if (f(m1) < f(m2)) l = m1;
        else r = m2;
    }
    printf("%.10f %.10f\n", (l + r) / 2, f((l + r) / 2));
    return 0;
}
```

## 6. 经典例题

### 6.1 求单峰函数极值

**题意**：给一个先增后减的函数，求最大值。

**做法**：实数三分。

### 6.2 三分求点到抛物线距离

**题意**：给抛物线 $y = ax^2 + bx + c$ 和点 $P$，求 $P$ 到抛物线的最短距离。

**做法**：距离函数关于 $x$ 单峰（在合理区间内），三分。

### 6.3 最大三角形（三分法）

**题意**：凸包上选三点使面积最大。

**做法**：枚举一条底边，三分找最高点。

### 6.4 三分求函数最值（含参数）

**题意**：$f(x) = \sum |x - a_i|$，求最小值。

**做法**：中位数；但也可以用三分（函数是凸的，单峰）。

### 6.5 二分答案 + 三分

某些题需要「二分区间的长度，三分找最优位置」。

## 7. 易错点与练习

### 易错点

1. **函数不单峰**：三分会得到错误的极值；
2. **平台期**：$f(m_1) == f(m_2)$ 时两边都可能，随便缩一边通常没问题，但要注意精度；
3. **整数三分的边界**：`m1 == m2` 时死循环，用写法二避免；
4. **迭代次数**：实数三分迭代 100~200 次，别用 `eps` 判断（可能死循环）；
5. **区间端点**：极值可能在端点，最后要比较；
6. **答案需要整数**：整数三分的结果要再检查附近几个点。

### 练习建议

1. 实数三分模板；
2. 整数三分模板；
3. 三分求抛物线距离；
4. 三分 + 凸包；
5. 对比三分与二分答案的区别。
