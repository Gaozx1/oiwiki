## 使用说明

1. **按目录顺序学习**：先 `00-语言与基础`，再数据结构与图论，最后算法思想。
2. **每个知识点文件夹内的 `README.md`** 都包含统一的五段式结构：
   - 概念与原理
   - 模板代码（C++14/17）
   - 经典例题
   - 易错点
   - 练习建议
3. 代码均可直接编译运行（`-O2 -std=c++14`）。
4. 欢迎提交 Issue / PR 补充内容。

## 贡献规范

- 每个知识点一个文件夹，文件夹内必须含 `README.md`；
- 代码块使用 ` ```cpp ` 标注语言；
- 公式使用 LaTeX（`$...$` 行内，`$$...$$` 独立行）；
- 例题请注明题意、思路与复杂度。
